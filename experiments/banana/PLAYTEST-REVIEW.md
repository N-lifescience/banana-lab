## 허브에 넘길 것 (제 폴더지만 제 것이 아닙니다)

- 커밋 `64e0e30`(배치 편집 y 입력칸, 여덟 실험 공통)이 편집 표 행에 **`<tr data-id="${it.id}">`** 를 붙였습니다. 그 때문에 `[data-id="banana"]` 가 **물건과 표 행 둘**에 걸려, `node scripts/check-bench.mjs` 가 **118/118 까지 통과한 뒤 「검사가 중간에 멎었습니다 — strict mode violation」** 로 서고 편집 모드 뒤쪽 검사가 안 돕니다. `npm run check` 는 초록불이라 커밋 게이트에는 안 잡힙니다.
  고치려면 표 행의 열쇠를 `data-id` 가 아닌 다른 이름(예: `data-row`)으로 바꾸면 됩니다. **여덟이 같은 화면이라 한 곳만 고치면 어긋나므로 제가 손대지 않았습니다.**

## 잘 된 것 세 줄

- **결과가 실제로 다르다.** (가)는 세포 윤곽만, (나)는 청람색 알갱이가 세포를 채우고, (다)는 선홍색 점 두어 개 — 지방 0.3 % 라는 사실이 그림에 그대로 있다. 라이트·다크 양쪽에서 청람과 선홍이 확실히 갈린다.
- **막는 자리가 딱 둘뿐이다.** 두껍게 바르기·열한 방울·안 씻은 스포이트·0° 로 덮기·덮개 없이 400배 — 전부 그대로 진행되고 시야가 답한다. 막힌 것은 금 간 유리를 올릴 때뿐이었고, 그때도 「새로 만들어야 합니다」까지 말한다.
- **키보드만으로 처음부터 끝까지 갈 수 있다.** 물건 → 놓기 단추 → 다음 물건, Esc 로 말풍선 닫기, 글칸 사이 Tab 에서 글자가 안 새고 포커스가 `body` 로 안 떨어진다. 잠긴 STEP 은 다 적고 **한 번** 누르면 열린다.
