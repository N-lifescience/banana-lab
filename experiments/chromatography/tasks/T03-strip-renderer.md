# T03 · 결과 렌더러 — 거름종이 위의 색 띠

바나나랩의 `src/render/fov.js`(현미경 시야) 자리에 `src/render/strip.js` 가 온다.
**이 실험이 "뼈대가 현미경 없이도 서는가" 를 검증하는 자리다.**

## 목표

상태를 받아 **같은 상태면 같은 그림**을 내는 순수 함수. 난수는 `seed` 로 받는다.
그래야 기록해 두었다가 탐구 노트와 보고서에서 되살릴 수 있다.

`renderStrip(params, { idPrefix })` — **`idPrefix` 를 처음부터 받는다.**
한 화면에 여러 장을 그리는 순간(탐구 노트 결과·보고서·모둠 보드) 하드코딩된 id 는
**에러 없이 조용히** 틀린다 (`PLAYBOOK.md` §9-4).

## 그릴 것

```
거름종이 2 × 10 cm 세로 스트립
  원점 선            아래에서 2.5 cm (연필이면 흐린 회색, 볼펜이면 잉크색 + 가짜 띠)
  원점의 점          지름은 spotWidthMm, 진하기는 load
  용매 전선          지금 높이. 표시했으면 연필 선이 남는다
  색 띠 4개          카로틴 주황 · 잔토필 노랑 · 엽록소 a 청록 · 엽록소 b 황록
  젖은 영역          전선 아래는 젖어 색이 살짝 짙다
  자 눈금            학생이 재는 자리 (mm)
```

## 결과가 답하는 것 — 화면이 대신 말한다

| 상태 | 그림 |
|---|---|
| `load` 낮음 | 띠 넷이 다 옅다. 흐려서 구별이 안 간다 |
| `spotWidthMm` 큼 | 띠가 굵고 서로 겹친다 |
| 원점 잠김 | **띠가 없다.** 원점 자리도 비었다 |
| 전선이 원점 가까이 | 띠가 뭉쳐 갈라지지 않았다 |
| 전선이 종이 끝 초과 | 전선을 그리지 않는다 — 어디였는지 알 수 없다 |
| 뚜껑 열어 둠 (빛) | **청록·황록 두 띠가 먼저 옅어진다.** 주황·노랑은 남는다 |
| 볼펜으로 원점 | 잉크가 갈라진 가짜 띠가 섞인다 |
| 층 분리 전에 뽑음 | 원점에 부스러기 얼룩, 띠 가장자리가 번진다 |

## 지킬 것

- **Rf 숫자를 그림에 적지 않는다.** 자 눈금만 그리고 **재는 것은 학생**이다.
  앱은 정답 Rf 를 갖고 있지 않다 (`AGENTS.md` §2.5)
- 띠 이름표를 기본으로 켜 두지 않는다 — **화면이 채점할 답을 먼저 말하면 안 된다**
  (`NEW-EXPERIMENT.md` §7-6). 이름표는 정리 단계에서 대조할 때만 켠다
- 이 파일은 아트 디렉션 린터의 **예외**다. 그래서 **애셋 에이전트에게 읽히지 않는다** —
  따라 쓰면 애셋이 오염된다

## 합격 기준

- [ ] 같은 params + 같은 seed → 같은 SVG 문자열 (테스트)
- [ ] `idPrefix` 두 개로 한 화면에 두 장을 그려도 서로 간섭하지 않는다 (테스트)
- [ ] 위 표의 8줄이 **눈으로 실제로 달라 보인다** — 하네스에서 손잡이를 움직여 확인
- [ ] 띠 순서가 위에서부터 **주황 · 노랑 · 청록 · 황록** 이다 (테스트)
- [ ] 그림 어디에도 Rf 숫자가 없다 (테스트)

## 검증 명령

```bash
npm run check
npm run dev   # → /harness.html 에서 손잡이를 움직여 눈으로
npm run shot -- '.strip-stage' strip
```
