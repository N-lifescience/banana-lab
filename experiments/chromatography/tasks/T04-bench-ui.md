# T04 · 실험대 조작 UI · 확대 뷰 · 어포던스

**어포던스까지 한 카드로.** 기능만 넣고 끝내지 마라 — 바나나랩에서 집기·채우기·문지르기가
전부 구현된 뒤에도 "이거 어떻게 하는 거야?" 라는 말을 들었다.

## 건드릴 파일

`src/ui/bench.js` 의 **세 곳만**. 나머지(드래그·스냅·이름표·히트박스·편집 모드)는 그대로.

```js
defaultItems()   // 실험대에 무엇이 어디에 놓이는가
dropTable()      // 무엇을 무엇에 끌어다 놓으면 무슨 일이 일어나는가
tapTable()       // 무엇을 클릭하면 무슨 일이 일어나는가
```

**조작표는 이 두 표에만 적는다.** 실제 실행·드래그 중 하이라이트·안내 문구 유무가 전부
이 표를 읽는다. 세 곳에 따로 적으면 조작을 하나 늘릴 때마다 세 곳이 어긋난다.

## 실험대 배치

배치는 **손으로 숫자를 적지 않는다.** `npm run dev` → `http://localhost:5173/experiments/chromatography/?edit=1`
에서 끌어 옮기고 「코드 복사」를 누른다.

```
선반    시금치 잎 · 거름종이 통 · 모세관 · 연필 · 자 · 추출액병 · 전개액병
작업면  원심관 · 바이알 · 실험 접시 · 폐액통 · 휴지 · 개수대 · 쓰레기통
```

## 실험대 / 확대 뷰의 경계

| 어디서 | 무엇을 |
|---|---|
| 실험대 | 물건을 집어 옮긴다. 어디에 무엇을 대는가 |
| 확대 뷰 | **결과를 가르는 값** — 원점을 몇 mm 에 긋는가, 몇 번 찍는가, 얼마나 오래 대는가, 전개액을 얼마나 붓는가 |

**변인은 손이 정해야 한다.** 가져다 대기만 하면 알아서 15번 찍히게 두면, "몇 번 찍는가"
라는 이 실험의 변인이 학생 손을 떠나고 세어 볼 일 자체가 없어진다.

확대 뷰 두 모드: **원점 찍기**(연필·모세관·말리기) / **전개**(전개액 붓기·종이 세우기·뚜껑).

## 어포던스 — 없으면 기능은 없는 것과 같다

- 물건에 마우스를 올리면 **이름 + 지금 할 수 있는 조작**
- 끄는 동안 **놓을 수 있는 곳** 강조, 지금 놓을 대상은 더 강하게
- 시간이 걸리는 조작(흔들기·전개)은 **진행 표시**
- 끄는 물건은 살짝 비치게 — 큰 물건이 아래 강조를 가린다
- 잡는 영역 최소 44 px. **판정도 같은 크기로**

강조는 「된다」가 아니라 **「여기에 무언가 일어난다」**다. 표를 **종류 쌍**으로만 적고
상태는 보지 않는다 — 빈 모세관을 원점에 대면 규칙 엔진이 "모세관이 비어 있습니다" 라고
답해 주는데, **그 답을 듣는 것이 배우는 내용이다.** 미리 걸러 내면 들을 기회가 사라진다.

## 물린 함정 (바나나랩에서 실제로)

1. **잡는 영역이 그림보다 크다.** `CONTENT_BOX` 를 쓴다
2. **다시 그릴 때마다 DOM 참조가 죽는다.** 떨어져 나간 노드는 크기가 0이다. 그때그때 조회
3. **빠른 드래그는 중간 이동 이벤트가 안 온다.** 누른 곳과 뗀 곳의 거리로 가른다
4. **포인터 이벤트만 들으면 `element.click()` 이 아무 일도 안 한다.** 보조기기가 통째로 막힌다

## 합격 기준

- [ ] `node scripts/check-bench.mjs` 통과
- [ ] 조작표와 안내 문구가 어긋나지 않는다 (테스트)
- [ ] 물건끼리 겹치지 않는다 (테스트)
- [ ] `element.click()` 으로도 모든 조작이 된다
- [ ] 다크 모드에서 사라지는 버튼이 없다
- [ ] **직접 끝까지 플레이했다** — 사람에게 물어보기 전에
