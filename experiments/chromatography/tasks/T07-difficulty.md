# T07 · 난이도 세 단계

## 핵심 규칙 하나

> **난이도는 설명만 줄인다. 할 수 있는 일은 세 단계가 똑같다.**

힌트를 줄여서 길이 막히면 그건 설명을 줄인 게 아니라 **강제를 넣은 것**이다.

| | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 절차 제시 | 다음 할 일 강조 | 목록만 | 목표만 |
| 실패 안내 | 원인 + 다음 행동 | 원인만 | 원인만 |
| 말풍선 힌트 | 문장 | 짧은 구 | 이름만 |
| 예상 문항 | 선택형 | 반주관식 | 완전 주관식 |
| 되돌리기 | 무제한 | 3회 | 1회 |
| 기구 초기 설정 | 대신 맞춰 줌 | 직접 | 직접 |

**1단계가 대신 맞춰 주는 것**: 원점을 아래에서 2.5 cm 에 그어 둔다. 전개액 깊이를 원점이
잠기지 않는 값으로 맞춰 둔다. **순서를 조심할 것** — 바나나랩에서 자동 보조의 순서를
잘못 짜서 보조가 슬라이드를 깨뜨렸다 (`PLAYBOOK.md` §9-6).

## 지킬 것

- 조작표가 난이도를 인자로 받지 않는다. **1단계와 3단계의 조작표 모양이 같은지** 테스트
- 난이도는 **시작 화면에서 고르고**, 주소(`?level=2`)로도 들어갈 수 있다 —
  교사가 반이나 모둠에 따라 링크를 나눠 주는 길이 필요하다
- 바나나랩에서 **118개 테스트가 통과하는데 2·3단계에 닿을 방법이 없었다.**
  주소로도 시작 화면으로도 실제로 들어가 보고 확인한다

## 합격 기준

- [ ] 세 단계에서 **할 수 있는 조작 집합이 같다** (테스트)
- [ ] `?level=2` · `?level=3` 으로 실제로 들어가진다 (직접 확인)
- [ ] 되돌리기 횟수가 단계별로 실제로 다르고, 3단계에서도 기능이 살아 있다
