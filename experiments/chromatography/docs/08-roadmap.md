# 08 · 구현 순서와 완성 판정

## 순서

한 번에 전부 만들지 않는다. 각 단계는 그 자체로 실행되고 눈으로 확인되는 상태에서 끝난다.

| 카드 | 내용 | 끝났다는 것 |
|---|---|---|
| T01 | 상태 모델 · 전개 물리 · 규칙 엔진 | UI 없이 정상 경로와 모든 실패 경로가 테스트로 통과 |
| T02 | 애셋 8종 · 팔레트 · 하네스 | `npm run check:art` 통과, 하네스에서 전부 보임 |
| T03 | 결과 렌더러 (거름종이) | 손잡이를 흔들어 여덟 가지 상태가 눈으로 달라 보임 |
| T04 | 조작 UI · 확대 뷰 · 어포던스 | `node scripts/check-bench.mjs` 통과 |
| T05 | 탐구 노트 7단계 · 문자열 | `npm run check` 통과 |
| T06 | 서술형 첨삭 | `node scripts/check-grading.mjs` — 바깥 문장 거짓 부정 0건 |
| T07 | 난이도 세 단계 | 2·3단계에 **실제로 닿는지** 브라우저로 확인 |
| T08 | 보고서 | 인쇄 미리보기까지 열어 봄 |
| T09 | 배포본 확인 | `node scripts/check-build.mjs` 통과 |
| T10 | 매니페스트 · 문서 정리 | `node --test tests/manifest.test.js` 통과 |

현재: **T01~T10 완료.** 결과 보드(Supabase)는 바나나랩에서 물려받은 그대로 두었다 —
이 실험에서 손대지 않았다.
진행 기록과 각 카드에서 무엇을 왜 고쳤는지는 `PROGRESS.md` 에 있다.

## 완성 판정 체크리스트

기능이 아니라 **설계 의도가 살아 있는지**를 본다. 하나라도 아니면 아직이다.

### 강제하지 않는가

- [ ] 원점이 잠기게 종이를 세우는 것이 **되기는 되는가**. 막혀 있으면 개정 취지가 사라진 것
- [ ] 볼펜으로 원점을 그을 수 있는가. 그리고 잉크의 가짜 띠가 실제로 나오는가
- [ ] 젖은 종이에 자를 대면 실제로 찢어지고, **거름종이 통에서 새것을 꺼낼 수 있는가**
- [ ] 두 하드 게이트의 문장이 **어디로 가야 하는지**까지 말하는가
- [ ] 흐린 결과가 기록되고, 정리 단계에 성찰 문항이 붙는가
- [ ] 확대 뷰의 단추가 잠겨 있지 않은가. 마른 종이에 「말리기」를 눌러도 규칙이 답해야 한다
- [ ] `tests/rules.test.js` 의 「하드 게이트는 두 종류뿐이다」가 통과하는가

### 과학적으로 맞는가

- [ ] 띠 순서가 위에서부터 **주황 · 노랑 · 청록 · 황록** 인가 (**종이**의 순서다)
- [ ] 「TLC」·「실리카겔」이 어디에도 없는가. 있으면 띠 순서가 거짓이 된다
- [ ] 엽록소 a 가 **청록**, b 가 **황록** 인가 (나무위키가 이 둘을 뒤바꿔 적어 두었다)
- [ ] 전개액이 **9:1**, 추출액이 **3:1** 인가 (7:3 은 다른 용매 계통의 값이다)
- [ ] 뚜껑을 열어 두면 **청록·황록 두 띠만** 옅어지는가. 주황·노랑까지 옅어지면 틀린 것
- [ ] 전선 거리가 시간의 **제곱근**에 비례하는가. 선형이면 절차의 근거가 사라진다
- [ ] 원점이 잠기면 띠가 **하나도** 남지 않는가. 옅어지기만 하면 잘못 구현한 것
- [ ] **화면 어디에도 색소별 Rf 값이 없는가.** 앱은 그 답을 갖고 있지 않다

### 만듦새

- [ ] `npm run check:art` 통과. 그라데이션·팔레트 밖 색·임의 선 두께 0건
- [ ] **색소 네 색이 기구 애셋에 없는가** (`tests/palette.test.js`)
- [ ] 같은 시드로 두 번 그리면 같은 그림, 다른 시드면 다른 그림인가
- [ ] `idPrefix` 를 달리한 두 장이 서로 간섭하지 않는가
- [ ] 화면의 id 가 애셋 안의 id 와 부딪히지 않는가 (`tests/dom-ids.test.js`)
- [ ] 다크 모드에서 띠 네 색이 모두 식별되는가
- [ ] 결과 보드에 이미지가 저장되고 있지는 않은가. 값 한 벌만 오가야 한다
- [ ] 학생 이름·학번을 입력받는 칸이 실험 중에 어디에도 없는가

### 교육적으로 작동하는가

- [ ] 서술형에 색소 이름만 늘어놓으면 통과하지 못하는가. **순서**를 물었으므로 순서를 써야 한다
- [ ] 색 이름으로 쓴 답도 통과하는가. 색소 이름을 못 외운 것이지 틀린 것이 아니다
- [ ] 전개율 첨삭이 **몫을 내주지 않는가.** 한 번 내주면 그 뒤로는 나눌 이유가 없다
- [ ] 실패한 학생이 **무엇을 고쳐야 할지** 화면에서 알 수 있는가 (`observability().worst`)
- [ ] 다른 모둠 결과가 왜 다르게 보이는지 조작 조건으로 설명할 수 있는가
