# 04 · 조작 규칙표 — 강제 대신 귀결

## 원칙 하나

> **강제하지 말고 결과로 답한다.**

학생의 잘못된 조작을 **막지 않는다.** 그대로 진행시키고 거름종이가 대신 말한다.

```js
// ❌ 막는다
if (spots < 10) return showError('열 번 이상 찍으세요');

// ✅ 결과로 답한다
const load = Math.min(spots * 0.055, 1);   // 렌더러가 흐린 띠를 그린다
```

`reduce()` 가 돌려주는 결과는 셋뿐이다.

| 결과 | 뜻 |
|---|---|
| `ok` | 진행됐다. 무엇이 바뀌었는지만 말한다 |
| `happened` | 진행됐다. 다만 이런 일이 일어났다 — **이 실험의 대부분이 여기다** |
| `blocked` | 진행되지 않았다. **아래 둘에만** |

`tests/rules.test.js` 의 「하드 게이트는 두 종류뿐이다」가 모든 액션을 여러 상태에서
돌려 이것을 지킨다.

## 하드 게이트 둘 — **빠져나갈 길을 문장에 담는다**

| 사유 | 언제 | 문장 |
|---|---|---|
| `IMPOSSIBLE` | 뚜껑을 닫은 바이알에 종이를 넣으려 할 때 | 「바이알 뚜껑이 닫혀 있어 종이를 넣을 수 없습니다. **바이알을 눌러 뚜껑을 먼저 여세요.**」 |
| `BROKEN` | 젖은 거름종이에 자를 댈 때 | 「젖은 거름종이에 자를 대자 찢어졌습니다. **선반의 거름종이 통에서 새것을 꺼내세요.** 다음에는 말린 뒤에 재세요.」 |

「새것을 꺼내세요」로 끝내지 않는다 — **어디서** 꺼내는지까지 말한다.
`tests/rules.test.js` 의 「차단 메시지는 어디로 가야 하는지까지 말한다」가 이것을 검사한다.

## 규칙표 — 잘못하면 무엇이 보이는가

전부 `happened` 다. 진행되고, 결과가 답한다.

| 액션 | 잘못하면 | 태그 | 결과로 보이는 것 |
|---|---|---|---|
| `PICK_LEAF` | 시든 잎을 고름 | `wilted-leaf` | 뽑을 색소가 적어 띠 넷이 다 흐리다 |
| `ADD_LEAF` | 시든 잎을 넣음 | `wilted-leaf` | 위와 같다 |
| `ADD_EXTRACT` | 잎 없이 넣음 | `no-leaf` | 추출액만 들어간다 |
| `ADD_EXTRACT` | 잎보다 두 배 넘게 | `diluted` | 상층액이 묽어 띠가 흐리다 |
| `SHAKE` | 잎·추출액이 없음 | `nothing-to-shake` | 흔들 것이 없다 |
| `LOAD_CAPILLARY` | 층 분리 전에 뽑음 | `unsettled` | 잎 부스러기가 딸려 와 원점이 지저분하다 |
| `LOAD_CAPILLARY` | 뽑을 것이 없음 | `no-extract` | 아무것도 안 묻는다 |
| `DRAW_ORIGIN` | **볼펜**으로 그음 | `pen-origin` | 잉크가 함께 올라가 **가짜 띠**가 섞인다 |
| `DRAW_ORIGIN` | 6 mm 아래 | `origin-low` | 전개액에 잠기기 쉽다 |
| `DRAW_ORIGIN` | 20 mm 위 | `origin-high` | 올라갈 거리가 짧아 덜 갈라진다 |
| `SPOT` | 모세관이 빔 | `capillary-empty` | 아무것도 안 찍힌다 |
| `SPOT` | 원점 선 없이 찍음 | `no-origin-line` | 자국은 남지만 잰 자리를 잃는다 |
| `SPOT` | 마르기 전에 겹쳐 찍음 | `spot-smeared` | 원점이 번져 커진다 → 굵은 띠 |
| `SPOT` | 한 번에 오래 댐 | `spot-wide` | 원점이 커진다 → 굵은 띠 |
| `POUR_SOLVENT` | 원점보다 깊게 | `solvent-deep` | 세우면 원점이 잠긴다고 미리 말한다 |
| `INSERT_PAPER` | 전개액이 없음 | `no-solvent` | 종이는 젖지 않는다 |
| `INSERT_PAPER` | 원점이 잠기게 | `origin-submerged` | **색소가 전개액에 풀려 나가 띠가 없다** |
| `INSERT_PAPER` | 아무것도 안 찍음 | `no-spots` | 전개액은 오르지만 갈라질 것이 없다 |
| (기다림) | 뚜껑을 안 덮음 | — | 빛이 들어 **청록·황록 두 띠가 먼저 옅어진다** |
| `REMOVE_PAPER` | 너무 일찍 | `too-early` | 넷이 원점 가까이 뭉쳐 갈라지지 않았다 |
| `REMOVE_PAPER` | 너무 늦게 | `front-overrun` | 전선이 종이 끝을 넘어가 **Rf 를 잴 수 없다** |
| `MARK_FRONT` | 마른 뒤에 | `front-dried` | 전선이 사라져 어디였는지 알 수 없다 |
| `DRY_PAPER` | 전선을 표시하기 전에 | `front-lost` | 위와 같다 |
| `MARK_BANDS` | 젖은 채로 | `marks-smeared` | 연필 자국이 번진다 |
| `CAPTURE` | 띠가 거의 없음 | `empty-capture` | 그대로 기록된다. 정리에서 왜 그랬는지 적는다 |

## 되돌아갈 길 — 막다른 길을 만들지 않는다

**새 조작을 넣을 때마다 「이걸 잘못하면 어떻게 되돌아오나」를 같이 정한다.**

| 길 | 어디서 | 무엇이 되돌아가나 |
|---|---|---|
| `NEW_PAPER` | 거름종이 통 · 쓰레기통 | 종이가 통째로 새것. 원심관의 상층액은 그대로 |
| `EMPTY_TUBE` | 폐액통 · 개수대 | 잘못 만든 추출액 |
| `EMPTY_VIAL` | 폐액통 · 개수대 | 너무 많이 부은 전개액 |
| `RINSE_CAPILLARY` | 폐액통 | 잘못 묻힌 상층액 |
| `UNCAP_VIAL` | 바이알 화면의 「뚜껑 열기」 | 뚜껑 (하드 게이트 1 을 빠져나가는 길) |
| `REMOVE_PAPER` | 실험대 위 단추 | 세워 둔 종이 |
| `DRY_PAPER` | 확대 뷰 | 젖은 종이 (하드 게이트 2 를 피하는 길) |
| `LIFT_RULER` | 확대 뷰 | 대어 둔 자 |

**소모품이 바닥나지 않는다.** 거름종이 통에는 몇 장이든 있다 —
소모품이 바닥나면 그건 결과가 아니라 막다른 길이다.

## 안전 규칙만은 예외

마개·손·폐액은 거름종이에 나타나지 않으므로 결과로 말할 수 없다.
그래서 **기록만 한다.** 감점은 없고, 늦게라도 지키면 위반 기록에서 지워진다
(`rules.js` 의 `safetyAction`).

이 실험의 용매는 **메탄올·아세톤·석유에터**다. 전부 휘발성이고 인화성이라
마개를 닫는 것이 바나나랩보다 더 중요하다.

## 무엇을 어디서 정하는가

| 어디서 | 무엇을 |
|---|---|
| 실험대 | 물건을 집어 옮긴다. 어디에 무엇을 대는가 |
| 확대 뷰 | **결과를 가르는 값** — 원점 높이, 찍는 횟수, 한 번에 대는 시간, 전개액 깊이 |

**변인은 손이 정해야 한다.** 가져다 대기만 하면 알아서 열다섯 번 찍히게 두면,
「몇 번 찍는가」라는 이 실험의 변인이 학생 손을 떠나고 세어 볼 일 자체가 없어진다.
