# 00 · 프로젝트 개요

## 무엇을 만드나

관찰 실험 **「크로마토그래피로 식물의 잎에서 광합성 색소 분리하기」**를 브라우저에서
수행하는 상호작용 시뮬레이터. 실험 id 는 `chromatography`.

교과서 지면:

- 목표 — 잎에 들어 있는 광합성 색소를 크로마토그래피로 분리하고, 전개율을 구할 수 있다
- 문제 인식 — 식물의 잎은 초록 한 가지 색으로 보이는데, 정말 한 가지 색소만 들어 있을까?
- 탐구 과정 — 시금치 잎 + 추출액(메탄올:아세톤 = 3:1) → 흔들어 섞고 층 분리 →
  거름종이 아래에서 2.5 cm 에 원점 긋기 → 모세관으로 상층액 10~20회 찍기 →
  전개액(석유에터:아세톤 = 9:1)에 세우기 → 꺼내 용매 전선 표시 → 거리 재기
- 결과 및 정리 — 색 띠 네 개와 그 순서, 전개율(Rf), 다른 모둠과 비교

## 이것은 종이 크로마토그래피다. TLC 가 아니다

**고치기 전에 `AGENTS.md` §2.5 를 반드시 읽어라.**

교과서가 가르치는 전개율 순서(카로틴 > 잔토필 > 엽록소 a > 엽록소 b)는 **종이(셀룰로스)의
순서**다. 실리카겔 TLC 에서는 잔토필이 맨 아래로 내려간다. 「TLC 판」이라 부르면서 종이
순서의 띠를 그리면 **앱이 일어나지 않는 일을 보여 주는 것**이 된다.

## 왜 만드나

교실에서 이 실험이 실패하는 지점은 정해져 있다.

- 전개액을 흥건히 부어 **원점이 잠긴다** → 색소가 씻겨 나가 띠가 아예 없다
- 모세관으로 몇 번 안 찍어 띠가 흐리다 → 넷을 구별할 수 없다
- 원점을 크게 찍어 띠가 굵다 → 이웃 띠와 겹쳐 보인다
- 너무 늦게 꺼내 전선이 종이 끝을 넘어간다 → **전개율의 분모를 잃는다**
- 원점을 볼펜으로 그어 잉크가 함께 올라간다
- 시든 잎을 쓰거나 뚜껑을 열어 둬서 엽록소가 빛에 파괴된다

그래서 이 시뮬레이터의 목표는 실험을 대신 보여 주는 것이 아니라
**그 실패 지점을 안전하게 반복 경험하게 하는 것**이다.

## 학습 목표 (조작적으로 다시 쓴 것)

1. 초록 한 가지로 보이던 잎에 **적어도 네 가지 색소**가 섞여 있다는 것을,
   자기가 만든 거름종이의 띠를 근거로 설명할 수 있다
2. 띠의 순서가 왜 그렇게 되는지를 색소의 성질(용해도·흡착)과 이어 설명할 수 있다
3. **전개율(Rf)을 자로 재어 스스로 계산**할 수 있다 —
   앱은 정답 Rf 를 갖고 있지 않다. 재는 것과 나누는 것이 이 실험이 가르치려는 바다
4. 원점이 잠기면 안 되는 이유, 연필로 그어야 하는 이유를 실패 경험으로 설명할 수 있다

## 화면 구조

좌측 **실험대(조작 공간)** + 우측 **탐구 노트(절차·기록·평가)** 의 2분할.
결과를 가르는 값(찍는 횟수·원점 높이·전개액 깊이)은 확대 뷰에서 손으로 정한다.

| 영역 | 내용 |
|---|---|
| 실험대 상단 선반 | 시금치 잎, 추출액병, 전개액병, 거름종이 통, 모세관, 연필, 자 |
| 실험대 작업면 | 쓰레기통, 폐액통, 원심관, 거름종이, 바이알, 휴지, 개수대 |
| 확대 뷰 | 색소 추출 / 거름종이 손질 / 전개 — 세 모드 |
| 탐구 노트 | 7단계 탭 + 세부 단계 체크 + 관찰 기록칸 |

## 현미경이 없다 — 이 뼈대의 첫 사례

바나나랩의 `src/sim/optics.js`(광학) 자리에 `src/sim/develop.js`(모세관 상승)가 온다.
결과 렌더러는 현미경 시야가 아니라 **거름종이 위의 색 띠**(`src/render/strip.js`)다.

이 실험이 "뼈대가 현미경 없이도 서는가" 를 검증한다. 서는 것으로 확인됐다 —
그대로 쓴 것은 `reduce()` 삼분법, 되돌리기, 애셋 계약과 린터, 실험대 드래그·어포던스,
탐구 노트 7단계, 검증 층 나누기다. 갈아 끼운 것은 물리·결과 렌더러·규칙표·애셋뿐이다.

## 기술 선택

- 프레임워크 없음. 바닐라 ES 모듈.
- 애셋은 인라인 SVG. 결과는 SVG 절차적 생성.
- 상태는 단일 객체 + 순수 리듀서. `src/sim/` 은 DOM을 모른다.
- 빌드는 Vite. 배포는 Vercel, 결과 보드는 Supabase (07번 문서).
