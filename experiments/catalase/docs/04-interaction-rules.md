# 04 · 조작 규칙 — 강제에서 귀결로

**이 문서가 프로젝트의 핵심이다.**

## 원칙

> **거의 모든 조작을 허용하고, 대신 결과로 답한다.**

막아 버리면 배우는 것은 「정해진 대로 눌러야 넘어간다」뿐이고, 실험하는 느낌도 사라진다.

## 결과 종류는 셋뿐

| outcome | 뜻 |
|---|---|
| `ok` | 진행됐다. 무엇이 바뀌었는지만 말한다 |
| `happened` | 진행됐다. 다만 이런 일이 일어났다 — **대부분 여기** |
| `blocked` | 진행되지 않았다 — **아래 두 사유에만** |

```js
BLOCKING_REASONS = {
  IMPOSSIBLE: 'impossible',  // 물리적으로 성립하지 않음
  BROKEN:     'broken',      // 기구가 파손돼 재제작이 필요함
}
```

이 외의 사유로 `blocked` 를 돌려주면 `rules.js` 의 `blocked()` 헬퍼가 **던진다.**
그리고 `tests/rules.test.js` 가 모든 액션을 여러 상태에서 훑어 다시 검사한다.

### `blocked` 일 때는 빠져나갈 길을 문장에 담는다

「새것을 꺼내세요」로는 **어디서** 꺼내는지 알 수 없다. 어디로 가야 하는지까지 말한다.

> ❌ 비커가 깨졌습니다. 새것을 쓰세요.
> ✅ 비커에 금이 갔습니다. **선반의 비커 통**에서 새것을 꺼내세요.

## 조작표

### 변인 설계

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `SET_INDEPENDENT` | `ok` | 조작변인을 고른다. **바꾸는 것도 막지 않는다** — 앞 시행이 그대로 남아 그래프가 갈릴 뿐이다 |
| `SET_CONTROL` | `ok` | 통제변인의 목표값을 정한다. **실험 도중에 바꿔도 막지 않는다** |
| `DECLARE_DESIGN` | `ok` | 설계를 정했다고 표시한다. **잠금이 아니다.** 안 눌러도 실험은 된다 |

### 감자즙

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `MAKE_EXTRACT {pct}` | `ok` | 감자즙을 만든다. 희석하면 효소가 그만큼 적다 |
| `BOIL_EXTRACT` | `happened` | 끓인다. **식혀도 안 돌아온다.** 이 감자즙으로 만든 원반은 뜨지 않는다 |

> 끓인 감자즙을 되돌리는 길은 **`MAKE_EXTRACT` 로 새로 만드는 것**이다.
> 「식히기」를 두지 않는다 — 식으면 돌아온다고 배우면 이 실험을 거꾸로 배운 것이다.

### 원반

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `PUNCH_DISC` | `ok` | 거름종이를 뚫는다. 지름 약 6 mm. **몇 장이든 뚫을 수 있다** |
| `SOAK_DISC` | `ok` / `happened` | 감자즙에 담근다. 감자즙이 없으면 `happened` — 아무것도 안 묻는다 |
| `PICK_DISC` | `ok` | 핀셋으로 집는다 |
| `DISCARD_DISC` | `ok` | 버린다. 되돌아갈 길 |

**안 담근 원반을 넣는 것을 막지 않는다.** 효소가 없어 안 뜨는 것이 답인데,
**완충하지 않은 pH 11 에서는 그래도 뜬다** — 그것이 이 실험에서 가장 중요한 대조군이다.

### 비커

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `POUR_H2O2 {pct}` | `ok` | 과산화수소수를 붓는다 (1 · 2 · 3 %) |
| `SET_PH {ph, method}` | `ok` / `happened` | 완충 용액 또는 0.1 M 산·염기로 pH 를 맞춘다 |
| `PUT_IN_BATH {tempC}` | `ok` / `happened` | 수조에 넣는다 (0 · 20 · 37 · 60 · 100 ℃) |
| `TAKE_FROM_BATH` | `ok` | 꺼낸다. 실온으로 돌아간다 |
| `EMPTY_BEAKER` | `ok` | 비운다. **되돌아갈 길** |
| `NEW_BEAKER` | `ok` | 선반의 비커 통에서 새것을 꺼낸다. 깨졌을 때의 유일한 길 |

`SET_PH` 를 `method: 'acidbase'` 로 하면 `happened` 로 답한다 —
**pH 를 산·염기로 직접 맞추면 국소적으로 pH 가 훨씬 높은 자리가 생기고 거기서 분해가 몰아친다.**
막지 않는다. 그 결과를 pH 11 에서 보는 것이 이 실험의 배울 것이다.

### 열 충격 — 이 실험의 유일한 파손

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `PUT_IN_BATH` 로 **80 ℃ 넘게 식힘** | `happened` | **비커에 금이 간다.** 실제로 그렇다 |
| 금 간 비커에 붓기·넣기 | `blocked` (`BROKEN`) | 「**선반의 비커 통**에서 새것을 꺼내세요」 |

이것이 이 실험에서 `blocked` 가 나오는 **유일한** 자리다.
금이 가는 것 자체는 `happened` 다 — 진행됐고, 그 결과가 파손이다.

**식힐 때만 걸린다.** 데울 때도 걸리게 두었더니 실온 비커를 100 ℃ 수조에 넣는
**정상 절차가 첫걸음부터 막혔다.** 뜨거운 유리를 찬물에 담그는 쪽만 깨진다.

### 시행

| 액션 | 결과 | 무엇이 일어나는가 |
|---|---|---|
| `DROP_DISC` | `ok` / `happened` | 원반을 비커에 넣는다. 시계가 시작된다 |
| `TICK {seconds}` | `ok` | 시간이 흐른다. 진행도가 1 이 되면 원반이 떠오른다 |
| `RECORD_TRIAL` | `ok` / `happened` | 시행을 기록한다 |
| `DELETE_TRIAL {at}` | `ok` | 기록을 지운다. **관찰을 무르는 것이 아니라 근거를 고르는 일이다** |

**설계와 어긋난 조건이어도 기록된다.** `offDesign` 에 어긋난 통제변인의 이름이 담기고,
그래프에서 선에서 떨어져 나온 점으로 보인다. **막지도, 숨기지도, 지우지도 않는다.**

**아직 안 뜬 채로 기록하는 것도 막지 않는다.** 관찰 시간(300초)을 넘겼으면
「뜨지 않음」으로, 아직 기다리는 중이면 `happened` 로 「아직 안 떴습니다」라고 말한다.

### 안전 — **조작으로 두지 않는다**

바나나랩에는 `WASH_HANDS` · `CLOSE_CAP` · `DISPOSE_WASTE` · `CHECK_TIDY` 가 있었다.
**이 실험에는 없다.** 넷 다 걷어냈다 (선생님 지시, 2026-08-28).

왜 걷어냈는가 — 판정하는 쪽(`CHECK_TIDY` · `NOTE_VIOLATION`)이 **화면 어디서도
불리지 않아서**, 자기 평가가 학생이 무엇을 했든 늘 「지켰습니다」라고 말하고 있었다.
안 하는 판정을 한 척하는 것이 안 하는 것보다 나쁘다.

지금은 **판정하지 않고 적어 두기만 한다.** 안전 안내는 화면에 글로만 있고
(`UI.notebook.valuesLead` · `valuesList`), **2쪽(준비물)** 에 붙는다 —
다 끝낸 뒤가 아니라 **기구를 잡기 전에** 읽을 것이라서다. 보고서에도 같은 글이 실린다.

## 되돌아갈 길 — 새 조작마다 같이 정한다

| 잘못한 것 | 돌아오는 길 |
|---|---|
| 감자즙을 잘못 만들었다 / 끓였다 | `MAKE_EXTRACT` 로 새로 만든다 |
| 원반을 엉뚱한 감자즙에 담갔다 | `DISCARD_DISC` → `PUNCH_DISC` |
| 비커에 엉뚱한 농도를 부었다 | `EMPTY_BEAKER` |
| 비커가 깨졌다 | `NEW_BEAKER` (선반의 비커 통) |
| 시행을 잘못 기록했다 | `DELETE_TRIAL` — ⚠ **규칙에는 있는데 화면에 단추가 없다.** [확인 필요] |

**소모품이 바닥나지 않는다.** 거름종이·비커·감자즙 재료는 세지 않는다 —
바나나랩에서 덮개 유리를 석 장만 두었더니 곧 막혔다.

---

## 되돌리기에 쌓지 않는 것

```js
TRANSIENT_ACTIONS = { TICK, MARK_READ }
```

**시간이 흐르는 것은 학생이 「한」 조작이 아니다.** 이걸 쌓으면 1초마다 도는 `TICK` 이
기록을 밀어내고, 되돌리기 1회짜리 3단계에서는 그 한 번이 `TICK` 을 무르는 데 쓰여 사라진다.
바나나랩에서 실제로 그랬다 — 테스트 90개가 통과하는 상태였다.

```js
CONTINUOUS_ACTIONS = { SET_CONTROL, SAVE_NOTE }
```

슬라이더 한 번 끄는 동안 수십 번 디스패치된다. 앞선 액션이 같은 종류면 새로 쌓지 않는다.
