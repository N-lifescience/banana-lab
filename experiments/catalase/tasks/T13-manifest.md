# T13 — 매니페스트 (`src/manifest.js`)

**상태: 끝남.** 무엇을 왜 그렇게 했는지는 `PROGRESS.md` 의 같은 번호 절에 있다.

**5분이고 화면에 안 쓰이는 파일이라 잊기 쉬운데, 합칠 때 이게 없으면 사람이 되짚어 써야 한다.**
실험을 다 만들고 나서 값만 채운다.

## 채울 여섯

| 칸 | 이 실험의 값 |
|---|---|
| `id` | `catalase` — **주소가 되고 한 번 정하면 못 바꾼다.** 교사가 만든 링크가 학습지에 인쇄돼 나간다 |
| `summary` | 카드 한 문장. **결과를 적지 않는다** — 목록 화면이 답을 먼저 말하면 안 된다 |
| `skeleton` | 뼈대 |
| `levels` | 난이도 세 단계 |
| `modes` | 혼자 / 모둠 |
| `curriculum` | **목록이다.** 같은 실험이 여러 교과서에 나온다 |

## `curriculum` 에 대해

교과서마다 시뮬레이터를 새로 만들지 않고 **여기에 한 줄을 늘린다.**

**쪽수를 모르면 `null` 로 둔다.** 지어낸 쪽수는 없는 쪽수보다 나쁘다 —
교사가 그 쪽을 펴 보고 나서야 틀린 것을 안다.

## `summary` 에 쓰면 안 되는 말

> ❌ 「37 ℃ 에서 가장 빨리 떠오르는 것을 확인한다」 — **답을 먼저 말한다**
> ✅ 「감자즙 원반이 과산화수소수에서 떠오르는 시간으로 효소에 영향을 주는 요인을 찾는다」

## 합격 기준

- [ ] 여섯 칸이 다 차 있다
- [ ] `id` 가 `catalase` 이고, 교과 접두사(`bio1-`)가 붙어 있지 않다
- [ ] `summary` 에 결과(37 ℃ · pH 7 · 안 뜬다)가 들어 있지 않다
- [ ] 모르는 쪽수가 `null` 이다. **지어낸 숫자가 없다**
- [ ] `node --test tests/manifest.test.js` 통과

## 검증 명령

```bash
node --test tests/manifest.test.js
npm run check
```
