# T03 — 결과 렌더러: 비커와 떠오르는 원반

**상태: 끝남.** 무엇을 왜 그렇게 했는지는 `PROGRESS.md` 의 같은 번호 절에 있다.

바나나랩은 현미경 시야(`src/render/fov.js`)였다. 이 실험의 결과는 **비커 안에서 원반이
떠오르는 그림**이다. `fov.js` 를 지우고 `src/render/beaker.js` 를 만든다.

## 지켜야 할 것

**상태를 받아 그림을 내는 순수 함수여야 한다.** 같은 상태를 주면 같은 그림이 나온다
(난수는 `seed` 로 받는다). 그래야 나중에 결과를 저장해 두었다가 탐구 노트와 보고서에서
되살릴 수 있다.

**`idPrefix` 를 처음부터 인자로 받는다.** 한 화면에 비커를 여러 개 그리는 순간
(시행 비교·결과 보드) `id` 가 하드코딩이면 **에러 없이 조용히** 틀린다.
바나나랩에서 물린 자리다 — 미리 받아 둔다.

## 그림에 들어가는 것

| 무엇 | 어디서 오는가 |
|---|---|
| 비커와 과산화수소수 액면 | 상태 |
| 수조와 온도 표시 | 상태 |
| **원반의 높이** | `riseProgress(conditions, elapsedS)` — 0 이면 바닥, 1 이면 액면 |
| 원반에 붙은 기포 수 | 같은 진행도. 늘어나다가 떠오르는 순간 가장 많다 |
| **원반을 넣기 전 비커 안의 거품** | `preFizz(conditions)` — 완충 안 한 pH 11 에서 1.00 |

마지막 줄이 중요하다. **효소가 없는데도 거품이 이는 것**을 학생이 눈으로 먼저 만나야
「왜 pH 11 이 더 빨랐지?」를 스스로 물을 수 있다. 이걸 안 그리면 결과만 이상해 보인다.

## 안 뜨는 조건을 어떻게 그리나

`riseTime()` 이 `floated: false` 를 돌려주는 조건(100 ℃ · pH 3 · 끓인 감자즙)은
**원반이 바닥에 그대로 있고 기포가 거의 없는 그림**이다. 「실패」 표시를 붙이지 않는다 —
안 뜨는 것도 결과이고, 그 결과가 효소가 죽었다는 뜻이다.

## 합격 기준

- [ ] `renderBeaker(params, { idPrefix })` 가 순수 함수다. 같은 입력 → 같은 SVG 문자열
- [ ] `src/sim/` 을 import 해서 값을 받고, 스스로 물리를 계산하지 않는다
- [ ] 반응색은 `palette.experiment.js` 에서만 온다
- [ ] 한 화면에 두 개를 그려도 `id` 가 부딪히지 않는다 (테스트로 못 박는다)
- [ ] 100 ℃ · pH 3 · 끓인 감자즙에서 원반이 바닥에 있다
- [ ] 완충 안 한 pH 11 에서 원반을 넣기 전에 기포가 보인다
- [ ] 하네스의 `#result-slot` 이 채워지고 `stagePending` 문구가 사라졌다
