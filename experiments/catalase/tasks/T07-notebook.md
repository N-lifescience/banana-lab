# T07 — 탐구 노트 7단계

**상태: 끝남.** 무엇을 왜 그렇게 했는지는 `PROGRESS.md` 의 같은 번호 절에 있다.

7단계 뼈대(문제 인식 · 준비물 · 예상 · 탐구 과정 · 결과 · 정리 · 자기 평가)는 **그대로 쓴다.**
`src/ui/strings.js` 를 갈아 끼우면 대부분 따라온다.

**7단계 구조를 조작 절차로 납작하게 만들지 않는다.** 바나나랩에서 실제로 그렇게 했다가
되돌렸다 — 탐구 노트는 「다음에 무엇을 누를까」가 아니라 「무엇을 왜 하려는가」다.

## 갈아 끼울 것

| 자리 | 무엇 |
|---|---|
| `appTitle`, `start.levels` | 실험 이름과 단계 설명 |
| `bench.items`, `bench.shortNames`, `bench.hints` | 물건 이름과 단계별 안내 |
| `notebook.protocol` | STEP 과 세부 단계 |
| `notebook.materials` | 준비물 표 |
| `notebook.predictOptions`, `predictWhyPlaceholder`, `predictFreePlaceholder` | 예상 |
| `notebook.q2Label`, `q3Label` | 정리 서술형 |
| `report.*` | 보고서 |

`selfEvalItems`(리커트 5점)와 `reflectionItems`(느낀 점)는 실험과 무관하다. **그대로 둔다.**

## 준비물 표에 반드시 들어갈 것

**농도를 정확히 적는다.** 이 표를 보고 교사가 준비한다.

- 3 % 과산화수소수
- 감자즙 (감자를 갈아 거른 것)
- 거름종이, 펀치 (지름 약 6 mm 원반)
- **완충 용액 pH 3 · 5 · 7 · 9 · 11**
- 산·염기를 그대로 쓴다면 **0.1 M 염산 · 0.1 M 수산화 나트륨**.
  **10 % 는 적지 않는다** — 10 % NaOH 는 GHS 피부 부식성 1A 다 (`AGENTS.md` §2.5)
- 수조 (0 · 20 · 37 · 60 · 100 ℃), 얼음
- 비커, 핀셋, 초시계

## 물린 함정

1. **빈칸에 첨삭을 띄우지 않는다.** 쓰기도 전에 부족하다는 말부터 듣는다
2. **화면이 채점하는 답을 먼저 적어 두지 않는다.** 바나나랩은 배율을 묻는 칸 **바로 위에**
   총배율을 적어 두고 있었다. 여기서는 「최적 온도는?」 옆에 37 ℃ 를 띄우지 않는다
3. **같은 예시 문구를 여러 칸에 걸지 않는다.** 학생은 그 한 문장을 베낀다.
   `tests/ui.contract.test.js` 가 칸마다 다른지 본다

## 합격 기준

- [ ] 7단계가 그대로 있고, 조작 절차로 납작해지지 않았다
- [ ] 예시 문구가 **칸마다 전부 다르다**
- [ ] 준비물 표의 농도가 `AGENTS.md` §2.5 와 같다. **10 % 가 어디에도 없다**
- [ ] 화면 어디에도 정답(37 ℃ · pH 7)이 학생이 답하기 전에 적혀 있지 않다
- [ ] 개인정보 칸이 없다 (`tests/roadmap.test.js` 가 본다)
- [ ] 화면에 보이는 한국어가 전부 `strings.js` 에 있다
