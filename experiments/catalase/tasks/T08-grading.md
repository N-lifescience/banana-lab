# T08 — 서술형 채점: 소재 목록과 바깥 문장

**상태: 끝남.** 무엇을 왜 그렇게 했는지는 `PROGRESS.md` 의 같은 번호 절에 있다.

**비용은 비대칭이다. 맞는 답을 부족하다고 하는 쪽이 훨씬 비싸다.**
아무것도 점수 매기지 않고 막지도 않으므로, 느슨해서 생기는 손해는 거의 없고
빡빡해서 생기는 손해는 **학생이 글쓰기를 그만두는 것**이다.

## 어떻게 짜는가

- **소재(subject)** 로 본다 — 「효소」·「변성」·「산소」처럼 있어야 할 것이 들어 있는가
- 길이는 문장 수가 아니라 **공백 뺀 글자 수**로 잰다
- 「왜냐하면」 같은 **깊이 단어는 힌트일 뿐** 판정 근거로 쓰지 않는다
- 결과는 `pass` / `more` / `unavailable` 셋. **틀렸다는 판정은 없다**

## 이 실험의 소재 목록에 들어갈 것

문항마다 다르지만, 학생이 실제로 쓸 말을 넉넉히 받아야 한다.

| 개념 | 학생이 쓸 만한 말 |
|---|---|
| 효소 | 효소 · 카탈레이스 · 촉매 |
| 기질 | 과산화수소 · 과산화수소수 · H2O2 |
| 산물 | 산소 · 기포 · 거품 · 물 |
| 변성 | 변성 · 죽었 · 파괴 · 망가 · 구조가 바뀌 |
| 최적 조건 | 최적 · 가장 빠르 · 잘 일어나 |
| 변인 | 조작변인 · 통제변인 · 종속변인 · 같게 · 다르게 |

**「끓였더니 안 떴다」처럼 용어 없이 관찰만 쓴 답을 부족하다고 하지 않는다.**
관찰을 정확히 쓴 것은 그 자체로 답이다.

## 검사는 반드시 바깥에서 만든 문장으로

**구현한 사람이 자기 키워드 목록을 보고 만든 테스트는 아무것도 검증하지 못한다.**
바나나랩에서 실제로 겪었다 — 전체 테스트 99개가 통과하는 상태에서, 바깥에서 새로 쓴
학생 문장 9개 중 6개가 「부족하다」 판정을 받았다. **전부 거짓 부정이었다.**

→ 채점 로직을 **안 본** 세션(또는 사람)이 학생 답안을 써서 `tests/grading.holdout.test.js`
를 만든다. 서브에이전트에 맡길 때 `src/ui/grading.js` 를 **읽지 말라고 명시한다.**

## 합격 기준

- [ ] `pass` / `more` / `unavailable` 셋뿐. 「틀렸다」가 없다
- [ ] 빈칸에는 아무 말도 뜨지 않는다
- [ ] 바깥에서 쓴 학생 문장 **최소 12개** 중 거짓 부정이 0 이다
- [ ] 용어 없이 관찰만 쓴 답이 `pass` 다
- [ ] 소재 목록이 `strings.js` 가 아니라 채점 모듈 한 곳에 있다

## 검증 명령

```bash
node scripts/check-grading.mjs
node --test tests/grading.holdout.test.js
npm run check
```

되돌려서 확인할 것: 소재 목록에서 「변성」을 빼면 홀드아웃 문장 중 **몇 개가 실제로
떨어지는지** 본다. 하나도 안 떨어지면 그 목록은 아무 일도 안 하고 있는 것이다.
