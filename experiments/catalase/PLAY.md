# 플레이 점검표 — 이것만 하시면 됩니다

기계가 볼 수 있는 것은 전부 검사로 돌려 놨습니다 (`npm run check` 229개 · 화면 26가지 ·
배포본 25가지). **기계가 못 보는 것만** 여기 남깁니다 — 어색한가, 헷갈리는가, 말이 되는가.

```bash
npm run dev
```

→ **http://localhost:5173/experiments/catalase/**

이상한 것을 찾으시면 **어느 줄에서 그랬는지만** 적어 주세요. 고치는 건 저희가 합니다.

## 1. 처음 열었을 때 (2분)

- [ ] 시작 화면에서 **1단계 · 모둠**을 골라 들어간다
- [ ] 실험대가 **잠겨 있고**, 왜 잠겼는지 화면이 말해 준다
- [ ] 탐구 노트 **1·2·3·4 쪽**을 열고 맨 밑 「이 쪽을 읽었습니다」를 누른다
- [ ] 네 쪽을 다 읽으면 자물쇠가 걷힌다

> **볼 것**: 2쪽 준비물 표의 그림이 실험대에 놓인 것과 같아 보이나요?
> 노트에서 본 것을 실험대에서 알아볼 수 있어야 합니다.

## 2. 설계하고 한 번 재기 (3분)

- [ ] 오른쪽 「실험 설계」에서 **온도**를 고른다
- [ ] 통제변인 칸이 바뀌는 것을 본다 (수조 온도가 목록에서 빠짐)
- [ ] 「이대로 실험하기」를 누른다
- [ ] 실험대에서: **거름종이** 클릭 → **핀셋**을 감자즙 100 % 로 끌기 →
      **과산화수소수 3 %** 를 비커로 → **비커**를 37 ℃ 수조로 → **핀셋**을 비커로
- [ ] 위쪽 관찰 창에서 기포가 붙고 원반이 떠오르는 것을 본다 (약 8초, 화면은 ×5 배속)
- [ ] **초시계**를 클릭해 기록한다

> **볼 것**: 물건에 마우스를 올렸을 때 뜨는 말풍선이 **무엇을 하라는 건지** 알려 주나요?
> 「이거 어떻게 하는 거지?」가 한 번이라도 들면 그 물건 이름을 적어 주세요.

## 3. 조건을 바꿔 두 번 더 (3분)

- [ ] **비커 → 폐액통**으로 비우고, 20 ℃ 로 한 번 (약 25초)
- [ ] 다시 비우고 **0 ℃** 로 한 번 (약 100초 — 화면으로는 20초)
- [ ] 탐구 노트 **5. 결과**에서 그래프에 점 셋이 이어진 것을 본다

> **볼 것**: 그래프가 「온도가 오르면 빨라진다」를 눈으로 말해 주나요?

## 4. 일부러 틀려 보기 — 여기가 이 실험의 핵심입니다 (5분)

- [ ] **통제변인 어기기**: 비커를 비우고 **과산화수소수 1 %** 로 20 ℃ 를 잰다
      → 그래프에서 그 점이 **선에서 떨어져 나오고**, 밑에 무엇이 어긋났는지 이름이 뜨는가
- [ ] **끓는 물**: 100 ℃ 수조에서 재 본다 (5분을 기다리기 싫으면 60 ℃ 로 먼저 → 100 ℃)
      → 아무리 기다려도 안 뜨고, 「뜨지 않음」으로 기록되는가
- [ ] **끓인 감자즙**: 오른쪽 끝 「끓인 감자즙」에 원반을 담가 37 ℃ 에서 재 본다
      → 안 뜨는가. 그래프에서 떨어져 나오는가
- [ ] **효소 없이도 뜨는 것**: 비우고 → **묽은 수산화 나트륨**을 비커에 →
      원반을 **감자즙에 안 담그고** 그대로 넣는다
      → **원반을 넣기 전부터 거품이 일고**, 감자즙 없이도 원반이 뜨는가 (약 15초)

> **볼 것**: 마지막 것이 이 실험에서 가장 중요합니다.
> 「효소가 없는데 왜 떴지?」라는 생각이 드나요? 그게 안 들면 화면이 덜 말한 것입니다.

- [ ] **비커 깨뜨리기**: 100 ℃ 수조에 넣었다가 곧바로 **0 ℃** 로 옮긴다
      → 금이 가고, **어디서 새 비커를 꺼내는지**까지 말해 주는가
      → 선반의 **비커 통**에 끌어다 대면 풀리는가

## 마우스 없이 한 번만 해 보실 수 있으면

**손을 마우스에서 떼고** 실험대에서 `Tab` 만 눌러 비커까지 간 다음, 거기서 한 번 더 `Tab`.
「여기에 놓기」 버튼으로 들어가면 정상입니다. `Enter` 로 놓아지고, `Esc` 로 말풍선을 치웁니다.

이걸 따로 적는 이유는 — **어젯밤까지 그 버튼에 닿을 방법이 아예 없었기 때문입니다.**
버튼은 화면에 떠 있었고 눌리기도 해서 검사는 통과하고 있었는데, 검사가 버튼을 직접
눌러 보는 방식이라 **거기까지 갈 수 있는지는 아무도 안 재고 있었습니다.**
Tab 을 여든 번 눌러 보고 알았습니다. 마우스를 못 쓰는 학생에게는 그 버튼이
실험을 시작하는 유일한 길입니다.

지금은 검사가 진짜로 키를 누릅니다. 그래도 사람 손으로 한 번 확인해 주시면 좋겠습니다.

- GitHub `N-lifescience/catalase-lab` (비공개)에 **push 했습니다** — 커밋 17개, 전부 계정에 연결됨
- **키보드로 실험을 시작할 수 없던 것을 고쳤습니다** (위 항목 — 놓기 버튼에 닿는 길이 없었습니다)
- 말풍선을 두고 마우스와 키보드가 다투던 자리 다섯 곳을 고쳤습니다.
  그중 하나는 **키보드로 한 번 조작하면 그 뒤로 아무것도 못 하게** 되는 것이었습니다
- **학생 화면에 붙어 있던 개발용 링크를 뗐습니다.** 그래프 아래 맨 끝에
  「탐구 노트와 보고서는 아직 만들지 않았습니다」(사실이 아닙니다)와 개발 도구로 가는
  링크가 남아 있었습니다. 화면 맨 아래라 아무도 못 봤습니다
- **태블릿(손가락)으로도 되는지 처음으로 재 봤습니다.** 됩니다 — 누르기도 끌기도.
  그전까지 검사가 전부 마우스·키보드여서 아무도 안 재고 있었습니다
- **끌어다 놓기에 검사가 하나도 없었습니다.** 이 실험의 주 조작인데, 놓기 코드를 끊어도
  검사 57가지가 전부 초록불이었습니다. 지금은 잡힙니다
- 다른 실험 세션 셋(banana · chromatography · osmosis)에 같은 문제를 알렸습니다 —
  물려받은 파일이라 사본 전부에 같은 자리가 있습니다. 두 곳은 이미 고쳤다고 회신했습니다
- 화면 검사가 26 → 55가지로 늘었습니다. 늘어난 것은 **진짜로 키를 누르고 손가락으로 누르는** 검사입니다

- **조작할 때마다 무엇을 했는지 화면이 말해 줍니다.** 그동안 서른 개가 쓰여 있고도
  한 번도 안 나오고 있었습니다 — 「원반이 떠올랐습니다, 8.2 초」까지 포함해서요
- 탐구 과정을 한 번에 한 STEP 씩 보이게 했습니다 (위 항목)
