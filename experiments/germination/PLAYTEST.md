# PLAYTEST.md — 직접 플레이해서 볼 것

**검사가 초록불이어도 여기서 걸리는 것이 있습니다.** 이 저장소에서도 그랬습니다 —
검사가 전부 통과하는 동안 **숟가락이 손에 안 잡혔고**(그림이 납작해서), 센서 손잡이가
탐침을 통째로 가려 **지금 콩에 닿았는지가 안 보였습니다.** 둘 다 콘솔 에러가 한 줄도
없었습니다.

## 띄우기

```bash
npm run dev
```

- 앱 — http://localhost:5173/experiments/germination/
- 애셋 손잡이 — http://localhost:5173/experiments/germination/harness.html
- 배치 편집 — http://localhost:5173/experiments/germination/?edit=1 (또는 아무 화면에서 **Ctrl+P**. 배포본에서도 됩니다)
- 2·3단계 — `?level=2` · `?level=3`
- 선생님 화면 — http://localhost:5173/teacher?exp=germination

**앱을 열면 실험대가 아니라 「시작 화면」이 먼저 나옵니다.** 난이도(1·2·3단계)와
방식(혼자 / 모둠)을 고르고 맨 아래 「**1단계로 시작하기**」를 눌러야 실험이 열립니다.
아무것도 안 골라도 1단계·모둠으로 잡혀 있으니 그냥 누르시면 됩니다.
`?level=2` 처럼 단계를 주소로 주면 **이 화면은 건너뜁니다.**

**「Port 5180 is already in use」가 뜨면** 남은 서버가 있는 것입니다:

```bash
kill $(lsof -t -nP -iTCP:5180 -sTCP:LISTEN)
```

## 이 실험이 무엇인가 — 한 줄

바이오챔버 **두 개**에 발아 중인 콩과 마른 콩을 **같은 양** 넣고 밀봉해, 어느 쪽에서
이산화 탄소와 온도가 더 크게 변하는지 봅니다. 배우는 것은 「발아 콩이 더 변한다」가
아니라 **무엇을 같게 두어야 그 말을 할 수 있는가** 입니다.

**시간은 실제보다 빠르게 흐릅니다 — 화면의 1초가 1분입니다.** 30분까지 잽니다.

## 1. 정상 경로 — 이대로 하면 좋은 결과가 나와야 합니다

탐구 노트 1~4 쪽을 열고 맨 아래 「이 쪽을 읽었습니다」를 눌러야 실험대가 열립니다.

| # | 하는 일 | 이래야 정상 |
|---|---|---|
| 1 | **숟가락**을 「발아 콩」 통으로 끌기 | 숟가락에 싹 난 콩이 담긴다 |
| 2 | **숟가락**을 **왼쪽 챔버**로 끌기 | 챔버 바닥에 콩이 쌓이고, 「1숟갈」이라고 말해 준다 |
| 3 | 1~2 를 한 번 더 (왼쪽 **2숟갈**) | |
| 4 | **숟가락** → 「마른 콩」 통 → **오른쪽 챔버**, 두 번 (오른쪽 **2숟갈**) | 오른쪽 콩은 **갈색이고 싹이 없다** |
| 5 | **BTB 병**을 왼쪽 챔버로, 오른쪽 챔버로 | 두 챔버 바닥 접시가 **파랗게** 찬다 |
| 6 | **왼쪽 센서**를 왼쪽 챔버로 끌기 | 꽂히면서 **확대 뷰가 열린다** |
| 7 | 확대 뷰에서 「**뚜껑 닫아 밀봉하기**」 → 「**측정 시작**」 → Esc | |
| 8 | **오른쪽 센서**로 같은 일 | |
| 9 | **10초쯤 기다리며 지켜보기** | 맨 윗줄에 「재는 중 — 왼쪽 N분 · 오른쪽 N분 (화면의 1초가 1분입니다)」이 뜨고, **1초에 1분씩 올라간다** |
| 9-2 | 그대로 **30초까지** 두기 | 30분을 다 채우면 **저절로 멈춥니다** — 아래를 보세요 |
| 10 | 왼쪽 챔버를 **클릭** | 큰 그림이 뜬다 |
| 11 | 「**두 챔버 결과 기록**」 → Esc | **한 챔버에서 눌러도 두 챔버가 함께 기록됩니다** — 대조가 그래야 성립합니다 |
| 12 | 실험대의 **폐액통 · 쓰레기통**을 한 번씩 클릭 | 「실제 실험에서는 …합니다. **이 앱은 그것을 확인하지 않습니다**」라고 말해 준다 |
| 13 | **탐구 노트 4쪽**에서 STEP 1 의 관찰 기록을 적기 | 적는 즉시 **STEP 2 가 열린다** (한 칸씩만 열립니다) |
| 14 | STEP 5 의 관찰 기록 두 칸을 적고 손 떼기 | **STEP 5 가 접히지 않는다.** 그 밑의 질문 ⓐ 가 아직 비어 있기 때문입니다 — ⓐ 까지 적어야 STEP 6 이 열립니다. 두 칸만 적었는데 접히면 버그입니다 |

**30초를 다 기다리면 이렇게 됩니다 — 고장이 아닙니다.**

관찰 시간은 **30분**이고 화면의 1초가 1분이므로, **측정 시작을 누르고 30초가 지나면
그 챔버는 스스로 멈춥니다.** 그때 세 가지가 한꺼번에 일어나는데 셋 다 정상입니다.

- 맨 윗줄의 「**재는 중 — …**」에서 **끝난 쪽이 빠집니다.** 둘 다 끝나면 줄이 통째로 사라집니다
- **초록** 말풍선이 뜹니다 — 「왼쪽 챔버가 관찰 시간(30분)을 다 채워 측정을 멈췄습니다.
  다시 시작할 수도, 개수대에서 비우고 처음부터 할 수도 있습니다.」
  (한동안 **빨갛게** 떴습니다. 제대로 끝낸 학생이 「내가 뭘 틀렸나」부터 찾는 자리라 초록으로
  바꿨습니다 — `PLAYTEST-REVIEW.md`. **빨갛게 뜨면 버그입니다**)
- 숫자는 그 자리에 **멈춘 채로 남습니다.** 10·11 은 멈춘 뒤에 해도 똑같이 됩니다

재는 **동안**을 보시려면 8 을 마치고 **10초쯤** 뒤에 10·11 을 하세요. 그러면 30분에
닿기 전이라 「재는 중」 줄이 살아 있고, 왼쪽만 숫자가 빠르게 오르는 것이 보입니다.

**여기서 봐야 할 것**

- 실험대의 **두 챔버 그림만 보고도** 어느 쪽이 더 변했는지 알 수 있는가
- **왼쪽 BTB 가 파랑 → 녹색 → 노랑**으로 가는가. **오른쪽은 파랑에 남는가**
- **왼쪽 온도계 기둥만** 눈에 띄게 오르는가
- 확대 뷰의 읽는 값에 「**눈으로**」와 「**센서로**」 꼬리표가 갈려 붙어 있는가
- 탐구 노트 「5. 결과」에 **두 챔버가 나란히** 실리고, 그 아래 그래프가 나오는가
- 그래프에 **「BTB 노랑」·「BTB 녹색」 눈금**이 그어져 있는가
  (그림과 그래프를 잇는 선입니다)
- 결과 설명이 「**콩의 상태만 다르고 나머지는 같습니다**」라고 말하는가

## 2. 실패 경로 — **막히지 않고 결과가 답해야** 합니다

하나씩 일부러 틀려 보세요. **막히면 그게 버그입니다.**

| 일부러 틀리기 | 이래야 정상 |
|---|---|
| **밀봉하지 않고** 측정 시작 | 진행되고, CO₂ 가 **낮은 값에서 이내 평평해진다.** 0 이 되는 것이 아니다 |
| 재는 **도중에 뚜껑 열기** | 곡선이 그 자리에서 **꺾여 내려온다.** 수직으로 뚝 떨어지면 버그다 |
| 확대 뷰에서 센서 손잡이를 **콩 속까지 끌어내리기** | 진행되고, **그래프가 톱니처럼 튄다.** 언제나 **위로만** 튀어야 한다 |
| 한쪽에만 **한 숟갈 더** 넣기 | 결과가 「**콩의 양이 두 챔버에서 다릅니다 — 왼쪽 2숟갈 · 오른쪽 3숟갈**」이라고 **값까지** 말한다 |
| **한쪽에만** BTB 넣기 | 안 넣은 챔버는 **색 칸이 아예 없다.** 「투명」이 아니라 없는 것 |
| **BTB 를 아예 안** 넣고 재기 | 색은 없어도 **그래프는 쌓인다** |
| **센서 없이** 밀봉하고 재기 | 그래프는 안 쌓이지만 **BTB 색과 온도계는 변한다** (센서는 재는 도구일 뿐) |
| **두 챔버에 같은 콩** 넣기 | 「같은 것을 두 번 잰 것이라 견줄 것이 없습니다」 |
| 한 챔버에 **두 종류를 섞어** 넣기 | 「그 챔버의 변화가 **어느 쪽 콩 때문인지 말할 수 없습니다** — 개수대에 대어 비우고 다시 담으세요」 |
| **콩 없이** 밀봉하고 재기 | 대기 농도에서 **아무 일도 안 일어난다** |
| 콩을 **가득**(6숟갈) 넣고 센서 꽂아 두기 | 콩이 쌓여 **센서가 파묻히고**, 그때 말해 준다 |
| 한쪽만 **오래** 재기 | 「잰 시간이 다릅니다 — 왼쪽 N분 · 오른쪽 M분」. **1분 차이까지는 말하지 않습니다** — 두 챔버를 차례로 시작하면 그만큼은 늘 어긋나서, 제대로 한 학생에게까지 붙던 말입니다 |
| 어긋난 채로 **결과 기록** | 그대로 기록되고, 탐구 노트 6쪽에 **무엇이 어긋났는지 짚는 자리**가 생긴다 |

**어느 것도 막히면 안 됩니다.** 결과가 대신 말해야 합니다.

## 3. 막혀야 하는 것은 **하나뿐**입니다

| 하는 일 | 이래야 정상 |
|---|---|
| **뚜껑을 닫은 채로** 콩·BTB·센서를 챔버에 넣기 | 막히고, 「**챔버를 클릭해 확대 뷰를 열고 「뚜껑 열기」를 누르세요**」 |
| **뚜껑을 닫은 채로** 센서 빼기 | 위와 같은 문장 |

**센서 빼기는 실험대에서 하는 것이 아닙니다.** 챔버에 꽂은 센서는 선반에서 사라지므로
끌어낼 것이 없습니다 — **챔버를 클릭해 확대 뷰를 열고 아래쪽 「센서 빼기」**를 누르세요.
(그래서 위 두 번째 줄은 「밀봉한 뒤 챔버를 클릭 → 「센서 빼기」」로 해 보시면 됩니다.)

**막는 문장이 「어디를 눌러야 하는지」까지 말하는지** 봐 주세요. 그게 이 앱의 규칙입니다.
「뚜껑을 여세요」로 끝나면 버그입니다.

기구가 깨지는 일은 이 실험에 **없습니다.** 억지로 만들지 않았습니다.

## 4. 되돌아갈 길이 다 열려 있는가

| 잘못한 것 | 돌아오는 길 |
|---|---|
| 콩을 섞었다 · 양을 잘못 넣었다 | 챔버를 **개수대**로 끌기 → 비우고 처음부터 |
| 숟가락에 잘못 담았다 | **다른 통**에 다시 대면 바뀐다 |
| 센서를 콩에 파묻었다 | 확대 뷰에서 손잡이를 **위로** 끌기 (손잡이는 챔버 그림의 **왼쪽**에 붙은 작은 단추입니다 — 가운데에 두면 탐침을 가려서 닿았는지가 안 보입니다) |
| 파묻은 센서를 뺐더니 부스러기가 묻었다 | 센서를 **휴지**로 끌기 |
| 밀봉을 잊었다 | 확대 뷰에서 뚜껑 닫고 다시 시작 |
| 관찰 시간(30분)을 다 썼다 | 「측정 시작」을 다시 누르거나 개수대에서 비우기 |
| 기록을 잘못 남겼다 | 탐구 노트 5쪽에서 「이 기록 지우기」 |

**막다른 길이 하나라도 있으면 버그입니다.**

## 5. 손이 아닌 것으로도 되는가

- **키보드만으로 끝까지**: Tab 으로 물건에 가면 말풍선에 「여기에 놓기」 단추가 나옵니다.
  거기서 **한 번 더 Tab 하면 그 단추로 들어가야** 하고, Enter 로 실제로 놓여야 합니다.
  **마우스를 한 번도 안 쓰고** 처음부터 끝까지 해 보세요
- **센서 깊이도 키보드로**: 확대 뷰에서 손잡이에 Tab 으로 간 뒤 **↑ ↓** 를 눌러 보세요.
  이 실험에서 손끝이 정하는 **유일한 값**이라, 여기가 막히면 마우스를 못 쓰는 학생은
  실험을 아예 할 수 없습니다
- **센서 손잡이를 끝까지**: ↑(또는 ↓)를 **끝에 닿고도 스무 번 더** 눌러 보세요.
  값은 그대로여도 **왜 안 움직이는지 말해 줘야** 합니다. 아무 말이 없으면 학생은 고장으로 읽습니다
- **탐구 노트의 글칸도 키보드로**: 3쪽 예상 칸에서 **Tab 으로 다음 칸으로 옮겨 가며** 쳐 보세요.
  **칸마다 제 글이 남아야** 하고, **손이 그 칸에 그대로 있어야** 합니다.
  마우스로 옮기면 안 보이는 자리라, **반드시 Tab 으로만** 해 보셔야 합니다
- **다 적고 곧장 단추로**: 마지막 칸에 적은 **그 손 그대로** 「이 쪽을 읽었습니다」를 누르세요.
  **한 번에 넘어가야** 합니다 — 두 번 눌러야 넘어가면 그건 고장입니다
- **확대 뷰**: Enter 로 열고 **Esc** 로 닫힙니다. 닫은 **직후에 바로 다른 물건이 집히는지**
- **다크 모드**: 시스템을 다크로 바꾸고 **BTB 세 색이 다 구별되는지**
- **색 없이도 읽히는가**: 화면을 흑백으로 보거나 눈을 가늘게 뜨고,
  그래프에서 **왼쪽(실선)과 오른쪽(점선)**이 갈리는지. 선 끝에 이름이 붙어 있어야 합니다
- **좁은 화면**: 창을 줄이거나 폰 가로 모드에서 확대 뷰의 아래쪽 단추에 손이 닿는지
- **인쇄**: 보고서를 만들어 「PDF로 저장」 해 보세요.
  **두 챔버가 종이에서도 나란히** 있어야 합니다 (위아래로 쌓이면 견줄 수가 없습니다)

## 6. 난이도

`?level=2` · `?level=3` 으로 열어 보세요.
**할 수 있는 일은 1단계와 똑같아야** 합니다 — 달라지는 것은 설명뿐입니다.

| | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 말풍선 | 문장 | 짧은 구 | **이름만** |
| 어긋났을 때 | 원인 + 다음 행동 | 원인만 | 원인 숨김 |
| 예상 | 보기에서 고르기 | 보기 + 까닭 쓰기 | 빈칸에 직접 |
| 탐구 과정 | 다음 할 일 강조 | 목록만 | **목표만** |
| 되돌리기 | 무제한 | 3회 | 1회 |

**못 하게 된 조작이 하나라도 있으면 버그입니다.**
다만 **막히는 이유는 3단계에서도 그대로 보여야** 합니다 — 막힌 채로 이유를 모르면
빠져나올 길이 없습니다.

## 7. 수치를 의심해 주세요 — **여기가 가장 확실하지 않은 곳입니다**

파일 안에 `[확인 필요]` 로 표시해 두었습니다.

- 30분에 발아 콩 2숟갈 → **약 2 800 ppm · +1.7 ℃** 로 나옵니다.
  **교실에서 실제로 재 보신 값과 많이 다르면 알려 주세요** — 고칠 곳은 그 파일의
