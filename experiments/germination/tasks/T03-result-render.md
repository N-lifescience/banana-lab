# T03 — 결과 화면: 챔버 그림이 몸통, 그래프가 보조

## 왜 이 순서로 적는가

교과서는 무선 CO₂ 센서로 재는 **디지털 활동**이다. 그대로 옮기면 그래프 뷰어가 된다.
그래서 결과를 **두 그림 나란히**로 만든다.

1. **챔버 그림** — 안의 BTB 색이 변하고 온도계가 오른다. 두 챔버를 나란히 놓는다
2. 그 아래 **그래프** — CO₂(ppm)와 온도(℃)의 시간 곡선

그림이 몸통이다. 그래프가 없어도 어느 쪽이 더 변했는지 눈으로 알 수 있어야 한다.

## 만들 파일

### `src/render/chamber.js`

`renderChamber(view, { idPrefix })` — **순수 함수**. 같은 상태면 같은 그림이 나온다.
`view` 는 `state.js` 가 만들어 주는 값 한 벌이다 (렌더러가 상태를 직접 뒤지지 않는다).

- BTB 색은 **3단계로 양자화**한다 (파랑·녹색·노랑). 연속 보간하면 두 챔버가 비슷해 보인다
- BTB 를 안 넣었으면 색 칸이 아예 없다 — 「투명」이 아니라 **없는 것**이다
- 온도계는 눈금과 함께 그린다. 숫자를 읽는 것이 아니라 **높이를 견주는 것**이 목적이다
- 센서가 콩에 파묻혔으면 그림에서도 파묻혀 보인다

### `src/render/graph.js`

`renderGraph(chambers, { idPrefix })` — **순수 함수**, `idPrefix` 를 받는다
(보고서가 한 화면에 여러 개를 그린다).

- 가로축 = 경과 시간(분). 세로축 둘 — CO₂(ppm)와 온도(℃)를 **위아래 두 칸**으로 나눈다.
  한 칸에 두 단위를 겹쳐 그리면 학생이 어느 눈금을 읽는지 알 수 없다
- 두 챔버를 **색만으로 가르지 않는다.** 선 모양(실선/점선)도 다르게 한다
- **어긋난 통제변인이 있으면 그래프가 그것을 이름으로 말한다.**
  「통제변인이 다릅니다」로는 무엇을 고쳐야 할지 알 수 없다 —
  「왼쪽 2숟갈 · 오른쪽 3숟갈」처럼 값을 적는다
- 아직 아무것도 안 쟀을 때도 축이 무너지지 않아야 한다
- 지우지 않는다. 어긋난 시행도 그대로 그린다

## 합격 기준

- [ ] 같은 상태 → 같은 SVG 문자열 (`Math.random`·`Date.now` 없음)
- [ ] `idPrefix` 가 다르면 `id` 가 하나도 겹치지 않는다
- [ ] 발아 콩 챔버와 마른 콩 챔버의 BTB 색이 **다른 단계**로 나온다
- [ ] 콩 양이 다르면 그래프 설명이 두 값을 이름과 함께 말한다
- [ ] 세로축이 잰 값에 맞춰지고 눈금이 읽을 수 있는 수로 올림된다
