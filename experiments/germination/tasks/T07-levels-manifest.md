# T07 — 난이도 세 단계 · 매니페스트 · 배포본

## 난이도 — 설명만 줄이고 조작은 줄이지 않는다

| | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 절차 제시 | 다음 할 일 강조 | 목록만 | 목표만 |
| 실패 안내 | 원인 + 다음 행동 | 원인만 | 원인만 |
| 말풍선 힌트 | 문장 | 짧은 구 | 이름만 |
| 예상 문항 | 선택형 | 반주관식 | 완전 주관식 |
| 되돌리기 | 무제한 | 3회 | 1회 |
| 기구 초기 설정 | 챔버를 씻어 놓고 시작 | 직접 | 직접 |

**할 수 있는 일은 세 단계가 똑같다.** 조작표가 난이도를 인자로 받지 않게 하고,
1단계와 3단계의 조작표 모양이 같은지 테스트한다.
난이도는 주소로도 들어갈 수 있어야 한다 (`?level=2`) — 교사가 반마다 링크를 나눠 준다.

## 매니페스트 (`src/manifest.js`) — 5분

| 칸 | 값 |
|---|---|
| `id` | `germination` — **한 번 정하면 못 바꾼다** |
| `title` | `UI.appTitle` |
| `summary` | 카드 한 문장. **결과를 적지 않는다** |
| `skeleton` | `time-course` (이미 `SKELETONS` 에 있다) |
| `status` | `ready` |
| `levels` · `modes` | `[1,2,3]` · `['solo','group']` |
| `curriculum` | 고 · 세포와 물질대사 · 비상교육 · Ⅱ. 물질대사와 에너지 · **62쪽** |

교과서 **판본은 확인하지 않았다.** 지어내지 말고 `[확인 필요]` 로 남긴다.
쪽수를 모르는 자리는 `null` 이다 — 지어낸 쪽수는 없는 쪽수보다 나쁘다.

## 배포본

```bash
npm run build && npm run preview
node scripts/check-build.mjs
```

배포본에 `window.__store` 와 `?edit=1` 이 없어야 한다 (개발 서버 전용).
