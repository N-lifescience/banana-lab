# T04 — 실험대 조작 UI · 확대 뷰

기능만 넣고 끝내지 않는다. **어포던스까지 한 카드로** 한다 —
어포던스가 없으면 학생에게는 그 기능이 없는 것과 같다.

## 세 곳만 고친다

`src/ui/bench.js` 의 `defaultItems()` · `dropTable()` · `tapTable()`.
드래그·자유 배치·이름표·히트박스·편집 모드·키보드 경로는 그대로 쓴다.

### 실험대에 놓을 것

선반 — 발아 콩 통 · 마른 콩 통 · 숟가락 · 센서 둘 · BTB 병
작업면 — 챔버 둘 · 개수대 · 폐액통 · 쓰레기통 · 휴지

배치는 손으로 숫자를 적지 않는다. `http://localhost:5173/experiments/germination/?edit=1` 에서 옮기고 「코드 복사」.

### 조작표 (`dropTable`) — **종류 쌍으로만** 적는다

상태는 여기서 보지 않는다. 빈 숟가락을 챔버에 대면 규칙 엔진이 「숟가락이 비어 있습니다」라고
답해 주는데, 그 답을 듣는 것이 배우는 내용이다.

| 끄는 것 | 놓는 곳 | 무슨 일 |
|---|---|---|
| `scoop` | `beanjar` | 콩을 담는다 |
| `scoop` | `chamber` | 챔버에 붓는다 (한 숟갈) |
| `bottle` | `chamber` | BTB 용액을 붓는다 |
| `sensor` | `chamber` | 확대 뷰가 열린다 — 깊이는 거기서 정한다 |
| `chamber` | `sink` | 비운다 (되돌아갈 길) |
| `tissue` | `sensor` | 센서를 닦는다 |

### 탭표 (`tapTable`)

| 물건 | 클릭하면 |
|---|---|
| `chamber` | 확대 뷰 — 큰 챔버 그림 · 뚜껑 · 측정 시작 |
| `beanjar` | 통 뚜껑을 닫는다 (정리) |
| `bottle` | 마개를 닫는다 (정리) |
| `waste` | 폐액을 버린다 (정리) |
| `tissue` | 손을 씻는다 (정리) |

## 확대 뷰 (`src/ui/zoom.js`)

바나나랩의 확대 뷰는 현미경 전용이라 **통째로 다시 쓴다.** 손끝으로 하는 일은 하나다.

- **센서 깊이를 끌어서 정한다.** 콩이 쌓인 높이는 숟갈 수에 따라 오르므로,
  많이 넣을수록 얕게 꽂아야 닿지 않는다. 닿아도 **막지 않는다** — 신호가 튄다
- 뚜껑 닫기/열기, 측정 시작/멈춤도 여기서 한다 (큰 그림을 보면서 하는 것이 자연스럽다)
- `renderChamber()` 를 크게 그려 보여 준다. 결과를 보는 곳이자 조작하는 곳이다

## 시간 흐름 (`src/main.js`)

`startClock()` 이 **돌고 있는 챔버가 있을 때만** `TICK` 을 보낸다.
아무 일도 없는 동안 `TICK` 이 되돌리기 기록을 채우면 3단계(되돌리기 1회)가 죽는다.
`TICK` 은 `TRANSIENT_ACTIONS` 에 넣는다.

시간은 **실제보다 빠르게 흐른다.** 그 사실을 화면 문구로 밝힌다 —
밝히지 않으면 학생이 그 속도를 실제 실험 시간으로 읽는다.

## 합격 기준

- [ ] 물건에 마우스를 올리면 이름 + 지금 할 수 있는 조작이 뜬다 (난이도별)
- [ ] 끄는 동안 놓을 수 있는 곳이 강조되고, 지금 놓을 대상은 더 강하다
- [ ] 키보드만으로 끝까지 할 수 있다 (Tab → Enter → 「여기에 놓기」)
- [ ] `element.click()` 으로도 조작된다 (보조기기)
- [ ] 잡는 영역이 최소 44 px
- [ ] 어느 조작도 `disabled` 로 막히지 않는다
- [ ] 실험대 물건이 서로 겹치지 않는다
