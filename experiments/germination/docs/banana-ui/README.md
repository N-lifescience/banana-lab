# docs/banana-ui/ — 참조 구현(바나나랩)의 화면 코드

**여기 있는 것은 이 실험의 코드가 아니다.** 바나나 실험(「바나나에서 탄수화물과 지질
관찰하기」)의 화면·테스트·검사 스크립트를 **본으로 삼으려고** 옮겨 둔 것이다.

## 왜 옮겼나

T01 에서 상태 모델(`src/sim/state.js`)을 이 실험 것으로 통째로 갈아 끼웠다.
바나나랩의 화면 코드는 `state.slides` · `state.microscope` · `state.tools.dropper` 를
깊이 읽고 있어서, 상태를 바꾸는 순간 전부 함께 갈아 끼워야 한다.
ES 모듈은 없는 이름을 import 하면 **파일이 읽히지도 않는다.**

그런데 그 화면들은 카드가 나뉘어 있다 — 실험대는 T04, 탐구 노트는 T05, 보고서는 T06.
한 번에 다 고치면 커밋 하나가 수천 줄이 되고, 안 고치면 그때까지 `npm run check` 가
계속 빨간불이다. **커밋 게이트가 한 번이라도 빨간불로 방치되면 그 뒤로 아무도 안 믿는다.**

그래서 **카드가 올 때까지 여기 둔다.** 카드마다 하나씩 꺼내 이 실험 것으로 고쳐
`src/` 로 되돌린다. 뼈대(드래그·스냅·어포던스·7단계·되돌리기)는 그대로 쓸 수 있다.

| ~~`src/zoom.js`~~ | **T04 에서 통째로 다시 썼다.** 현미경 조작은 버렸다 — 이 실험의 손끝 조작은 센서 깊이 하나뿐이다 |
| ~~`src/notebook.js`·`src/progress.js`~~ | **T05 에서 돌아갔다.** 7단계 뼈대는 그대로, 쪽 내용은 새로 썼다 |

함께 되살렸다.

## 지금 꺼져 있는 것

- **없다.** T06 에서 보고서와 선생님 화면까지 돌아왔다.
  `src/net/` 과 `supabase/` 는 처음부터 그대로다.

**꺼진 검사는 아무 데도 안 나온다** — 초록불은 그대로이기 때문이다. 그래서 여기 적어 둔다.

### 꺼지지 않게 옮긴 것

개인정보 검사는 `roadmap.test.js` 와 `report.test.js` 에 흩어져 있었다. 그 둘을 치우면
**함께 꺼진다.** `tests/privacy.test.js` 로 옮기면서 파일 하나가 아니라 **디렉터리를
훑게** 고쳤다 — `src/ui/` 에 무엇이 들어오고 나가든 계속 본다.

## 읽을 때

**여기 적힌 판단을 이 실험의 규칙으로 가져오지 않는다.** 바나나랩의 사정에서 나온 것이다.
`docs/banana-progress.md` 와 같은 쓰임이다 — **함정 사례집**으로 읽는다.
