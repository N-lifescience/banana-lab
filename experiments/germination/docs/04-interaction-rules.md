# 04 — 조작 규칙표: 강제 대신 귀결

> **원칙:** 학생의 잘못된 조작을 막지 않는다. 그대로 진행시키고 **결과가 대신 말한다.**
> 이 표를 먼저 적고, 그 표를 `src/sim/rules.js` 로 옮겼다.

## 결과 삼분법

| 결과 | 뜻 | 얼마나 |
|---|---|---|
| `ok` | 뜻대로 됐다 | 정상 경로 |
| `happened` | 진행은 됐는데 뜻대로는 아니다 | **대부분 여기** |
| `blocked` | 진행되지 않았다 | **아래 둘에만** |

## 하드 게이트는 둘뿐이다

| 사유 | 이 실험에서 | 빠져나갈 길 (문장에 담는다) |
|---|---|---|
| `IMPOSSIBLE` 물리적으로 성립하지 않음 | 닫힌 뚜껑 안으로 콩·BTB·센서를 넣기, 닫힌 뚜껑에서 센서 빼기 | 「챔버를 클릭해 **확대 뷰**를 열고 **「뚜껑 열기」**를 누르세요」 |
| `BROKEN` 기구 파손 | **없다.** 억지로 만들지 않는다 | — |

「뚜껑을 여세요」로는 어디를 눌러야 여는지 알 수 없다. **어디로 가야 하는지까지** 말한다.

## 조작 하나하나

| 액션 | 정상 | 어긋났을 때 — **무엇이 답하는가** |
|---|---|---|
| `SCOOP_BEANS` | 숟가락에 한 숟갈 | 다른 콩을 들고 있으면 통에 도로 붓고 새로 담는다 (`happened`) |
| `POUR_BEANS` | 챔버에 한 숟갈 | 빈 숟가락 → 아무것도 안 담긴다 · **두 갈래를 섞으면** `mixed` — 그 챔버로는 아무것도 말할 수 없다 · 가득 차면 실험대에 흐른다 · **꽂아 둔 센서가 파묻히면 그 순간 말해 준다** |
| `POUR_BTB` | 바닥 접시에 BTB | 안 넣으면 **색 칸이 아예 없다.** 그래프만 남는다 |
| `INSTALL_SENSOR` | 콩에 닿지 않는 자리에 꽂힌다 | — (꽂자마자 파묻힌 채로 시작하지 않는다) |
| `SET_SENSOR_DEPTH` | 확대 뷰에서 끈다 | **콩에 닿는 깊이도 막지 않는다** → 그래프가 튄다 |
| `REMOVE_SENSOR` | 뺀다 | 파묻혀 있었으면 **부스러기가 묻어 온다** → 계속 조금씩 튄다. 휴지로 닦는다 |
| `WIPE_SENSOR` | 부스러기를 지운다 | 되돌아갈 길 |
| `SEAL` / `OPEN_LID` | 뚜껑 | **재는 도중에 열어도 막지 않는다** → CO₂ 가 새어 곡선이 그 자리에서 꺾인다 |
| `START` | 측정 시작 | 밀봉 안 함·센서 없음·콩 없음 **전부 진행된다.** 무엇이 빠졌는지 말해 주고, 결과가 그것을 보여 준다 |
| `TICK` | 재고 있는 챔버에만 | 관찰 시간(30분)을 채우면 스스로 멈춘다. **다시 시작할 수 있다** |
| `EMPTY_CHAMBER` | 개수대에서 비운다 | **막다른 길을 없애는 유일한 길.** 센서 부스러기는 남는다 |
| `RECORD` | 두 챔버를 기록 | 어긋난 상태도 그대로 기록되고 **무엇이 어긋났는지 함께 남는다** |
| `DELETE_CAPTURE` | 기록을 지운다 | 무엇을 근거로 삼을지 고르는 것도 탐구다 |

## 되돌아갈 길

새 조작을 넣을 때마다 「이걸 잘못하면 어떻게 돌아오나」를 같이 정한다.
되돌리기(UNDO)에 기대지 않는다 — 난이도가 올라가면 횟수가 유한하다.

| 잘못한 것 | 돌아오는 길 |
|---|---|
| 콩을 섞었다 · 양을 잘못 넣었다 | 챔버를 **개수대**에 → 비우고 처음부터 |
| 숟가락에 잘못 담았다 | 다른 통에 다시 담으면 바뀐다 |
| 센서를 콩에 파묻었다 | 확대 뷰에서 **위로 끌어 올린다** |
| 센서에 부스러기가 묻었다 | **휴지**에 대어 닦는다 |
| 밀봉을 잊었다 | 확대 뷰에서 뚜껑을 닫고 다시 시작 |
| 관찰 시간을 다 썼다 | 다시 시작하거나 비우고 처음부터 |

## 안전 규칙만은 예외

마개·손·폐액은 챔버 그림에 나타나지 않으므로 **결과로 말할 수 없다.**
그래서 `CHECK_TIDY` 가 보고서를 열 때 한 번 보고 자기 평가에 적는다.
**감점은 없다.** 늦게라도 하면 위반 기록에서 지워진다 — 벌이 아니라 기록이다.
