# T03 — 결과 렌더러

## 목표
**맹관부에 모이는 기체 그림이 몸통이다.** 그래프는 보조다 — 센서 곡선 하나만 보여 주면
그래프 뷰어가 된다.

## 건드릴 파일
- `src/render/tube.js` — 상태를 받아 그림을 내는 **순수 함수**. `idPrefix` 를 받는다

## 합격 기준
- [ ] 같은 상태면 같은 그림이 나온다 (난수는 `seed` 로 받는다)
- [ ] 효모 없는 대조군과 있는 것이 그림에서 갈린다
- [ ] KOH 를 넣으면 맹관부 기체가 줄어드는 것이 보인다

## 검증
```bash
npm run check
npm run shot -- '.bench-stage' tube
```
