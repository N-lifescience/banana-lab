# T06 — 결과 그래프

## 목표
조건 대 기체 발생량. **실험대가 막지 않은 것이 여기서 대답한다** — 설계와 어긋난 시행은
선에서 떨어져 나오고, 무엇이 어긋났는지 이름으로 말한다.

## 지킬 것
- 어긋난 시행을 숨기거나 지우지 않는다
- 재지 않은 조건도 가로축에 남긴다 — 「하나만 재고 끝냈다」와 「다 쟀다」가 같은 그림이 되면 안 된다
- **색만으로 가르지 않는다.** 모양이 먼저다
