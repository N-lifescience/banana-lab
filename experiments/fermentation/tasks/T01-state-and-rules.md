# T01 — 상태 모델 · 발효 모형 · 규칙 엔진

## 목표
화면 없이 이 실험의 규칙을 먼저 세운다. `src/sim/` 은 DOM 을 모른다 —
`document`·`window`·`Date.now()`·`Math.random()` 을 쓰지 않는다.

## 건드릴 파일
- `src/sim/state.js` — 조작변인 목록 · 통제변인 · 발효관 상태
- `src/sim/fermentation.js` — CO₂ 발생 모형. **[사실] 과 [모형] 을 갈라 적는다**
- `src/sim/rules.js` — 조작 하나당 함수 하나
- `src/sim/progress.js` — 절차 세부 단계 판정
- `tests/rules.test.js` · `tests/fermentation.test.js`

## 이 실험이 지켜야 할 사실
- 온도: **30~35 ℃ 최대 → 40 ℃ 이상 급감 → 55~60 ℃ 사실상 0 → 10 ℃ 이하 거의 0**
  (*S. cerevisiae* 최적 28~33 ℃ · 최대 생장 39~41 ℃ · 상한 45.4 ℃)
- 대조군에 **증류수**를 넣는 이유는 **총 부피를 같게 맞추기 위해서**다
- 효모액 = 건조 효모 **6 g / 증류수 50 mL**. 「10 % 효모액」이라는 표기는 쓰지 않는다
- 「끓인 효모액」 대조군 · 「주머니 달린 발효관」 · BTB 는 이 실험의 것이 아니다
