# T02 — 상태 모델 · 규칙 엔진 · 품질

`src/sim/state.js` · `src/sim/rules.js` · `src/sim/quality.js`

## 조작표 (docs/04-interaction-rules.md 에 표로 먼저 적는다)

채혈 → 빨아올리기 → 밀봉 → 회전판에 넣기 → 균형 → **당기기** → 멎기를 기다리기 →
꺼내기 → 재기 → 기록.

## 막지 않는다

헤파린 없는 모세관을 골라도, 균형을 안 맞춰도, 밀봉이 얕아도 **그대로 진행시킨다.**
결과가 답한다 — 응고해 혈청이 뜨거나, 흔들려 층이 흐려지거나, 혈액이 샌다.

## 허용되는 하드 게이트는 둘뿐

1. **할 수 없는 일** — 돌고 있는 회전판에 모세관을 넣을 수 없다.
2. **깨진 기구** — 부러진 모세관은 쓸 수 없다.

둘 다 **빠져나갈 길을 문장에 담는다.** 「새것을 꺼내세요」로는 어디서 꺼내는지 알 수 없다.

## 합격 기준

- `reduce()` 가 돌려주는 `outcome` 은 `ok` · `happened` · `blocked` 셋뿐이고,
  `blocked` 는 위 둘에만 나온다 (`tests/rules.test.js` 가 전 액션을 훑는다).
- 되돌아갈 길이 모든 실패에 있다 — 새 모세관 · 회전판에서 빼기 · 고무찰흙 떼기.
- 소모품이 바닥나지 않는다.
