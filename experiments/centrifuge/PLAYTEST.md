# PLAYTEST.md — 직접 플레이해서 볼 것

**검사가 초록불이어도 여기서 걸리는 것이 있습니다.** 이 저장소에서도 실제로 그랬습니다 —
검사가 전부 통과하는 동안 확대 뷰에서 모세관을 기울여도 **각도 숫자가 안 움직였고**,
끈을 마구 눌러 대는 것이 박자를 맞춘 것보다 빨랐습니다. 둘 다 콘솔 에러가 한 줄도 없었습니다.

## 띄우기

```bash
npm run dev
```

- 앱 — http://localhost:5173/experiments/centrifuge/
- 애셋·결과 손잡이 — http://localhost:5173/experiments/centrifuge/harness.html
- 배치 편집 — http://localhost:5173/experiments/centrifuge/?edit=1
- 2·3단계 — `?level=2` · `?level=3`
- 혼자/모둠 — `?mode=solo` · `?mode=group`

```bash
kill $(lsof -t -nP -iTCP:5179 -sTCP:LISTEN)
```

## 1. 정상 경로 — 이대로 하면 층이 뚜렷하게 갈려야 합니다

주소를 열면 **시작 화면**이 먼저 나옵니다 — 난이도(1·2·3)와 혼자/모둠을 고르고
「1단계로 시작」을 누릅니다. (`?level=1` 처럼 주소로 정하면 이 화면을 건너뜁니다.)

그다음 탐구 노트 1~4 쪽을 열고 맨 아래 「이 쪽을 읽었습니다」를 눌러야 실험대가 열립니다.

| # | 하는 일 | 이래야 정상 |
|---|---|---|
| 1 | **소독솜**을 손끝으로 끌기 | 손끝이 젖은 느낌으로 바뀐다 |
| 2 | **채혈침**을 손끝으로 끌기 | 손끝에 **선홍색** 방울이 맺힌다 |
| 3 | **모세관**을 손끝으로 끌기 | 확대 뷰 「혈액 빨아올리기」가 열린다. 각도는 **35° 로 이미 맞춰져** 있고 아래 문구가 초록으로 「잘 빨려 올라오는 각도」다 |
| 4 | 모세관을 **누르고 있기** | **누르는 순간부터** 빨려 올라온다. 「혈액 기둥」이 순식간에 관의 **70 %** 까지 차고 거기서 멈춘다 — 핏방울 한 방울이 다 들어간 것이다 (0.3초면 끝난다. 1초를 누르고 있어도 더 안 는다) |
| 5 | 모세관을 **좌우로 끌어** 각도를 바꿔 보기 | 각도 숫자가 **함께 움직인다.** 13~57° 밖으로 나가면 문구가 주황으로 바뀐다. **끄는 동안에도 계속 빨아올리므로**, 방울이 남아 있으면 그 각도로 들어간다 |
| 6 | Esc → 채혈침을 손끝으로 다시 → 모세관을 손끝으로 → 또 누르고 있기 | 기둥이 관을 **가득**(100 %) 채운다 |
| 7 | Esc → **모세관**을 고무찰흙으로 끌기 | 확대 뷰 「모세관 끝 막기」가 열린다 |
| 8 | 「바깥쪽 끝」이 골라진 채로 모세관을 **아래로 100 px쯤 끌었다 놓기** | 「밀어 넣은 깊이」가 70 % 언저리 — 눈금의 붉은 구간(92 % 부터 부러짐) 앞에서 멈춘다. 마개가 생긴다 |
| 9 | 「축 쪽 끝」을 누르고 같은 만큼 끌었다 놓기 | 두 단추에 ✓ 가 붙는다 |
| 10 | Esc → **모세관**을 회전판으로 끌기 | 모세관이 실험대에서 사라지고 회전판 왼쪽 빨대에 **수평으로** 들어간다 |
| 11 | **모세관 통**을 회전판으로 끌기 | 오른쪽 빨대에 빈 모세관이 들어간다. (**실험대에서는 아무 말도 안 나옵니다** — 균형이 맞았다는 문구는 다음 칸의 확대 뷰에 있습니다) |
| 12 | **회전판을 눌러** 확대 뷰 열기 | 「끈 당기기」가 열리고 아래에 지금 모세관 그림이 함께 보인다. 「균형이 맞아 곧게 돕니다」가 **초록으로** 적혀 있다 |
| 13 | **박자 표시가 「지금!」으로 바뀔 때** 링을 아래로 끌었다 놓기 — **25번쯤** | 아래 |
| 14 | 손을 놓고 **3초쯤 기다리기** | 회전이 잦아들고, 「회전 빠르기」 글자도 **아주 빠르게 돎 → 꽤 빠르게 돎 → 느리게 돎** 으로 함께 내려간다. 그동안에도 층은 계속 갈리므로 「결과의 읽을 만함」이 조금 더 오른다 |
| 15 | Esc → 도구 막대의 **「회전판 멈추기」** 누르기 → 단추가 **「회전판에서 모세관 꺼내기」** 로 바뀌면 **한 번 더** 누르기 | 모세관이 실험대로 돌아온다 (단추 하나가 두 번 일한다. 돌고 있는 회전판에 손을 넣지 않게 하는 순서다) |
| 16 | **자**를 모세관으로 끌기 | 「모세관에 자를 댔습니다 …」가 **초록으로** 뜹니다. 다만 **실험대에는 눈금이 안 붙습니다** — 눈금은 모세관 **그림 안**에 그려지므로 다음 칸에서 보입니다 |
| 17 | **회전판을 다시 눌러** 확대 뷰 열기 → 「결과 기록」 누르기 | 모세관 그림 **아래에 0~70 mm 눈금자**가 붙어 있다. 「결과의 읽을 만함」이 80 을 넘는다 |

**15·16·17 의 차례를 지켜 주세요.** 자를 대기 **전에** 「결과 기록」을 누르면, 그 기록에는
눈금이 없는 그림이 담깁니다 — 탐구 노트에서 잴 것을 놓고 잴 자가 없어집니다.

### 13번 — 여기가 이 실험의 몸통입니다. 자세히 봐 주세요

**박자 표시**(회전판 그림 바로 아래 막대)가 왼쪽에서 오른쪽으로 **차오르다가**
가득 차면 「지금!」으로 바뀝니다. 그때 링을 당기면 회전이 빨라집니다.

- 「지금!」에 맞춰 당기면 → **「회전 빠르기」가 「느리게 돎」 → 「꽤 빠르게 돎」 → 「아주 빠르게 돎」**
  으로 올라가고, 「박자가 맞은 정도」가 80 % 를 넘습니다
- 당기고 나면 막대가 **0 으로 떨어지고 다시 차오릅니다.** 그 오르내림이 곧 리듬입니다
- **빨라질수록 막대가 더 빨리 차오릅니다.** 손을 그에 맞춰 빠르게 놀려야 합니다 —
  같은 박자로 계속 당기면 어느 순간부터 늦게 당기게 되고 속도가 안 오릅니다
- 아래로 **많이 끌수록 세게** 당깁니다 — 「당기는 세기」 숫자는 **끌고 있는 동안**만 오르고,
  손을 놓으면 0 으로 돌아갑니다 (당겨진 값이 아니라 지금 쥔 세기라서 그렇습니다)

**이래야 정상**

- 25번쯤 당기면 아래 모세관 그림에 **세 부분**이 보인다 —
  왼쪽에 짙은 **암적색**, 아주 얇은 **회백색** 띠, 오른쪽에 **담황색**
- 처음(안 갈렸을 때)에는 기둥 전체가 **선홍색**이고, 갈리면서 **어두워진다**
- 그림 아래에 **「← 회전 바깥쪽 (교과서 그림의 「아래」)」 / 「축 쪽 →」** 가 적혀 있다

**「결과의 읽을 만함」은 아직 60 언저리입니다 — 정상입니다.**
이 값에는 「잴 수 있는가」가 들어 있어서, **자를 대기 전에는 아무리 잘 돌려도 70 을 못 넘습니다.**
박자를 잘 맞춰 25번 당기면 68, 40번을 당겨도 70 에서 멎습니다 — 거기가 천장입니다.

**자를 대면 확 오릅니다** — 같은 관이 25번이면 **97**, 40번이면 **100** 이 됩니다.
박자가 어긋난 만큼 낮게 나오니 **80 을 넘으면 정상**으로 보시면 됩니다.

> **기록해도 이 값은 안 오릅니다 — 그게 맞는 동작입니다.** 점수는 **관의 상태만** 보고 매깁니다.
>
> 예전에는 「기록했으면 만점」 갈래가 있어서, **첫 기록을 넘기는 순간 회전 확대 뷰만**
> 자를 안 댔는데도 70 에서 100 으로 뛰고 탐구 노트는 70 에 머물렀습니다 — **같은 관을
> 두 화면이 다르게** 말한 것입니다. 걷어냈습니다. 이제 확대 뷰와 노트가 같은 값을 말합니다.
>
> **그러니 두 값이 다르면 그건 버그입니다 — 꼭 적어 주세요.** (확대 뷰의 숫자와,
> 그 관을 기록한 뒤 탐구 노트 5단계 기록 카드에 적힌 숫자를 맞대 보시면 됩니다)

### 16·17번 — 재기

자를 대면 **「모세관에 자를 댔습니다. 바깥쪽 끝에서 적혈구층 경계까지, 그리고 기둥 전체를
읽으세요.」**가 초록으로 뜹니다. 그런데 **실험대에는 눈금이 안 붙습니다** — 눈금은 실험대가
아니라 모세관 **그림 안**에 그려지기 때문입니다. 회전판을 다시 눌러 확대 뷰를 열면
모세관 그림 아래에 **0~70 mm 눈금자**가 붙어 있습니다.

그 상태로 「결과 기록」을 누르면, 탐구 노트 「5. 결과」의 기록 카드에도 눈금자가 함께 실립니다.
거기서 **헤마토크릿**을 넣어 보세요.

> 적혈구층 길이 ÷ 혈액 기둥 전체 길이 × 100

- **화면은 그때 그려진 대로 채점합니다.** 정답표에 45 를 박아 두지 않았습니다 —
  적혈구층은 돌릴수록 다져져 짧아지므로, **덜 돌린 학생은 더 큰 값을 재는 것이 맞습니다**
- 25번쯤 당긴 기록이면 **53 언저리**, 40번이면 **49 언저리**가 나옵니다.
  ±8 까지 봐주므로 잘 돌린 뒤라면 45 도 통과합니다 —
  다만 **20번쯤에서 멈춘 기록에 45 를 넣으면 통과하지 않습니다** (그때 그림은 60 입니다).
  그러니 **적어 둔 숫자를 넣지 말고 눈금을 읽어 넣으세요**
- **맞으면 아무 말도 안 나옵니다** (문구가 사라지는 것이 통과 표시입니다)
- **틀리게 넣어도 화면이 답을 알려 주지 않습니다.** 「자를 다시 대고 …」만 나옵니다.
  숫자가 나오면 그건 버그입니다 — 한 번 알려 주면 그 뒤로 잴 이유가 없어집니다

## 2. 실패 경로 — **막히지 않고 결과가 답해야** 합니다

> **안전은 세지 않습니다.** 소독·침 버리기·손 씻기·지혈은 **조작이 아닙니다** —
> 준비물(2쪽)에 적어 두기만 하고 앱이 확인하지 않습니다. 개수대·침 폐기함·휴지는
> **실험대에 없습니다.** 그러니 그것들을 찾다가 「없다」고 적지 마세요.
> (한때 있었고 사장님 지시로 걷어냈습니다. `docs/04-interaction-rules.md` §5 참고)

하나씩 일부러 틀려 보세요. **막히면 그게 버그입니다.**
(막혀도 되는 것은 아래 §3 의 둘뿐입니다)

| 일부러 틀리기 | 이래야 정상 |
|---|---|
| **소독을 건너뛰고** 채혈침부터 | 그대로 채혈된다. 「실제 실험이라면 하지 않는 일입니다」 라고만 말하고 **세지 않는다** |
| **쓴 채혈침을 다시** 손끝에 | 그대로 된다. 역시 말만 하고 세지 않는다 |
| 모세관을 **수직으로 세워서**(0°) 대기 | 적게 들어오고 **기포**가 낀다. 「공기가 함께 들어가」 토스트 |
| 기둥을 **아주 조금만** 채우고 진행 | 갈리기는 갈리는데 「혈액 기둥의 길이」가 깎이고 재기 어렵다 |
| **모세관 통을 눌러 「민무늬」로 바꾸고** 새 모세관으로 처음부터 | 돌리는 동안 **응고**한다. 층이 안 갈리고 위층 이름이 **「혈청」**으로 바뀐다. 그림에 **혈병**이 생긴다 |
| 채혈하고 **한참 두었다가**(20초쯤) 빨아올리기 | 헤파린 관이라도 「이미 굳기 시작한 피는 되돌릴 수 없습니다」 |
| 고무찰흙을 **아주 얕게**(20 px만) 누르기 | 막히긴 한다. 돌리면 **혈액이 샌다** — 기둥이 짧아진다 |
| **한쪽 끝만 막고** 돌리기 | 「그쪽으로 그대로 날아갑니다」 토스트. 실제로 빠진다 |
| **반대쪽 빈 모세관 없이** 돌리기 | 「흔들립니다」가 주황으로 뜨고, 층의 **경계가 흐리게 번진다**. 같은 힘으로 **덜 빨라진다** |
| 확대 뷰의 **「밀어 넣은 깊이」 슬라이더**를 한쪽만 30 %로 | 「깊이가 다릅니다」 토스트. 역시 흔들린다 |
| **박자를 안 보고 마구** 당기기 | **속도가 거의 안 오른다.** 「박자가 어긋나 회전을 거슬렀습니다」 토스트 |
| **살짝만**(20 px) 당기기 | 느리게 오른다 |
| **열 번쯤만** 당기고 기록 | 붉은 부분이 길게 남아 헤마토크릿이 **70 % 넘게** 나온다 — 과대평가. 「더 돌린 뒤 다시 기록해도 됩니다」 |

**여기서 가장 중요한 것:** 위 어느 것도 **경고창으로 막혀서는 안 됩니다.**
토스트가 뜨고 결과가 달라질 뿐이어야 합니다.

## 3. 막혀야 하는 것은 **둘뿐**입니다

그리고 그 둘은 **빠져나갈 길이 문장에 있어야** 합니다.

| 해 보기 | 이래야 정상 |
|---|---|
| **돌고 있는 동안** 모세관 통을 회전판으로 끌기 | 막힌다. 「회전판을 손으로 **감싸 멈춘 뒤에** 넣으세요」 |
| 고무찰흙에 모세관을 **끝까지**(붉은 구간까지) 눌러 넣기 | 부러진다. 「**선반의 모세관 통에서** 새것을 꺼내세요」 |

「새것을 꺼내세요」로 끝나면 버그입니다 — **어디서** 꺼내는지가 문장에 있어야 합니다.

돌고 있는 회전판에서 「꺼내기」를 누르면 어떻게 되는지도 봐 주세요.
도구 막대의 단추가 돌고 있을 때는 **「회전판 멈추기」**로 바뀌어 있어야 합니다 —
그 순서를 단추가 지켜 줍니다.

## 4. 되돌아갈 길이 다 열려 있는가

**막다른 길이 하나라도 있으면 버그입니다.** 각각 해 보세요.

- 기둥을 잘못 채웠다 → **모세관을 모세관 통으로** 끌기 → 새것이 나온다
- 모세관이 부러졌다 → 같은 길. 또는 **폐기물 통**으로 끌기
- 밀봉이 얕다 → 확대 뷰에서 **「고무찰흙 떼어 내기」** → 다시 막기
- 균형을 안 맞추고 돌렸다 → **멈추고** 빈 모세관 넣기
- 덜 돌렸다 → **더 당기면 된다.** 이미 갈린 것은 그대로 있다
- 헤파린 없는 것을 골랐다 → 모세관 통을 눌러 바꾸고 새것 꺼내기
- 핏방울이 말랐다 → 다시 채혈
- 잘못 기록했다 → 탐구 노트 5단계에서 **「이 기록 지우기」**
- **모세관을 몇 번이든 새로 꺼낼 수 있는가** (열 번쯤 해 보세요. 바닥나면 버그입니다)

## 5. 손이 아닌 것으로도 되는가

### 키보드만으로

마우스를 **한 번도 쓰지 말고** Tab · Enter · Esc 만으로 해 보세요.

- Tab 으로 물건에 가면 말풍선에 **「여기에 놓기 — 손끝 / 회전판 …」** 단추가 나오는가
- 그 단추를 Enter 로 눌러 조작이 되는가
- 회전판에 Enter → 확대 뷰가 열리는가
- **링에 Enter 를 박자에 맞춰 눌러 회전이 오르는가** ← 여기가 막히면 이 실험의 몸통이
  마우스 전용이 됩니다
- Esc 로 나가면 **열었던 물건으로 포커스가 돌아오는가**
- 놓은 물건이 화면에서 사라졌을 때(모세관→회전판) 포커스가 `<body>` 로 빠지지 않는가

**그리고 탐구 노트도 키보드로만 해 보세요.** 위 여섯 줄이 다 실험대 이야기라
**노트의 글칸은 아무도 안 밟았습니다** — 오늘 가장 크게 깨져 있던 자리가 거기였습니다.

- **3단계로** 열고 3쪽(예상)에서 첫 칸에 적은 뒤 **Tab 으로만** 다음 칸으로 옮겨 가세요.
  칸마다 **자기가 친 글이 그 칸에** 있는가 · 손(포커스)이 **그 칸에 남아** 있는가
  — 앞 칸의 글이 사라지거나 뒤 칸에 몰리면 버그입니다
- 다 적고 **곧장** 「이 쪽을 읽었습니다」를 누르면 그 누름이 먹히는가
  (마지막 칸에서 손을 떼지 않고 눌러 보세요)
- 4쪽에서 STEP 제목에 Tab 으로 가서 Enter 로 펼쳐지는가 · 잠긴 STEP 은 **왜 안 열리는지**
  말하는가
- 회전판이 도는 동안 노트에 적어도 **글자가 지워지지 않는가**

### 다크 모드

시스템을 다크로 바꾸고 다시 보세요.

- 단추 글자가 배경에 묻히지 않는가 (예전에 흰 바탕에 흰 글씨가 된 적이 있습니다)
- 탐구 노트 **일곱 쪽을 다 열어** 보세요. 고른 탭은 배경색이 달라집니다
- 실험대 물건 이름표가 읽히는가

### 좁은 화면

**★ 아직 안 고친 것 — 폰에서 토스트가 조작 단추를 가립니다.**
어느 쪽에 두어도 무언가를 가려서 **사장님 판단으로 남겨 둔 자리**입니다.

**이 숫자는 「회전판에 모세관을 물리고 확대 뷰를 연」 상태에서만 나옵니다** —
그 단추가 그때만 있기 때문입니다. 그냥 열어서 보면 **가린 것이 없어 보입니다.**

| 어디에 두면 | 무엇을 가리는가 |
|---|---|
| 지금처럼 **위** | 확대 뷰의 「회전판에서 모세관 꺼내기」를 **390px 에서 95 %** (375:88 · 320:63) |
| **아래**로 내리면 | 폰의 실제 높이에서 탐구 노트를 **최대 100 %** (390×568 에서 84 %) |

손가락은 그대로 닿습니다(토스트가 포인터를 안 받습니다). **안 보일 뿐입니다.**
옮기지 않고 푸는 길 셋 — 확대 뷰 안쪽 아래에 붙이기 · 조작 줄에 자리 비우기 ·
확대 뷰가 열린 동안 더 짧게 두기. 셋 다 눈에 보이는 변경이라 손대지 않았습니다.


브라우저 창을 **가로 480 px** 까지 줄여 보세요. 그리고 **눕힌 스마트폰**(가로 900 × 세로 400)도.

- 확대 뷰가 가로로 넘치지 않는가
- 넘칠 때 **아래쪽 단추까지 스크롤로 닿는가** (닫기 단추가 화면 밖으로 밀려나면 버그)
- 보고서 창의 학년·반·번호 칸이 잘리지 않는가

## 6. 난이도 — 1·2·3 에서 무엇이 달라지는가

`?level=1` · `?level=2` · `?level=3` 으로 각각 들어가 보세요.

| | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 물건에 마우스를 올리면 | 문장으로 안내 | 짧은 구 | **이름만** |
| 확대 뷰의 원리 설명 | 있다 | 없다 | 없다 |
| 박자 표시 | 크게 | 크게 | 작고 흐리게 |
| 「결과의 읽을 만함」 아래 힌트 | 있다 | 없다 | 없다 |
| 탐구 과정 | 다음 할 일 강조 | 목록만 | **목표만** |
| 예상 | 보기에서 고르기 | 보기 + 까닭 | **빈칸만** |
| 되돌리기 | 무제한 | 3회 | 1회 |

**여기서 봐야 할 것: 3단계에서도 할 수 있는 일이 똑같은가.**
안내가 줄어드는 것은 맞지만, 3단계에서 **못 하게 되는 조작이 하나라도 있으면 버그**입니다.
특히 —

- 3단계에서도 Tab 으로 「여기에 놓기」 단추가 나오는가
- 3단계에서도 물건을 끌면 놓을 곳이 강조되는가
- 3단계에서도 박자 표시가 (작더라도) 보이는가
