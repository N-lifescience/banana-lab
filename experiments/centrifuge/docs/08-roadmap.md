# 08 · 구현 순서와 완성 판정

## 순서

한 번에 전부 만들지 않는다. 각 단계는 그 자체로 실행되고 눈으로 확인되는 상태에서 끝난다.
작업 카드는 `tasks/` 에 있다.

| 카드 | 내용 | 끝났다는 것 |
|---|---|---|
| T00 | 이름표 | 브라우저 탭과 링크 미리보기에 이 실험 이름이 뜬다 |
| T01 | 회전 물리 · 혈액의 층 (`spin.js`) | 박자가 맞으면 빨라지고 어긋나면 느려진다 |
| T02 | 상태 · 규칙 · 품질 | UI 없이 정상 경로와 실패 경로가 테스트로 통과 |
| T03 | 애셋 13종 | `npm run check:art` 통과, 하네스에서 전부 보임 |
| T04 | 결과 렌더러 (`tube.js`) | 갈린 정도·흔들림·응고를 슬라이더로 흔들어 검증 |
| T05 | 실험대 조작 UI | 끌어다 놓기 · 말풍선 · 키보드 경로 |
| T06 | 확대 뷰 — **끈을 당기는 리듬** | 박자를 맞추면 빨라지고, 마구 눌러 대면 못 간다 |
| T07 | 탐구 노트 7단계 | 예상 → 결과 → 정리가 이어진다 |
| T08 | 서술형 첨삭 | **바깥에서 던진 문장**이 통과한다 |
| T09 | 보고서 · 개인정보 | 방침과 실제 payload 가 양방향으로 맞는다 |
| T10 | 난이도 · 브라우저 검사 | 91 + 29 + 13건 통과 |
| T11 | 매니페스트 · 문서 · 진행 기록 | 합칠 때 사람이 되짚어 쓸 것이 없다 |

## 완성 판정 — 기계가 보는 것

```bash
npm run check                                  # 커밋 게이트. 197건
node scripts/check-bench.mjs                   # 실험대 어포던스. 91건
node scripts/check-ui.mjs                      # 당기는 리듬. 13건
node scripts/check-grading.mjs                 # 서술형 첨삭 (바깥 문장)
npm run build && npm run preview
node scripts/check-build.mjs                   # 배포본. 29건
```

## 완성 판정 — 사람이 봐야 하는 것

기계는 색과 두께만 본다. 아래는 눈으로 봐야 한다 — `PLAYTEST.md` 가 그 목록이다.

- [ ] 회전판 그림에서 **모세관이 수평으로 물려 있는 것**이 보이는가
- [ ] 갈리는 동안 적혈구층이 **선홍에서 암적으로 어두워지는 것**이 보이는가
- [ ] 연층(회백색 얇은 띠)이 **눈에 보이는가**
- [ ] 박자 표시를 보고 손이 리듬을 잡을 수 있는가 — 너무 빠르거나 느리지 않은가
- [ ] 라이트/다크 양쪽에서 애셋이 제대로 보이는가
- [ ] 하드 게이트 둘의 문장에 **빠져나갈 길**이 있는가 (어디서 새것을 꺼내는지까지)
