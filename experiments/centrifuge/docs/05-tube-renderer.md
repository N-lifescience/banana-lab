# 05 · 결과 렌더러 — 모세관의 층

`src/render/tube.js` 가 구현이고 이 문서는 설명이다. 값이 어긋나면 코드가 맞다.
회전 물리는 `src/sim/spin.js` 에 있다.

바나나랩의 `fov.js`(현미경 시야) 자리에 오는 파일이다. **이 실험에는 현미경이 없다.**

---

## 방향 — 이 파일에서 가장 틀리기 쉬운 것

**회전판은 모세관을 수평으로 문다.** 교과서 그림의 「아래」는 회전 **바깥쪽** 끝이고,
혈장은 **축 쪽**이다.

```
   ← 회전 바깥쪽 (교과서 그림의 「아래」)              축 쪽 →
   ┌──────────────┬─┬────────────────┬─────────────┐
   │  적혈구층    │▓│     혈장       │   빈 관     │
   │  (암적색)    │ │   (담황색)     │             │
   └──────────────┴─┴────────────────┴─────────────┘
                   ↑ 연층(백혈구·혈소판) 회백색, 1 % 미만
```

`renderTube()` 는 **왼쪽을 바깥쪽으로** 그리고, 그 두 낱말을 **화면에 글자로 적는다.**
적어 두지 않으면 그리는 사람도 읽는 사람도 위/아래로 되돌려 생각하다가 뒤집는다.
`tests/roadmap.test.js` 가 `layerBands()` 의 차례와 그 글자를 함께 검사한다.

## 물리 — `spin.js`

| 값 | 뜻 | 출처 |
|---|---|---|
| `HEMATOCRIT.male/female` | 0.45 / 0.40 | 사람이 검증한 브리프 |
| `BUFFY_FRACTION` | 0.007 (1 % 미만) | 같음 |
| `MAX_SPEED` | 1 — **정규화한 값. rpm 이 아니다** | 실제 값은 `[확인 필요]` |
| `WORK_HALF` | 누적 원심 일이 이만큼이면 절반쯤 갈린다 | 시뮬레이션 단위 |
| `SIM_PER_SECOND` | 1.7 — 손과 화면 사이의 속도 | 물리가 아니라 조작감 |
| `TUBE_LEN_MM` | 75 — **자의 눈금을 그리는 데만** | `[확인 필요]` |

`TUBE_LEN_MM` 이 `[확인 필요]` 인데도 결과가 흔들리지 않는 이유는 **헤마토크릿이 길이의
비**이기 때문이다. `tests/spin.test.js` 가 길이를 60·75·100 으로 바꿔 그것을 확인한다.

### 덜 돌리면 헤마토크릿이 크게 나온다

이 실험에서 가장 값진 오차다. 적혈구는 바깥쪽으로 가라앉으므로 **축 쪽에서 맑은 혈장이
자라 들어온다.** 붉은 부분은 처음에 기둥 전체였다가 다져지면서 헤마토크릿 값까지 줄어든다.

```
packedFraction(sep) = 1 - (1 - hct) · sep
```

절반만 돌린 학생은 적혈구층을 실제보다 길게 재고 값을 **과대평가**한다.
막지 않는다 — 그 과대평가가 "왜 더 돌려야 하는가" 를 말해 준다.

### 당기는 리듬

```
timingError(since) — since 는 마지막으로 당긴 뒤 지난 꼬임 주기 수
  k = max(1, round(since))          가장 가까운 맞는 박. **한 주기 뒤부터 찾는다**
  err = min(0.5, |since - k|)

  since ≈ 0             → 0.5   당긴 직후. 자동으로 가장 나쁜 때가 된다
  since = 1, 2, 3 …     → 0     맞는 박. 한 박 쉬어도 리듬이다
  그 사이               → 클수록 어긋남. 0.5 면 정확히 반대 박
```

`pullGain` 은 어긋난 만큼 **음수**를 낸다 — 아직 돌고 있는 회전판을 거스른다.
이것이 없으면 「리듬 있게」가 「빨리 여러 번」이 된다.

**마구 눌러 대는 것을 막는 것은 `max(1, …)` 한 자리다.** 앞서 여기에 「다시 꼬이는 몫」
상수를 따로 두었는데, 없애도 아무 검사가 안 깨졌다 — 이미 같은 일을 하고 있었다.
하는 일이 없는 상수는 다음 사람에게 "여기서 무언가를 막고 있다" 고 거짓말한다.
그리고 `beatRate` 가 속도에 비례해 커진다 — **빨라질수록 손을 더 빨리 놀려야 한다.**

## 그림에서 물러선 자리 둘

이 파일은 아트 디렉션(라인+플랫)의 **예외**다. 흐리게 섞인 경계는 굵은 외곽선으로
그릴 수 없다. **애셋을 만드는 사람은 이 파일을 읽지 말 것** — 따라 쓰면 애셋이 오염된다.

1. **연층의 최소 획 두께 (`MIN_BAND_PX`).**
   실제로 1 % 미만이라 비례대로 그리면 한 줄도 안 된다. 그런데 학생이 봐야 하는 것이
   바로 그 얇은 띠다. **비율은 그대로 두고 획만** 굵게 긋는다 —
   `layerBands()` 가 내는 값은 참값이고, 검사도 그 값을 본다.

2. **관의 굵기.**
   실제 모세관은 길이에 견주면 머리카락처럼 가늘다. 굵기는 읽히도록 부풀리고,
   **길이 방향만 비례를 지킨다** — 학생이 재는 것이 길이이기 때문이다.

## 색

| 무엇 | 색 | 왜 |
|---|---|---|
| 채혈 순간의 핏방울 · 갈리기 전의 기둥 | **선홍** `bloodFresh` | 두 색을 갈라 칠하지 않으면 「다져져서 어두워졌다」가 화면에서 사라진다 |
| 다져진 적혈구층 | **암적** `packedCells` | |
| 연층 | **회백** `buffyCoat` | 한국어 위키백과의 「담황색」을 따르면 **혈장과 구분이 안 된다** |
| 혈장 / 혈청 | 담황 `plasma` / `serum` | 실제로도 비슷하다. **색으로 가르지 않고** 이름표와 혈병으로 가른다 |

갈리는 동안 적혈구층은 선홍 → 암적으로 **섞여 간다** (`toneOf`).
그 색들은 **기구에 쓰면 안 된다** — `tests/palette.test.js` 가 그려진 SVG 를 훑어 막는다.

## `idPrefix` 를 반드시 넘길 것

한 화면에 여러 장을 그리는 순간 `id` 가 부딪혀 **에러 없이 조용히** 틀린 그림이 된다
(뒤엣것의 그라데이션을 앞엣것이 쓴다). 결과 카드가 여럿 쌓이는 탐구 노트 5단계에서
실제로 일어나는 일이라, `tests/roadmap.test.js` 가 그것도 검사한다.

```js
renderTube(a, { idPrefix: 'cap0-' })
renderTube(b, { idPrefix: 'cap1-' })
```
