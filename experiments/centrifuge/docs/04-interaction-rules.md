# 04 · 조작 규칙 — 강제에서 귀결로

**이 문서가 프로젝트의 핵심이다.**

> **강제하지 말고 결과로 답한다.** 이 표에 「막는다」는 두 줄뿐이고, 그 둘은
> 「할 수 없는 일」과 「깨진 기구」다 (`AGENTS.md` §2.1).

`reduce(state, action) → { state, outcome, message, tag }` 이고 `outcome` 은 셋뿐이다.

| 결과 | 뜻 |
|---|---|
| `ok` | 뜻대로 됐다 |
| `happened` | 진행은 됐는데 뜻대로는 아니다. **이 실험의 대부분이 여기다** |
| `blocked` | 진행되지 않았다. **아래 두 줄에만** |

---

## 1. 채혈

| # | 조작 | 잘못했을 때 — **결과가 답한다** |
|---|---|---|
| R-01 | `SWAB_FINGER` 손끝을 소독한다 | 건너뛰어도 진행된다. **안전 기록에 남는다** (감점이 아니라 기록) |
| R-02 | `PICK_CAPILLARY({kind})` 모세관을 고른다 | **헤파린 / 민무늬 — 이 실험의 변인 하나다.** 민무늬를 골라도 막지 않는다. 돌리는 동안 응고해 층이 안 갈리고, 위에 뜨는 것은 혈장이 아니라 **혈청**이 된다 |
| R-03 | `PRICK_FINGER` 채혈침으로 톡 | 소독을 안 했으면 기록에 남는다. **쓴 침을 다시 쓰면** 그것도 기록에 남는다. 여러 번 찔러도 막지 않는다 |
| R-04 | `DRAW_BLOOD({angleDeg, dwell})` 빨아올린다 | **비스듬히 대야 들어온다.** 수직으로 세우면 공기가 함께 들어가 기둥에 **기포**가 생기고, 그 기포가 나중에 길이를 잴 때 오차가 된다. 짧게 대면 기둥이 짧다 |
| R-05 | 핏방울을 오래 두었다 빨아올린다 | 손끝에 맺힌 피는 굳기 시작한다. **헤파린 모세관이라도** 이미 굳기 시작한 피는 되돌릴 수 없다 |

## 2. 밀봉

| # | 조작 | 잘못했을 때 |
|---|---|---|
| R-06 | `SEAL_END({end, press})` 고무찰흙에 눌러 막는다 | 얕게 누르면 **샌다** — 돌리는 동안 혈액이 빠져 기둥이 짧아진다. 새는 양은 **속도의 제곱**에 비례한다 |
| R-07 | 너무 세게 누른다 | **유리가 부러진다.** ← 막는 둘 중 하나 (`BROKEN`). 빠져나갈 길: 선반의 모세관 통에서 새것을 꺼낸다 |
| R-08 | `PEEL_CLAY({end})` 고무찰흙을 뗀다 | 잘못 막았을 때 되돌아가는 길. 언제든 다시 막을 수 있다 |
| R-09 | 한쪽만 막고 돌린다 | 막지 않는다. 안 막은 쪽으로 그대로 날아간다 |

## 3. 회전판

| # | 조작 | 잘못했을 때 |
|---|---|---|
| R-10 | `LOAD_ROTOR({slot, what})` 빨대에 넣는다 | **돌고 있으면 넣을 수 없다.** ← `IMPOSSIBLE`. 빠져나갈 길: 회전판을 손으로 감싸 멈춘다(`STOP_ROTOR`) |
| R-11 | 반대쪽을 비운 채 돌린다 | 막지 않는다. **흔들린다** — 층이 흐리게 섞이고, 흔들리는 회전판은 같은 힘으로 덜 빨라진다 |
| R-12 | `SEAT({slot, depth})` 밀어 넣는 깊이를 맞춘다 | 두 쪽의 깊이가 다르면 무게 중심이 어긋나 그만큼 흔들린다 |
| R-13 | `PULL({strength})` 끈을 당겼다 놓는다 | **박자가 맞아야 빨라진다.** 반대 박에 당기면 돌고 있는 회전판을 거스르게 되어 **오히려 느려진다.** 그리고 빨라질수록 박자가 잦아진다 — 손을 더 빨리 놀려야 한다 |
| R-14 | 약하게 · 짧게 당기고 만다 | 막지 않는다. **덜 갈린다** — 붉은 부분이 실제 헤마토크릿보다 길게 남아 학생이 값을 **과대평가**한다. 그 과대평가가 "왜 더 돌려야 하는가" 를 말해 준다 |
| R-15 | `STOP_ROTOR` 손으로 감싸 멈춘다 | 언제든 된다. 되돌아가는 길이다 |
| R-16 | `UNLOAD({slot})` 꺼낸다 | **돌고 있는데 손을 대면 모세관이 부러진다.** ← `BROKEN`. 빠져나갈 길: 먼저 멈추고, 부러졌으면 새것을 꺼낸다 |

## 4. 재기와 기록

| # | 조작 | 잘못했을 때 |
|---|---|---|
| R-17 | `MEASURE` 자를 댄다 | 기둥이 짧거나 기포가 많으면 **어디까지가 혈액인지 애매해진다.** 막지 않는다 |
| R-18 | `LIFT_RULER` 자를 치운다 | |
| R-19 | `CAPTURE` 결과를 기록한다 | 흐린 결과도 기록된다. 정리 단계에서 왜 흐렸는지 스스로 적게 한다 |
| R-20 | `DELETE_CAPTURE({at})` 기록을 지운다 | 무엇을 근거로 삼을지 고르는 일이다. 관찰을 무르는 것이 아니다 |
| R-21 | `NEW_CAPILLARY` 새 모세관을 꺼낸다 | **막다른 길에서 빠져나오는 길.** 통에 넉넉히 들어 있어 바닥나지 않는다 |

## 5. 안전과 정리 — **조작으로 두지 않는다 (R-22~R-26 걷어냄)**

사장님 지시로 **안전 조작을 통째로 걷어냈다.** 아래 다섯은 한때 조작이었고 지금은
**코드에 없다.** 안전 수칙은 **준비물(2쪽)에 적어 두기만 하고, 이 앱은 그것을 지켰는지
확인하지 않는다** — 그 사실도 화면에 적혀 있다.

**표에서 지우지 않고 남겨 둔다.** 지우면 다음 사람이 「코드에 없고 문서에도 없으니
새로 만들 것」으로 읽는다. 여기 남겨 두면 **「없애기로 한 것」**임을 안다.
(「코드에 없음 · 문서에 있음」은 보통 **배선이 빠진 것**이라 다시 이으라는 뜻이 된다 —
 R-18 이 그 경우다. 아래 다섯은 그 반대이므로 갈라 적는다)

| # | 걷어낸 조작 | 지금은 |
|---|---|---|
| ~~R-22~~ | `WIPE_FINGER` 휴지로 눌러 지혈한다 | 2쪽 안내로만 |
| ~~R-23~~ | `DISPOSE_LANCET` 채혈침을 손상성 폐기물 통에 | 2쪽 안내로만 |
| ~~R-24~~ | `DISPOSE_TUBE` 쓴 모세관을 폐기물 통에 | 폐기물 통은 남았으나 **되돌리는 길**이다(`NEW_CAPILLARY`) |
| ~~R-25~~ | `WASH_HANDS` 손을 씻는다 | 2쪽 안내로만 |
| ~~R-26~~ | `CHECK_TIDY` 마칠 때 정리를 했는지 본다 | 세지 않는다. 자기 평가의 「안전 수칙을 지켰다」 항목은 **선생님 판단으로 남겨 두었다** |

## 막는 것은 이 둘뿐이다

| 사유 | 어디서 | 빠져나갈 길이 문장에 있는가 |
|---|---|---|
| `IMPOSSIBLE` | 돌고 있는 회전판에 모세관 넣기 (R-10) | 「회전판을 손으로 감싸 멈춘 뒤 넣으세요」 |
| `BROKEN` | 부러진 모세관을 쓰기 (R-07 · R-16) | 「선반의 **모세관 통**에서 새것을 꺼내세요」 |

**「새것을 꺼내세요」로는 어디서 꺼내는지 알 수 없다.** 어디로 가야 하는지까지 말한다.
`tests/rules.test.js` 가 모든 액션을 여러 상태에서 돌려 보고, `blocked` 가 나오면
사유가 이 둘 중 하나인지와 **문장에 빠져나갈 길이 담겼는지**를 본다.

## 되돌아갈 길

새 조작을 넣을 때마다 **"이걸 잘못하면 어떻게 되돌아오나"** 를 같이 정한다.

| 잘못한 것 | 되돌아가는 길 |
|---|---|
| 기둥을 짧게 빨아올렸다 | 다시 빨아올린다 (핏방울이 남아 있으면) · 새 모세관 |
| 밀봉이 얕다 | `PEEL_CLAY` 로 떼고 다시 막는다 |
| 모세관이 부러졌다 | `NEW_CAPILLARY` — 선반의 모세관 통 |
| 균형을 안 맞추고 돌렸다 | `STOP_ROTOR` → 빈 모세관을 반대쪽에 넣는다 |
| 덜 돌렸다 | 더 당긴다. 이미 갈린 것은 그대로 있다 |
| 헤파린 없는 것을 골랐다 | 새 모세관을 헤파린 통에서 꺼낸다 |
| 핏방울이 말랐다 | 다시 채혈한다 (침은 새것으로) |

**소모품은 바닥나지 않는다.** 바닥나면 그건 결과가 아니라 막다른 길이다.
