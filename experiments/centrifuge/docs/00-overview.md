# 00 · 프로젝트 개요

## 무엇을 만드나

고등학교 『세포와 물질대사』 탐구활동 **「간이 원심분리기로 혈액 원심분리하기」**(24쪽)를
브라우저에서 수행하는 탐구형 가상실험.

**이 실험은 재구성이다.** 교과서 1단계인 종이 회전판 **제작(공작)** 은 만들지 않는다 —
오리고 붙이는 것은 절차의 질이 결과로 드러나지 않아 가상화할 이득이 없다.
회전판은 완성품으로 주고, 실험은 혈액 원심분리(2단계)부터다.
대신 종이 원심분리기(paperfuge)의 핵심인 **「끈을 당기는 리듬」** 을 조작으로 살렸다.

교과서 지면:

- 목표 — 간이 원심분리기로 혈액을 분리하고, 갈라진 층을 관찰할 수 있다
- 문제 인식 — 혈액을 원심분리하면 어떻게 될까? 갈라진 것들은 각각 무엇일까?
- 탐구 과정 — 손끝 소독 → 채혈 → 모세관에 빨아올리기 → 양끝 밀봉 →
  회전판에 물리고 균형 맞추기 → 끈을 리듬 있게 당기기 → 자로 층 길이 재기

## 무엇을 관찰하나

모세관은 회전판에 **수평으로** 물린다. 교과서 그림의 「아래」는 회전 **바깥쪽** 끝이고,
혈장은 **축 쪽**이다. 위/아래로 적으면 그리는 사람이 반드시 뒤집는다.

| 층 | 색 | 비율 |
|---|---|---|
| 적혈구층 (바깥쪽) | **암적색** | 약 45 %(남) · 40 %(여) |
| 연층(백혈구·혈소판) | **회백색** | 1 % 미만 |
| 혈장 (축 쪽) | 담황색 | 약 55 % |

적혈구층이 전체 혈액 기둥에서 차지하는 비율이 **헤마토크릿**이다.
**앱은 그 값을 화면에 먼저 말하지 않는다** — 학생이 자로 두 길이를 재어 스스로 나눈다.

## 이 실험의 변인

| 변인 | 어디서 정하나 | 잘못하면 |
|---|---|---|
| 모세관에 헤파린이 발려 있는가 | 실험대에서 모세관 통을 눌러 고른다 | 응고해 층이 안 갈리고, 위층이 **혈청**이 된다 |
| 모세관을 댄 각도 | 확대 뷰에서 좌우로 끈다 | 세우면 공기가 들어가 기포가 낀다 |
| 고무찰흙을 누른 깊이 | 확대 뷰에서 아래로 끈다 | 얕으면 새고, 세면 유리가 부러진다 |
| 반대쪽 균형 | 빈 모세관을 넣고 깊이를 맞춘다 | 흔들려 층이 흐리게 섞인다 |
| **당기는 세기와 박자** | 확대 뷰에서 링을 끌었다 놓는다 | 덜 갈려 헤마토크릿을 **과대평가**한다 |

## 층

```
src/style/     아트 디렉션 토큰 + 이 실험의 색 (palette.experiment.js)
src/assets/    SVG 애셋(형태) + 계약(contract.js)
src/sim/       회전 물리(spin.js) · 상태 · 규칙 · 품질 — DOM 을 모른다
src/render/    결과 렌더러(tube.js) — 상태를 받아 모세관의 층을 그린다
src/ui/        조작 UI · 확대 뷰 · 탐구 노트 · 문자열
```

## 없는 것 — 그리고 왜 없는가

- **시계.** 회전 시간의 실제 값이 `[확인 필요]` 다. 손으로 돌리는 원심분리기로 혈장이
  분리된다는 것 자체는 실증돼 있지만(paperfuge, *Nature Biomedical Engineering* 2017),
  그 논문의 1.5분은 **연구 장비 기준**이라 학생 활동 수치로 쓸 수 없다.
- **회전수(rpm).** 같은 이유다. 화면은 「느리게 돎 / 꽤 빠르게 돎」처럼 눈으로 본 것만 말한다.
- **「몇 번 당기세요」.** 그 수도 `[확인 필요]` 다. 절차 판정도 횟수가 아니라
  **층이 갈렸는가**로 본다 (`src/sim/progress.js`).
- **현미경.** 이 실험에는 없다. `optics.js` 자리에 `spin.js` 가 왔다.
