# T04 · 실험대 조작 UI

## 목표

실험대에서 실제로 플레이할 수 있게 만든다. **어포던스까지 한 카드로 끝낸다** —
기능만 넣고 끝내면 "이거 어떻게 하는 거야?" 를 듣는다 (`PLAYBOOK.md` §4).

## 실험대에 놓일 것

적양파 비늘잎 · 해부칼 · 핀셋 · 받침 유리(통) · 덮개 유리(통) · 스포이트 ·
**증류수 병 · 설탕 용액 병 4종(5·10·15·20 %)** · **거름종이** · 현미경 ·
페트리 접시 · 폐액통 · 개수대 · 쓰레기통 · 휴지

## 실험대 / 확대 뷰 경계

**변인은 손이 정해야 한다.** 이 실험의 변인은 셋이다.

| 변인 | 어디서 정하는가 |
|---|---|
| **어느 면을 벗기는가** (바깥/안쪽) | 확대 뷰 — 비늘잎을 뒤집어 고른다 |
| **어느 농도를 쓰는가** | 실험대 — 어느 병을 집는가 |
| **거름종이를 몇 번 대는가** | 실험대에서 끌어다 대거나, 현미경 확대 뷰의 단추로 |

봉입 방울 수와 덮개 유리 각도는 바나나랩 그대로 확대 뷰에서 정한다.

## 조작표는 한 곳에만

`dropTable()` · `tapTable()` 두 표가 **셋에 함께 쓰인다** — 실제 실행 · 드래그 중 대상
강조 · 안내 문구 유무. 세 곳에 따로 적으면 조작을 하나 늘릴 때마다 어긋난다.

표는 **종류 쌍**으로만 적고 상태는 보지 않는다. 빈 핀셋을 받침 유리에 대면
규칙 엔진이 "핀셋이 비어 있습니다" 라고 답해 주는데, **그 답을 듣는 것이 배우는 내용이다.**

## 되돌아갈 길 (막다른 길을 만들지 않는다)

- **재물대에 올린 채로도 치환에 닿아야 한다.** 올린 받침 유리는 실험대에서 사라지고,
  이 실험의 치환은 원래 **보면서 하는 일**이다. 직접 플레이해서 막혀 있는 것을 잡았다
- 잘못 만든 슬라이드 → `RINSE_SLIDE` (개수대)
- 금 간 슬라이드 → `NEW_SLIDE` (받침 유리 통)
- 잘못 덮은 덮개 유리 → `LIFT_COVERSLIP` → `DISCARD_COVERSLIP` (쓰레기통)
- 더러워진 렌즈 → `CLEAN_LENS` (휴지)
- **안쪽 표피를 벗겼을 때** → 비늘잎에서 다시 벗긴다. 비늘잎이 바닥나지 않게 할 것
- **거름종이** 도 바닥나지 않게 할 것. 여러 번 치환하는 것이 이 실험의 정상 경로다

## 하지 말 것

- 잡는 영역을 프레임으로 판정하기 — `CONTENT_BOX` 를 쓴다 (`NEW-EXPERIMENT.md` §7-1)
- DOM 참조를 붙잡아 두기 — 다시 그릴 때마다 죽는다. 그때그때 조회한다
- 포인터 이벤트만 듣기 — `element.click()` 이 아무 일도 안 해서 보조기기가 막힌다
- 잡는 영역 44 px 미만
- 버튼을 `disabled` 로 막기 (`tests/ui.contract.test.js` 가 잡는다)

## 합격 기준

- [ ] `node scripts/check-bench.mjs` 통과
- [ ] 물건에 마우스를 올리면 **이름 + 지금 할 수 있는 조작**이 뜬다
- [ ] 끄는 동안 놓을 수 있는 곳이 강조되고, 지금 놓을 대상은 더 강하다
- [ ] 시간이 걸리는 조작(거름종이로 빨아들이기)에 진행 표시가 있다
- [ ] **직접 끝까지 플레이했다** — 칼집부터 원형질 분리 복귀 기록까지
- [ ] 다크 모드에서 버튼이 사라지지 않는다
- [ ] `?edit=1` 배치 편집 모드에서 조작이 일어나지 않는다
      (**되돌려서 실제로 실패하는지 확인할 것** — 모드를 껐다 켜도 결과가 같으면
       아무것도 안 보는 검사다. 바나나랩에서 실제로 그랬다)
