# 작업 카드 — 삼투 실험

번호 순서대로 진행한다. 카드 하나가 곧 한 번의 커밋 단위다.
카드 형식과 규칙은 바나나랩에서 그대로 물려받았다 (`docs/banana-tasks/README.md`).

각 카드는 같은 형식이다.

- **목표** — 무엇이 끝나야 하는가
- **먼저 읽을 것** — 이 카드를 하기 전에 반드시 읽는 문서
- **건드릴 파일** — 여기 없는 파일을 고쳐야 한다면 먼저 카드를 수정한다
- **하지 말 것** — 이 카드에서 자주 나오는 실수
- **합격 기준** — 체크박스. 한 줄씩 대조한다
- **검증** — 실제로 실행해서 통과를 확인하는 명령

## 규칙

1. 카드에 없는 일을 하고 싶으면 **먼저 카드를 추가**한 뒤 진행한다
2. 검증 명령이 실패한 상태로 카드를 닫지 않는다
3. 합격 기준에 "눈으로 확인"이 있으면 `npm run shot` 으로 실제 이미지를 남긴다
4. 카드를 닫을 때 이 파일의 진행표와 `PROGRESS.md` 를 갱신한다

## 이 실험에서 카드마다 되풀이해 확인할 것

- **막지 않았는가.** 새 `blocked` 는 파손·물리적 불가 둘뿐이다 (`AGENTS.md` §2.1)
- **되돌아갈 길이 있는가.** 새 조작을 넣을 때마다 "이걸 잘못하면 어떻게 되돌아오나"를 같이 정한다
- **화면이 답을 먼저 말하지 않는가.** 세포액 농도 추정이 이 실험의 탐구인데,
  화면 어딘가에 그 숫자가 적혀 있으면 탐구가 사라진다
