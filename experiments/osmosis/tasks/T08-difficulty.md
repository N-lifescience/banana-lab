# T08 · 난이도 세 단계

## 목표

**난이도는 설명만 줄인다. 할 수 있는 일은 세 단계가 똑같다.**

## 먼저 읽을 것

- `PLAYBOOK.md` §5

## 건드릴 파일

```
src/ui/start.js
src/ui/strings.js
src/ui/bench.js       힌트 분량만
tests/ui.contract.test.js
```

## 표

| | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 절차 제시 | 다음 할 일 강조 | 목록만 | 목표만 |
| 실패 안내 | 원인 + 다음 행동 | 원인만 | 원인만 |
| 말풍선 힌트 | 문장 | 짧은 구 | 이름만 |
| 예상 문항 | 선택형 | 반주관식 | 완전 주관식 |
| 되돌리기 | 무제한 | 3회 | 1회 |
| 기구 초기 설정 | 대신 맞춰 줌 | 직접 | 직접 |

## 하지 말 것

- 힌트를 줄여서 **길이 막히게** 하기. 그건 설명을 줄인 게 아니라 강제를 넣은 것이다
- 조작표가 난이도를 인자로 받게 하기

## 합격 기준

- [ ] 1단계와 3단계의 조작표 모양이 **같다** (테스트)
- [ ] `?level=2` · `?level=3` 으로 **실제로 들어가진다**
      (바나나랩에서 118개가 통과하는데 2·3단계에 **닿을 방법이 없었다**)
- [ ] 3단계에서 되돌리기가 사실상 죽어 있지 않다 — 직접 플레이해서 확인
- [ ] 1단계 자동 보조의 **순서**가 맞다. 저배율로 먼저 내린 뒤 초점을 맞춘다
      (`PLAYBOOK.md` §9-6 — 반대로 하면 올리자마자 슬라이드가 깨진다)
