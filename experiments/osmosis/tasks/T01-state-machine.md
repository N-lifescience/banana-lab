# T01 · 규칙표와 상태 머신

## 목표

UI 없이 상태 머신만으로 이 실험의 정상 경로와 **모든 실패 경로**를 통과시킨다.
바나나랩의 `src/sim/` 이 뼈대로 남아 있다 — 삼분법(`ok`/`happened`/`blocked`)과
되돌리기·로그·스냅샷은 그대로 쓰고, **실험 내용을 전부 갈아 끼운다.**

## 먼저 읽을 것

- `AGENTS.md` §2.1 (강제하지 말고 결과로 답한다) · §2.4 · §2.5 (**과학적 사실**)
- `docs/04-interaction-rules.md` — 이 카드에서 **먼저 이 문서를 이 실험 것으로 다시 쓴다.**
  표를 먼저 적고 그 표를 코드로 옮긴다. 반대로 하면 규칙이 코드 안에 흩어진다

## 건드릴 파일

## 이 실험의 조작 (규칙표에 그대로 옮길 것)

| # | 조작 | 잘못했을 때 결과가 어떻게 답하는가 |
|---|---|---|
| R-01 | `CUT_SCALE` 비늘잎에 5×5 mm 칼집 | 칼집이 없으면 표피가 통째로 찢겨 두껍게 벗겨진다 |
| R-02 | `PEEL_EPIDERMIS` 핀셋으로 표피 벗기기 (**바깥쪽/안쪽**) | **안쪽이면 색소가 없어 시야에 색이 없다.** 이 실험의 핵심 실패다 |
| R-03 | `PLACE_SAMPLE` 받침 유리에 올리기 | 접혀 올리면 겹쳐 보인다 |
| R-04 | `FILL_DROPPER` / `RINSE_DROPPER` 스포이트 | 안 씻고 다른 용액을 담으면 농도가 섞인다 |
| R-05 | `DROP` 증류수 봉입 | 모자라면 일부만 잠기고, 넘치면 덮개 유리가 뜬다 |
| R-06 | `PICK_COVERSLIP` / `PLACE_COVERSLIP` 각도 | 45° 에서 벗어나면 기포 |
| R-07 | `MOUNT` / `UNMOUNT` 재물대 | 덮개 유리 없이 올리면 고배율에서 렌즈가 시료에 닿는다 |
| R-08 | `SET_OBJECTIVE` · `COARSE_FOCUS` · `FINE_FOCUS` · `SET_DIAPHRAGM` · `MOVE_STAGE` | 바나나랩 그대로 |
| R-09 | `APPLY_SOLUTION` 덮개 유리 **한쪽**에 용액 | **여기까지만 하면 아무 일도 안 일어난다.** 액이 들어가지 않는다 |
| R-10 | `WICK` 반대쪽에 **거름종이** | 이것을 해야 치환이 진행된다. 한 번으로는 덜 바뀐다 |
| R-11 | `TICK` 시간 경과 | 삼투는 즉시가 아니다. 덜 기다리면 중간 상태가 보인다 |
| R-12 | `CAPTURE` 결과 기록 | 흐린 상도 기록된다. 막지 않는다 |
| R-13 | `RINSE_SLIDE` · `NEW_SLIDE` · `LIFT_COVERSLIP` · `DISCARD_COVERSLIP` · `CLEAN_LENS` | **되돌아갈 길** |
| R-14 | `WASH_HANDS` · `CLOSE_CAP` · `DISPOSE_WASTE` · `CHECK_TIDY` | 정리. 감점 없이 기록만 |
| R-15 | `SAVE_NOTE` · `MARK_READ` · `DELETE_CAPTURE` · `UNDO` | 바나나랩 그대로 |

## 할 일

1. `docs/04-interaction-rules.md` 를 이 실험 것으로 다시 쓴다. 위 표가 출발점이다
2. `src/sim/osmosis.js` — 삼투 모형과 상수
   - 쓰는 용액: 증류수 + 설탕 용액 5 · 10 · 15 · 20 %
   - 세포마다 세포액 농도가 조금씩 다르다 (**시드로 결정**). 그래야
     「절반이 원형질분리를 일으키는 농도」라는 판정이 성립한다 (`AGENTS.md` §2.5)
   - 원형질체 부피비 · 원형질분리 세포 비율을 순수 함수로 낸다
   - **출처를 대지 못하는 값은 `[확인 필요]` 로 표시하고 화면에 숫자로 내보내지 않는다**
3. `state.js` — 슬라이드 스키마를 갈아 끼운다
   `sample: { side, thickness, folded }` · `medium` · `pendingSolution` · `exchange` · `osmosisT` 등
4. `rules.js` — 위 표의 액션. 바나나 전용(`PEEL_BANANA`·`SMEAR`)은 지운다
5. `quality.js` — 이 실험의 관찰 가능성. **배율 적합도**를 다시 정한다
   (세포 윤곽과 원형질체 틈을 보는 관찰이라 400배가 꼭 필요한지 다시 판단할 것)
6. `optics.js` — 양파 표피세포 치수. 확실하지 않으면 `[확인 필요]`
7. 정상 경로 통합 테스트: 칼집 → 바깥쪽 표피 → 올리기 → 증류수 봉입 → 덮개(45°) →
   재물대 → 저배율 초점 → 배율 올리기 → 기록 → 설탕 용액 적용 → 거름종이 → 기다림 →
   기록 → 증류수로 되돌림 → 기록

## 하지 말 것

- `blocked` 를 새로 추가하지 말 것. `BLOCKING_REASONS` 두 가지 외에는 `blocked()` 가 던진다
- `src/sim/` 안에서 `document` · `window` · `Date.now()` · `Math.random()` 을 쓰지 말 것
- `reduce` 안에서 원본 상태를 변형하지 말 것 (테스트가 잡는다)
- **거름종이를 대지 않았다고 「거름종이를 대세요」로 막지 말 것.** 액이 안 들어가서
  시야가 그대로인 것을 보여 준다
- **안쪽 표피를 막지 말 것.** 색이 없는 시야를 보여 준다. 그것이 이 실험이 가르치는 것이다
