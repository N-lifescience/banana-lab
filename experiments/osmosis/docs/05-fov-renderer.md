# 05 · 현미경 시야 렌더러

> **세포에서 일어나는 삼투 현상 관찰하기** (id: `osmosis`)

## 원칙

시야는 미리 그린 그림이 아니라 **상태에서 매번 생성**한다. 그래야:

- 배율·초점·농도를 바꾼 결과가 정직하게 반영된다
- 결과 보드가 이미지 대신 시드만 저장할 수 있다 (07번 문서)
- 같은 학생이 다시 열어도 같은 그림이 나온다

아트 디렉션(라인+플랫)은 **여기 적용되지 않는다.** 시야는 광학 시뮬레이션이라 굵은 외곽선을
쓰지 않는다. 다만 액포색은 `palette.experiment.js` 를 공유한다.

## 이 시야가 지켜야 하는 것 — 여기가 틀리면 전부 무의미하다

1. **보라색 영역의 크기 = 원형질체의 크기.** 안토시아닌이 액포에 있기 때문이다
2. **세포벽은 그 자리에 그대로 있다.** 줄어드는 것은 원형질체뿐이다.
   `tests/fov.test.js` 가 증류수 시야와 20 % 시야의 **세포벽 사각형 좌표가 같은지**로 못 박는다
3. 원형질체와 세포벽 사이의 **틈은 바깥 용액으로 차 있다** (세포벽은 전투과성)
4. **터지지 않는다.** 저장액에서는 세포벽까지 꽉 찰 뿐이다
5. **한 시야 안에서 세포마다 정도가 갈린다** — 「절반이 원형질분리」 판정이 여기서 나온다
6. `side === 'inner'` 면 액포색이 없다. 세포벽 윤곽만 희미하게 보인다

## 광학 — 임의로 바꾸지 말 것

접안렌즈 시야수(FN) 18 mm 기준.

```
시야 지름(µm) = 18000 / 대물배율
pxPerUm       = 시야원 지름(px) / 시야 지름(µm)
```

| 대물 | 총배율 | 시야 지름 | 시야 안 세포 수 | 원형질체 틈 |
|---|---|---|---|---|
| 4× | 40배 | 4500 µm | 약 660개 | 갈라 보이지 않는다 |
| 10× | 100배 | 1800 µm | 약 106개 | **보이고 셀 수 있다 — 이 관찰의 자리** |
| 40× | 400배 | 450 µm | 약 7개 | 잘 보이지만 **비율을 잴 수 없다** |

**이 실험의 최적 배율은 400배가 아니라 100배다.** 재는 것이 「세포 몇 개 중 몇 개」라
시야에 셀 만큼의 세포가 있어야 한다. 바나나랩에서 그대로 베껴 오면 안 되는 곳이다
(`src/sim/quality.js` 의 `magnificationFactor`).

실물 치수 — **[확인 필요]**:

- 양파 표피세포 긴 변 **300 µm** · 짧은 변 **80 µm** · 세포벽 **3 µm**

1차 출처를 대지 못했다. 확실한 것은 **모양**이다 — 길쭉하고 긴 변:짧은 변이 3~4:1 이며,
세포벽이 또렷한 격자를 이룬다. 그 비가 위 표의 「시야 안 세포 수」를 정하므로
`tests/optics.test.js` 가 값과 비를 함께 고정한다. **이 숫자는 화면에 나오지 않는다** —
시야 아래에 적히는 것은 시야 지름뿐이다.

## 원형질체는 등방으로 줄지 않는다

부피비를 세제곱근으로 모든 방향에 똑같이 나누면 **100배에서 15 % 원형질분리가 안 보인다.**
실제로는 원형질체가 벽에서 떨어지며 둥글게 뭉쳐 **긴 변 쪽 끝에서 훨씬 많이 물러난다.**
실제 시야에서 원형질분리가 「양쪽 끝이 오므라든」 모습으로 보이는 것이 그래서다.

```js
protoplastAxes(ratio) = { long: ratio ** 0.75, short: ratio ** 0.25 }
// 두 지수를 더하면 1 — 넓이비는 그대로 부피비를 따른다
```

## 생성 규칙

| 요소 | 규칙 |
|---|---|
| 세포벽 격자 | 길쭉한 벽돌. 가로 `300 µm × pxPerUm`, 세로 `80 µm × pxPerUm`. 줄마다 이음매를 어긋나게 |
| 세포액 농도 | 세포마다 `CELL_SAP_PCT ± SPREAD` 삼각분포. **0 이면 이 실험이 성립하지 않는다** |
| 원형질체 | 세포 안쪽에 둥근 사각형. 크기는 위 `protoplastAxes` |
| 액포색 | 두 단만 — `vacuole` · `vacuoleDeep`. 수축하면 **같은 색이 짙어진다.** 색이 바뀌면 학생이 「반응」으로 읽는다 |
| 틈 | 원형질체가 물러난 자리에 바깥 용액색 층. **비어 있지 않다** |
| 핵 | 짧은 변이 9 px 이상일 때만. 그보다 작으면 점 하나로 뭉개져 개수만 는다 |
| 마른 곳 | `coverage < 1` 이면 잠기지 않은 자리는 뿌옇고, 그 세포는 삼투가 일어나지 않는다 |
| 접힘 | 띠 하나에 세포가 한 겹 더 겹쳐 보인다 |
| 두꺼운 표피 | 시야 전체가 한 겹 겹쳐 보이고 어두워진다 |
| 초점 흐림 | `blur = focusErr × 22 px` |
| 광량 | 검은 오버레이 `(1 − brightness) × 0.55` |
| 기포 | 굵고 짙은 테두리의 큰 원 |
| 넘침 | 덮개 유리가 떠서 상이 8 px 어긋나 겹친다 |
| 렌즈 오염 | 한쪽에 얼룩진 타원 |

## 절대 하면 안 되는 것

- **세포벽을 함께 수축시키지 말 것.** 이 실험을 통째로 거꾸로 가르친다
- **저장액에서 세포를 터뜨리지 말 것.** 세포벽이 있다
- **농도마다 배경색을 달리 칠하지 말 것.** 농도는 색이 아니라 원형질체의 크기로만 나타난다.
  색으로 가르면 학생이 현미경을 보기 전에 답을 고른다 (`tests/fov.test.js` 가 잡는다)
- **시야에 비율이나 농도를 숫자로 적지 말 것.** 세는 것이 학생의 일이다
- `Math.random()` — 같은 상태가 같은 그림을 내야 한다
- 렌더러 안에서 `id` 를 하드코딩하지 말 것. 한 화면에 여러 시야를 그리는 순간
  **에러 없이 조용히** 틀린다. `idPrefix` 를 받는다
