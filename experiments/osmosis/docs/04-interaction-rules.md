# 04 · 조작 규칙 — 강제에서 귀결로

> **세포에서 일어나는 삼투 현상 관찰하기** (id: `osmosis`)

**이 문서가 프로젝트의 핵심이다.**

## 원칙

초기 설계에서는 전제조건을 만족하지 못하면 진행을 막았다. 그러나 학생은 절차대로만 하지 않는다.
막아 버리면 배우는 것은 "정해진 대로 눌러야 넘어간다"뿐이고, 실험하는 느낌도 사라진다.

> **거의 모든 조작을 허용하고, 대신 결과로 답한다.**

이 실험에서 그 원칙이 가장 크게 걸리는 자리는 셋이다.

1. **안쪽 표피를 벗기는 것을 막지 않는다.** 색소가 없는 시야를 보여 준다.
   그것을 보고 「아, 색이 있어야 크기를 볼 수 있구나」를 아는 것이 이 실험이 가르치는 것이다.
2. **거름종이를 안 대도 막지 않는다.** 액이 가장자리에 고여 있고 시야는 그대로다.
   「용액을 떨어뜨렸는데 왜 안 변하지」에서 치환이 무엇인지가 나온다.
3. **평형에 닿기 전에 기록해도 막지 않는다.** 중간 상태가 그대로 기록된다.

## 결과 종류는 셋뿐

| outcome | 뜻 |
|---|---|
| `ok` | 진행됐다. 무엇이 바뀌었는지만 말한다 |
| `happened` | 진행됐다. 다만 뜻대로는 아니다 — **대부분 여기 해당** |
| `blocked` | 진행되지 않았다 — **아래 두 사유에만 허용** |

**정상 경로에서는 `happened` 가 한 번도 나오지 않아야 한다.**
제대로 하고 있는데 매번 경고가 뜨면 학생은 경고를 읽지 않게 된다.
`tests/rules.test.js` 의 통합 테스트가 이것을 지킨다 — 실제로 여기서
「거름종이를 한 번 댔다」가 경고로 잡히는 것을 발견하고 `ok` 로 고쳤다.
**한 번에 다 안 바뀌는 것이 정상이다.**

## 하드 게이트가 허용되는 단 두 가지

```js
BLOCKING_REASONS = {
  IMPOSSIBLE: 'impossible',  // 물리적으로 성립하지 않음
  BROKEN:     'broken',      // 기구가 파손돼 재제작이 필요함
}
```

이 외의 사유로 `blocked` 를 돌려주면 `rules.js` 의 `blocked()` 헬퍼가 **던진다.**
그리고 `tests/rules.test.js` 의 「하드 게이트는 두 종류뿐이다」가 모든 액션을 여러 상태에서
훑어 다시 검사한다. 새 하드 게이트가 필요하다고 판단되면 **코드를 고치지 말고 사람에게 물어본다.**

지금 이 실험에서 `blocked` 는 **한 곳뿐이다** — 금 간 슬라이드를 재물대에 올리려 할 때.
그리고 그 문장에는 **어디로 가야 하는지**가 들어 있다("받침 유리 통에서 새것을 꺼내").

## 용액 치환 — 이 실험의 중심

```
APPLY_SOLUTION   덮개 유리 한쪽에 용액을 댄다   →  slide.pending 에 고인다. 아래는 그대로
WICK             반대쪽에 거름종이를 댄다        →  exchange += 0.5
                 exchange 가 1이 되면            →  medium = pending
```

치환이 덜 됐을 때 덮개 유리 아래에 실제로 있는 농도는 **섞인 농도**다.

```js
effectivePct = mediumPct + (pendingPct − mediumPct) × exchange
```

| 거름종이 | exchange | 증류수 → 20 % 일 때 실제 농도 | 학생이 보게 되는 것 |
|---|---|---|---|
| 0회 | 0.0 | 0 % | 아무 변화 없음. 액만 가장자리에 맺혀 있다 |
| 1회 | 0.5 | 10 % | 몇몇 세포만 갈라진다. **어중간한 결과** |
| 2회 | 1.0 | 20 % | 거의 모든 세포가 갈라진다 |

## 삼투는 즉시 일어나지 않는다

세포가 지금 평형을 이루고 있는 농도를 `slide.equivPct` 스칼라 하나로 둔다.
`TICK` 이 이 값을 덮개 유리 아래 농도 쪽으로 지수적으로 옮긴다.

이렇게 두면 학생이 평형에 닿기 전에 용액을 또 바꿔도 자연스럽게 이어진다 —
「직전 평형」을 따로 기억할 필요가 없다.

## 원형질체 — 무엇이 줄고 무엇이 안 주는가

```js
protoplastRatio(바깥 농도, 세포액 농도)
  바깥 ≤ 세포액  →  1        세포벽이 버틴다. 팽압만 오른다. **터지지 않는다**
  바깥 > 세포액  →  세포액 / 바깥   반트호프. 벽에서 떨어져 눌리지 않는다
```

**세포벽은 줄지 않는다.** 이것을 `tests/fov.test.js` 가 좌표로 못 박는다 —
증류수 시야와 20 % 시야의 세포벽 사각형이 **완전히 같아야** 통과한다.

원형질체는 등방으로 줄지 않는다. 벽에서 떨어지며 **둥글게 뭉치기 때문에 긴 변 쪽 끝에서
훨씬 많이 물러난다** (`osmosis.protoplastAxes`). 실제 시야에서 원형질분리가
「양쪽 끝이 오므라든」 모습으로 보이는 것이 그래서다.

**세포마다 세포액 농도가 다르다** (`sapPct`). 이것이 0 이면 모든 세포가 한꺼번에
갈라져 「절반이 원형질분리를 일으키는 농도」라는 판정 자체가 사라진다.

## 봉입액 방울 수 — 연속 반응 곡선

"두 방울"은 지시이지 조건이 아니다.

```js
coverage = min(drops / 2, 1)
excess   = clamp((drops − 2) / 3, 0, 1)
```

| 방울 | coverage | excess | 학생이 보게 되는 것 |
|---|---|---|---|
| 0 | 0.00 | 0.00 | 마른 채로 덮인다. 뿌옇고 대비가 죽는다 |
| 1 | 0.50 | 0.00 | 잠긴 자리만 삼투가 일어난다. **시야 안에 경계가 보인다** |
| 2 | 1.00 | 0.00 | 표피 전체가 잠긴다 |
| 3–4 | 1.00 | 0.33~0.67 | 액이 넉넉해 뿌예진다 |
| 5+ | 1.00 | 1.00 | 넘쳐서 덮개 유리가 뜬다. 상이 둘로 겹친다 |

## 규칙표

행은 두 종류다. **조작**은 학생이 직접 일으키는 액션이고,
**자동 판정**은 독립 액션이 아니라 다른 액션 안에서 도는 판정이다.

| ID | 종류 | 조작 · 판정 | 어디서 도는가 | 순진한 설계 (강제) | 이 프로젝트 (귀결) |
|---|---|---|---|---|---|
| R-01 | 조작 | 비늘잎에 5×5 mm 칼집 | `CUT_SCALE` | — | 진행된다. 칼집은 한 조각에 한 번 쓰인다 |
| R-02 | 조작 | 표피를 벗긴다 (**바깥/안쪽**) | `PEEL_EPIDERMIS` | 안쪽 선택 차단 | 진행된다. **안쪽이면 색소가 없어 크기를 볼 수 없다** |
| R-03 | 자동 판정 | 칼집 없이 벗기기 | `PEEL_EPIDERMIS` 안의 `cut` | 진행 차단 | 두께가 `UNCUT_MIN_THICKNESS` 아래로 못 내려간다. 세포가 겹쳐 보인다 |
| R-04 | 조작 | 받침 유리에 올린다 | `PLACE_SAMPLE` | 접힘 차단 | 진행된다. 접힌 자리는 세포가 겹쳐 보인다 |
| R-05 | 조작 | 스포이트를 채운다 | `FILL_DROPPER` | — | 씻지 않았으면 **나가는 농도가 이름표와 달라진다**(`pct`) |
| R-06 | 조작 | 봉입액을 n방울 | `DROP` | 진행 차단 | 진행된다. 위 곡선대로 시야가 달라진다 |
| R-07 | 조작 | 덮개 유리를 덮는다 | `PLACE_COVERSLIP` | 경고 | 각도로 기포가 정해진다 |
| R-08 | 조작 | 덮개 유리 한쪽에 용액 | `APPLY_SOLUTION` | 「거름종이를 먼저」 안내 | **아무 일도 안 일어난다.** 액이 가장자리에 고인다 |
| R-09 | 조작 | 반대쪽에 거름종이 | `WICK` | — | 치환이 진행된다. 한 번이면 섞인 농도 |
| R-10 | 조작 | 시간 경과 | `TICK` | 자동 완료 | 삼투가 지수적으로 진행된다. 덜 기다린 중간 상태도 보인다 |
| R-11 | 조작 | 덮개 유리 없이 재물대 | `MOUNT` | 차단 | 진행된다. 400배로 올리면 렌즈가 시료에 닿는다 |
| R-12 | 조작 | 저배율을 건너뛰고 400배 | `SET_OBJECTIVE` | 차단 | 진행된다. **초점 허용 범위가 1/10** 이라 사실상 못 찾는다 |
| R-13 | 조작 | 고배율에서 조동나사 | `COARSE_FOCUS` | 차단 | **슬라이드에 금이 간다.** 허용된 하드 귀결 |
| R-14 | 조작 | 조리개를 닫은 채 관찰 | `SET_DIAPHRAGM` | 경고 | 진행된다. 어두워서 원형질체 경계가 안 보인다 |
| R-15 | 조작 | 평형 전에 결과 기록 | `CAPTURE` | 차단 | 허용한다. `settled: false` 로 남고 정리 단계에서 묻는다 |

되돌아갈 길 (**막다른 길을 만들지 않는다**):
`RINSE_SLIDE` · `NEW_SLIDE` · `LIFT_COVERSLIP` · `DISCARD_COVERSLIP` · `CLEAN_LENS` ·
`RINSE_DROPPER` · `UNMOUNT` · `DELETE_CAPTURE` · `UNDO`.
비늘잎과 거름종이는 **소모품으로 세지 않는다** — 안쪽을 잘못 벗겼을 때 되돌아갈 길이
거기밖에 없고, 치환은 여러 번 하는 것이 정상 경로다.

기포 함수:

```js
bubbles = round(6 × clamp((|angleDeg − 45| − 10) / 45, 0, 1))
// 35°~55° → 0개, 수직(90°)이나 눕힘(0°)에 가까울수록 최대 6개
```

## 관찰 가능성 — 합격이 아니라 상태

```
score = 100 × f방울 × f초점 × f광량 × f두께 × f기포 × f배율 × f렌즈 × f표피면
```

**배율 항이 바나나랩과 다르다.** 여기서 재는 것은 「세포 몇 개 중 몇 개가
원형질분리를 일으켰는가」라 **100배가 최적이다.** 400배는 잘 보이지만 시야에 세포가
예닐곱 개뿐이라 비율을 잴 수 없고, 40배는 원형질체와 세포벽 사이의 틈이 갈라 보이지 않는다.

`f표피면` 은 안쪽 표피일 때 0.3 이다. 낮게 매길 뿐 막지 않는다 —
왜 낮은지는 시야 자체가 말한다.

## 화면이 답을 먼저 말하지 않는다

세포액 농도(`osmosis.CELL_SAP_PCT`)는 **[확인 필요]** 인 데다, 그 값을 관찰로 추정하는 것이
이 실험의 탐구다. 그래서 이 숫자는 **화면 어디에도 나오지 않는다.**
`tests/rules.test.js` 가 `UI` 의 모든 문자열을 훑어 새어 나가는지 본다.
`CAPTURE` 도 원형질분리 세포의 비율을 담지 않는다 — 세는 것은 학생이다.

## 안전은 **판정하지 않는다** (앞의 규칙을 걷어냈다)

한때 마개 방치·폐액 미처리를 `session.violations` 에 기록해 자기 평가에 보여 주었다.
**두 가지가 틀려서 통째로 걷어냈다.**

1. **거짓말을 했다.** 판정을 채우는 `CHECK_TIDY` 가 「보고서 열기」를 누를 때만 도는데
   자기 평가 쪽은 그 전에 보므로, **아무것도 안 한 학생에게 「세 가지를 모두 지켰습니다」**가 떴다.
2. 더 큰 것 — **화면에서 마개를 닫는 것은 안전 습관이 아니라 조작 순서 외우기다.**
   진짜 마개는 교실에서 닫는다. 가상 실험이 그걸 지켜본다고 하면 아이는 화면만 배운다.

지금은 안전을 **하기 전에 읽는 안내**로만 둔다 — 탐구 노트 **2쪽(준비물)** 의 `.safety-note` 다.
자기 평가에는 안전 목록이 없다. `session.violations` · `tidy` 는 **상태에서 사라졌다.**
다시 넣으려거든 위 1·2 를 먼저 읽을 것.
