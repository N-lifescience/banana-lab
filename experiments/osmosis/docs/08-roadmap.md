# 08 · 구현 순서와 완성 판정

> **세포에서 일어나는 삼투 현상 관찰하기** (id: `osmosis`)

## 순서

한 번에 전부 만들지 않는다. 각 단계는 그 자체로 실행되고 눈으로 확인되는 상태에서 끝난다.
카드 본문과 진행표는 `tasks/README.md` 에 있다.

| 카드 | 내용 | 끝났다는 것 |
|---|---|---|
| T01 | 규칙표와 상태 머신 | UI 없이 정상 경로와 모든 실패 경로가 테스트로 통과 |
| T02 | 애셋 | `npm run check:art` 통과, 하네스 애셋 시트에서 옆 칸과 견주어 확인 |
| T03 | 시야 렌더러와 하네스 | 손잡이로 흔들어 눈으로 검증. 성능 측정 |
| T04 | 실험대 조작 UI | `node scripts/check-bench.mjs` + **직접 끝까지 플레이** |
| T05 | 탐구 노트 | 7단계 패널, 기록칸, 절차 판정표 |
| T06 | 서술형 첨삭 | `node scripts/check-grading.mjs` + 바깥 문장 |
| T07 | 보고서 | 농도별 표. 절반 농도는 화면이 계산하지 않는다 |
| T08 | 난이도 세 단계 | `?level=2·3` 으로 **실제로 들어가지는지** 화면에서 |
| T09 | 배포본 확인 | `node scripts/check-build.mjs` — 뒷문 없이 손으로만 |
| T10 | 매니페스트 | `node --test tests/manifest.test.js` |

**결과 보드(Supabase)는 이 저장소에서 만들지 않는다.** 스키마와 제출 코드는 클론에
그대로 들어 있고 이미 돈다 (`src/net/` · `teacher.html` · `supabase/`).

## 완성 판정 체크리스트

기능이 아니라 **설계 의도가 살아 있는지**를 본다. 하나라도 아니면 아직이다.

### 강제하지 않는가

- [ ] **안쪽 표피를 벗기는 것이 되기는 되는가.** 막혀 있으면 이 실험이 가르치려는 실패가 사라진다
- [ ] **거름종이를 안 대도 진행되는가.** 액이 가장자리에 고여 있고 시야가 그대로인가
- [ ] 덮개 유리 없이 400배로 관찰이 **되기는 되는가**
- [ ] 한 방울만 떨어뜨렸을 때 **시야 안에 경계가 보이는가**. 전체가 옅어지기만 하면 잘못 구현한 것
- [ ] 고배율에서 조동나사를 돌렸을 때 슬라이드가 실제로 깨지고, 다시 만들어야 하는가
- [ ] 평형 전에 기록해도 되고, 그 사실이 기록에 남는가
- [ ] `tests/rules.test.js` 의 「하드 게이트는 두 종류뿐이다」가 통과하는가
- [ ] **막다른 길이 없는가.** 비늘잎과 거름종이가 바닥나지 않고, 금 간 유리를 새것으로 바꿀 수 있는가

### 과학적으로 맞는가

- [ ] **세포벽이 농도가 달라져도 그 자리에 그대로 있는가.** 함께 줄면 통째로 거꾸로 가르친다
- [ ] **증류수에서 터진 세포가 없는가.** 세포벽까지 꽉 찰 뿐이어야 한다
- [ ] 원형질체가 물러난 자리가 **바깥 용액으로 차 있는가** (세포벽은 전투과성)
- [ ] 세포액 농도 언저리에서 **한 시야에 두 종류가 섞여 있는가**. 한꺼번에 갈라지면 「절반」 판정이 사라진다
- [ ] 안쪽 표피 시야에 액포색이 나오지 않는가
- [ ] 100배에서 세어지고 400배에서는 셀 만큼 안 들어오는가
- [ ] 두꺼운 표피가 실제로 **겹쳐 보이는가**. 경고만 띄우고 잘 보이면 의미가 없다

### 만듦새

- [ ] `npm run check:art` 통과. 그라데이션·팔레트 밖 색·임의 선 두께 0건
- [ ] 같은 시드로 두 번 그리면 같은 그림, 다른 시드면 다른 그림인가
- [ ] 다크 모드에서 액포색과 세포벽이 모두 식별되는가
- [ ] 결과 보드에 이미지가 저장되고 있지는 않은가. 시드와 파라미터만 오가야 한다
- [ ] 학생 이름·학번을 입력받는 칸이 어디에도 없는가
- [ ] 화면에 `**별표**` 가 그대로 뜨지 않는가

### 화면이 답을 먼저 말하지 않는가

- [ ] **세포액 농도가 화면 어디에도 숫자로 나오지 않는가**
- [ ] 기록(`CAPTURE`)에 원형질분리 세포의 비율이 들어 있지 않은가
- [ ] 농도별 표의 비율 칸이 **비어 있는가**. 세는 것은 학생의 일이다
- [ ] 예상 보기와 결과 요약에 「원형질 분리」 같은 낱말이 없는가.
      그 낱말을 붙이는 것이 정리 단계에서 묻는 일이다
- [ ] 첨삭 문구가 농도를 흘리지 않는가

### 교육적으로 작동하는가

- [ ] 2번 문항에서 **값이 맞았는지를 채점하지 않는가.** 추정하는 것이 이 탐구다
- [ ] 실패한 학생이 **무엇을 고쳐야 할지** 화면에서 알 수 있는가 (`observability().worst`)
- [ ] 1단계 실패 안내에 **다음 행동**이 있고, 그 문장에 **어디로 가야 하는지**가 들어 있는가
- [ ] 다른 모둠 결과가 왜 다르게 보이는지 조작 조건으로 설명할 수 있는가
