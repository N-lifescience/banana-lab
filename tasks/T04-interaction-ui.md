# T04 · 조작 UI

## 목표

개발 하네스를 실제 실험대로 교체한다. 좌측 실험대 + 우측 탐구 노트 2분할.

## 먼저 읽을 것

- `docs/00-overview.md` — 화면 구조
- `docs/04-interaction-rules.md` — 결과 메시지가 어디서 나오는지
- `src/ui/strings.js`

## 건드릴 파일

```
index.html
src/main.js
src/ui/bench.js       (새로) 실험대 — 드래그·드롭
src/ui/zoom.js        (새로) 확대 뷰 — 슬라이드 제작 / 현미경 관찰
src/ui/toast.js       (새로) 결과 메시지
src/ui/strings.js
```

## 할 일

1. **실험대** — 애셋 배치, 집기/놓기. 포인터 이벤트로 통일한다 (태블릿 대응)
2. **확대 뷰** — 슬라이드 제작 모드와 현미경 관찰 모드. `Esc` 로 나간다
3. **결과 메시지** — `reduce()` 가 돌려주는 `message` 를 토스트로 띄운다.
   `outcome === 'happened'` 는 중립 톤, `'blocked'` 만 경고 톤
4. **관찰 가능성 게이지** — 현미경 모드에 상시 표시. `worst` 항목을 함께 보여 준다
5. **되돌리기 버튼** — 남은 횟수 표시

## 하지 말 것

- 버튼을 비활성화(`disabled`)해서 조작을 막지 말 것. **누를 수 있어야 한다.**
  누른 결과가 시야에 나타나는 것이 이 프로젝트의 설계다
- 토스트에 "잘못했습니다", "틀렸습니다" 같은 표현을 쓰지 말 것.
  무슨 일이 일어났는지만 말한다
- 한국어 문자열을 코드에 직접 쓰지 말 것 — `src/ui/strings.js`
- `src/sim/` 에 DOM 코드를 넣지 말 것

## 합격 기준

- [ ] 마우스와 터치 양쪽에서 드래그가 된다
- [ ] 잘못된 조작이 **막히지 않고** 진행되며, 토스트가 무슨 일이 일어났는지 말한다
- [ ] 확대 뷰 전환이 키보드로도 가능하다
- [ ] 포커스 표시가 보이고, `prefers-reduced-motion` 을 존중한다
- [ ] 콘솔 에러 0건
- [ ] 라이트/다크 양쪽 확인
