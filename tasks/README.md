# 작업 카드

**전체 진행 순서와 붙여넣을 프롬프트는 `WORKFLOW.md` 에 있다.** 여기는 카드 자체의 규칙이다.

번호 순서대로 진행한다. 카드 하나가 곧 한 번의 커밋 단위다.

각 카드는 같은 형식이다.

- **목표** — 무엇이 끝나야 하는가
- **먼저 읽을 것** — 이 카드를 하기 전에 반드시 읽는 문서
- **건드릴 파일** — 여기 없는 파일을 고쳐야 한다면 먼저 카드를 수정한다
- **하지 말 것** — 이 카드에서 자주 나오는 실수
- **합격 기준** — 체크박스. 한 줄씩 대조한다
- **검증** — 실제로 실행해서 통과를 확인하는 명령

## 규칙

1. 카드에 없는 일을 하고 싶으면 **먼저 카드를 추가**한 뒤 진행한다
2. 검증 명령이 실패한 상태로 카드를 닫지 않는다
3. 합격 기준에 "눈으로 확인"이 있으면 `npm run shot` 으로 실제 이미지를 남긴다
4. 카드를 닫을 때 이 파일의 진행표를 갱신한다
