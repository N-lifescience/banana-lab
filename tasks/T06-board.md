# T06 · 모둠 결과 보드

## 목표

수업 코드로 묶인 공유 보드. 다른 모둠 결과가 실시간으로 올라온다.

## 먼저 읽을 것

- `docs/07-board-and-deploy.md` — **전부**
- `supabase/schema.sql`

## 건드릴 파일

```
src/board/client.js   (새로) Supabase 클라이언트
src/board/store.js    (새로) 제출·구독
src/ui/board.js       (새로) 보드 화면
supabase/schema.sql
.env.example
```

## 할 일

1. Supabase 프로젝트 생성, `schema.sql` 적용, **RLS 켜기**
2. 수업 코드 입력 → 세션에 보관 (로그인 없음)
3. 제출: `fieldParams()` + 서술 메모. **이미지 업로드 없음**
4. 구독: Realtime 으로 같은 `class_id` 의 새 행을 받아 보드에 추가
5. 카드 렌더: 저장된 시드·파라미터로 `renderFOV()` 를 다시 호출해 그림을 복원
6. 시드 카드 두 장을 미리 깔고, 학생 결과가 3장을 넘으면 감춘다
7. 교사 화면: 수업 코드 발급, 개별 카드 삭제

## 하지 말 것

- **`submissions` 에 이미지 컬럼을 추가하지 말 것.** 시드로 재생성한다
- 학생 이름·학번·이메일을 받는 칸을 만들지 말 것
- RLS 없이 배포하지 말 것. anon key 하나로 테이블 전체가 열린다
- 서비스 롤 키를 프런트엔드에 넣지 말 것

## 합격 기준

- [ ] 로그인 없이 수업 코드만으로 제출·조회가 된다
- [ ] 다른 반 `class_id` 로는 조회되지 않는다 (RLS 실제 확인)
- [ ] 다른 브라우저에서 제출하면 내 보드가 자동으로 갱신된다
- [ ] 저장된 시드로 복원한 그림이 원본과 픽셀 단위로 같다
- [ ] 이미지 컬럼이 스키마에 없다
- [ ] 개인정보 입력칸이 어디에도 없다
- [ ] `expires_at` 이 설정되고 만료 삭제가 동작한다

## 검증

```bash
npm run check
# RLS 확인: 다른 class_id 로 select 를 시도해 0행이 나오는지
```
