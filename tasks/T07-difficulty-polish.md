# T07 · 난이도와 마무리

## 목표

난이도 3단계 분기, 접근성, 모바일, 배포.

## 먼저 읽을 것

- `docs/06-lab-notebook.md` — 난이도 3단계 표
- `docs/08-roadmap.md` — 완성 판정 체크리스트

## 건드릴 파일

```
src/ui/*
src/sim/rules.js      (메시지 상세도 분기)
vite.config.js
```

## 할 일

1. **난이도 분기**
   - 절차 제시: 하이라이트 / 목록만 / 목표만
   - 메시지: 원인+다음행동 / 원인만 / "결과가 나오지 않았습니다"
   - 되돌리기: 무제한 / 3회 / 1회
   - 변인 조작: 고정 / 배율 자유 / 전부 자유
2. **접근성** — 키보드만으로 전체 진행 가능, 포커스 표시, `aria-live` 로 토스트 읽기,
   `prefers-reduced-motion` 존중, 색만으로 정보를 전달하지 않기
3. **모바일** — 태블릿 세로에서 2분할을 상하로 전환, 터치 타깃 44 px 이상
4. **다크 모드** — 시야 원은 항상 밝게 유지 (현미경은 밝은 시야다). 패널만 어둡게
5. **배포** — Vercel 연결, 환경 변수 설정, 학교망 접근 확인

## 하지 말 것

- 3단계에서도 하드 게이트를 늘리지 말 것. 메시지만 줄인다
- 색만으로 청람/선홍을 구분하게 하지 말 것. 라벨을 함께 둔다

## 합격 기준

- [ ] 세 난이도가 실제로 다르게 동작한다
- [ ] 키보드만으로 처음부터 끝까지 진행된다
- [ ] 태블릿 세로에서 조작이 가능하다
- [ ] 다크 모드에서 시야가 어두워지지 않는다
- [ ] `docs/08-roadmap.md` 의 완성 판정 체크리스트를 **한 줄씩** 대조해 전부 통과
- [ ] 배포 URL 에서 학교망 접근이 확인됐다
