# T35 — 진짜 모둠 플레이: 기록을 QR 로 모둠장 기기에 모은다

> 사장님 지시 (2026-09-05): 「모둠으로 플레이했을 때 모둠원 몇 명인지, 모둠명, 모둠장(닉네임만 —
> 학번·이름은 안 된다)을 정하고, 각자 기기에서 플레이하고 탐구노트를 각자 쓴다. 어느 정도 되면
> 그 내용을 모아서 정리하고 … 토의한 후 모둠장 기기에서 정리한 뒤 PDF 로 제출한다.
> 그때에만 개인 정보를 입력한다.」
> 「서버 없이 QR 로 옮기기. 모둠장 기기의 한 화면에서 보고 수정하는 걸로.」

## 원칙 — 바뀌지 않는 것

- **서버·DB·환경변수는 여전히 없다.** 기록은 모둠원 기기 → (QR 또는 코드 문자열) → 모둠장 기기로만 간다.
- **개인정보는 여전히 PDF 를 만들 때만 받는다.** 모둠 설정에서 받는 것은 모둠명·인원·역할·닉네임뿐이고,
  이것도 `store` 밖(`createGroupStore`, 메모리)에 둔다. 새로 고치면 사라진다.
- **막지 않는다.** 닉네임을 안 적으면 「모둠원」으로 부른다. 기록이 다 안 모여도 정리·PDF 는 된다.
- **모둠장의 노트가 곧 모둠 정리다.** 따로 「정리 칸」을 두지 않는다 — 모둠장 화면의 칸마다 모둠원 기록이
  아래 붙고, 「초안 채우기」가 그 칸에 합친 문장을 넣어 준다. 보고서는 지금처럼 모둠장의 노트를 읽는다.

## 만드는 것

| 파일 | 하는 일 |
|---|---|
| `packages/lab-kit/ui/qr.js` | 버전 2~7 → **2~20** (버전 정보 비트, 10 이상의 16비트 길이 필드). 기록 한 조각 ~600 B |
| `packages/lab-kit/group/codec.js` | 순수. 기록 → deflate → base64url → `VB1.<id>.<i>.<n>.<data>` 조각. 조각을 모아 되돌리는 `createCollector()` |
| `packages/lab-kit/group/merge.js` | 순수. 여러 사람 문장을 문장 단위로 나눠 겹치는 것을 지우고 **여럿이 같이 쓴 문장부터** 놓는 초안 |
| `packages/lab-kit/group/store.js` | 모둠 설정 + 모인 기록. 메모리뿐 |
| `packages/lab-kit/group/send-ui.js` | 모둠원: 「기록 보내기」 — QR 여러 장이 자동으로 넘어감 + 「코드 복사」 |
| `packages/lab-kit/group/collect-ui.js` | 모둠장: 「기록 모으기」 — 카메라(jsQR, 누를 때만 내려받음) + 코드 붙여넣기 |
| `packages/lab-kit/group/panel.js` | 노트 머리의 모둠 칸, 칸마다 붙는 모둠원 기록 카드 + 「초안 채우기」 |
| `packages/lab-kit/ui/start.js` | 모둠으로 할 때 모둠명·인원·역할·닉네임을 받는다 |
| `vercel.json` | `Permissions-Policy: camera=(self)` — 앱 안에서 QR 을 읽으려면 필요하다 |
