## 붙여 넣을 프롬프트

banana-lab 저장소의 `src/assets/sink.js` 와 `src/assets/bin.js` 를 **고친다.**
구조·계약·id 는 그대로 두고 **그림만** 손본다. 파일을 새로 만들지 마라.

먼저 `npm run dev` 로 서버를 띄우고 **`http://localhost:5173/harness.html`** 의
「애셋 시트 — 전 종 대조」를 연다. 다른 11종과 나란히 놓고 보면서 고친다.
**혼자 보지 말고 항상 옆 칸과 견주어라.** 이 일은 "맞게 그렸나" 가 아니라
"열세 개가 한 세트로 보이나" 를 맞추는 일이다.

### 개수대 (`sink.js`) — 고칠 것

1. **한 그림에 시점이 둘 섞여 있다.**
   싱크볼 안쪽(사다리꼴 + X자 경사선)은 위에서 내려다본 그림인데,
   바깥 몸통과 상판은 정면에서 본 그림이다. 그래서 "봉투에 X를 그은 것" 처럼 읽힌다.
   **다른 12종과 같은 시점으로 통일한다** — 살짝 위에서 비스듬히 본 3/4 시점이다.
   `microscope.js`, `waste.js`, `tissue.js` 를 열어 그 시점을 그대로 따른다.
   앞면(에이프런)이 보이고, 그 위로 볼 입구가 타원처럼 열려 있어야 한다.

2. **바닥 X자 경사선을 지운다.** 스테인리스 배수 경사를 나타내려 한 것 같은데,
   평면에 대각선 두 개를 그으면 봉투로 읽힌다. 입체가 서면 필요 없다.

3. **우하단 음영(`#basin-shade`)이 몸통 실루엣과 안 맞는다.**
   지금은 몸통 안쪽에 별개의 회색 사각형이 계단처럼 얹혀 있다.
   음영은 **몸통 외곽선을 따라간 조각**이어야 한다. 다른 애셋의 `*-shade` path 를 보라.

4. **토수구가 볼 밖에 있다.** 수도꼭지에서 나온 물이 상판 위로 떨어진다.
   구스넥 끝(물 나오는 곳)이 **볼 안쪽 위**에 오게 한다.
   `#water` 의 물줄기도 그 자리에서 볼 바닥으로 떨어져야 한다.

5. **여백이 없다.** 프레임을 꽉 채워서 다른 애셋과 나란히 놓으면 혼자 답답하다.
   `banana.js` 정도의 여백을 남긴다.

### 쓰레기통 (`bin.js`) — 고칠 것

1. **음영(`#trash-shade`)이 통을 뚫고 나간다.**
   뚜껑 오른쪽에 네모난 회색 판이 붙어 있고, 페달 옆으로도 사각형이 삐져나온다.
   가장 눈에 띄는 문제다. 음영은 **몸통·뚜껑 외곽선 안쪽**에만 있어야 한다.

2. **`#trash-fill` 이 화면에 안 나타난다.**
   뚜껑이 투입구를 덮고 있어서, 안에 버린 덮개 유리가 `opacity: 1` 이 되어도 아무것도 안 보인다.
   **이건 계약 위반이다** — 코드는 이 노드의 opacity 로만 "찼다/비었다" 를 말한다.
   뚜껑을 살짝 열어 두거나, 통 앞면에 투명창을 두거나, 뚜껑 위로 살짝 넘치게 그려서
   **`fill: 0` 과 `fill: 1` 이 눈으로 구별되게** 한다.
   `npm run dev` 후 하네스에서 두 상태를 번갈아 보며 확인해라.

3. **라벨의 영어를 뺀다.** "SOLID WASTE" 가 한글보다 크고 눈에 먼저 든다.
   이 앱은 한국어 앱이다. 한글만 남기고, 작은 글씨는 지워라 —
   실물 크기 240 mm 라 화면에서는 어차피 안 읽힌다.

4. **페달의 분홍 줄무늬를 없앤다.** `PALETTE.rubber` 는 스포이트 고무 색이다.
   이 색이 실험대에 또 나오면 수단 Ⅲ(선홍색)과 헷갈린다. 금속색이나 몸통색을 써라.

5. **뚜껑이 열린 것도 닫힌 것도 아니다.** 뚜껑 아래로 투입구 타원이 드러나 있어
   뚜껑이 떠 있는 것처럼 보인다. 닫힌 모양을 확실히 하거나, 2번과 함께 확실히 열어라.

### 두 애셋 공통 — 절대 바꾸지 말 것

- `viewBox` 는 `0 0 400 300` 고정
- `NODES` 배열과 id: `sink.js` → `#basin`, `#basin-shade`, `#faucet`, `#water` /
  `bin.js` → `#trash`, `#trash-shade`, `#trash-fill`
- `export` 셋: `NODES`, `render(state)`, `applyState(root, state)`
- `src/assets/contract.js` 와 `src/ui/` 는 건드리지 마라
- 색은 `PALETTE` 값만. 선 색은 `INK` 하나. 두께는 `STROKE.outline(3)/.detail(2)/.hair(1.5)`
- 그라데이션·필터·블러 금지. 광원은 좌상단 45° 고정

### 끝났는지 확인하는 법

```bash
npm run check:art -- sink
npm run check:art -- bin
```

둘 다 "위반 없음". 그다음 **반드시 하네스에서 눈으로** 확인한다.

```bash
npm run dev
```

`http://localhost:5173/harness.html` → 「애셋 시트 — 전 종 대조」

- 열세 칸이 같은 시점·같은 선 두께로 보이는가
- 음영이 전부 형태 안쪽 우하단에 있는가 (밖으로 튀어나온 조각이 없는가)
- 폐액통과 쓰레기통이 한눈에 구별되는가
- 쓰레기통의 `fill: 0` 과 `fill: 1` 이 눈으로 구별되는가
- 라이트 모드와 다크 모드 양쪽에서 봤는가

## 사람이 알아 둘 것 (프롬프트에 포함하지 않음)

- 1차 결과물도 **린터는 통과했다.** 린터는 색·선 두께·금지 요소만 본다.
  시점·실루엣·상태가 눈에 보이는가는 기계가 못 잡는다. 그래서 하네스를 보라고 시킨 것이다.
- `#trash-fill` 이 안 보이는 것이 가장 무거운 문제다. 계약된 노드가 화면에 나타나지 않으면
  코드가 상태를 말할 방법이 없어진다 (`docs/02`).
- 덮개 유리(`coverslip.js`)의 접지 그림자가 회전을 안 따라가던 버그는 **이쪽에서 이미 고쳤다.**
  안티그래비티가 만든 것이 아니라 T02 부터 있던 것이다.
