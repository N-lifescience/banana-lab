# T17 애셋 — 덮개 유리 통

낱장 덮개 유리는 22 mm 라 실험대에서 12 px 남짓으로 그려집니다. 석 장을 늘어놓아도
무엇인지 알아볼 수가 없어서, **통 하나에서 꺼내 쓰는 것**으로 바꿨습니다.

계약(`src/assets/contract.js`)·상호작용(`src/ui/bench.js`)·문자열은 **이미 붙어 있습니다.**
`src/assets/coverbox.js` 에 자리표시 그림이 들어 있고, 그것만 다시 그리면 됩니다.

아래 「붙여 넣을 프롬프트」를 그대로 복사해서 던지세요.

---

## 붙여 넣을 프롬프트

banana-lab 저장소의 `src/assets/coverbox.js` **한 파일만** 다시 그린다.
구조·계약·id 는 그대로 두고 그림만 손본다. 다른 파일은 건드리지 마라.

먼저 `npm run dev` 로 서버를 띄우고 **`http://localhost:5173/harness.html`** 의
「애셋 시트 — 전 종 대조」를 연다. 이미 있는 열세 종과 나란히 놓고 보면서 그린다.
**혼자 보지 말고 항상 옆 칸과 견주어라.** 이 일은 "맞게 그렸나" 가 아니라
**"열네 개가 한 세트로 보이나"** 를 맞추는 일이다.

### 무엇을 그리는가

**덮개 유리(커버글라스) 22 × 22 mm 낱장을 담아 두는 작은 통.**
학생은 핀셋을 이 통에 끌어다 대어 한 장을 집는다. 그러니 그림만 보고
**"저 안에 얇은 유리가 여러 장 들어 있고, 핀셋으로 한 장 집을 수 있겠다"** 가 읽혀야 한다.

- 뚜껑이 **열려 있어야 한다.** 닫힌 통은 안에 무엇이 있는지 말해 주지 않는다.
- 유리 낱장이 **통 위로 살짝 드러나** 있어야 집을 수 있는 것으로 읽힌다.
- 여러 장이 겹쳐 있다는 것이 보여야 한다. 한 장만 그리면 그냥 유리 조각이다.

### 반드시 지킬 것

- `viewBox` 는 `0 0 400 300` 고정
- `NODES` 배열과 id 를 **그대로 유지한다**: `#box`, `#box-shade`, `#stack`
  - `#stack` 은 통에 담긴 덮개 유리 묶음이다. 이 노드가 없으면 계약 위반이다
  - `#box-shade` 는 통의 우하단 음영이다
- `export` 는 셋: `NODES`, `render(state)`, `applyState(root, state)`
  - **상태가 없다.** `render()` 는 인자를 받지 않아도 되고, `applyState` 는 비워 둔다.
    덮개 유리는 얼마든지 꺼내 쓰고, 한 번 쓴 것은 쓰레기통으로 가지 이 통으로 돌아오지 않는다
- 색은 `src/style/tokens.js` 의 `PALETTE` 값만. 선 색은 `INK` 하나.
  두께는 `STROKE.outline(3) / .detail(2) / .hair(1.5)` 셋뿐
- **유리는 `PALETTE.glass` 를 쓴다.** 통 몸통은 유리와 구별되는 색이어야 한다
  (자리표시는 `PALETTE.bodyDark` 를 썼다. 더 나은 선택이 있으면 팔레트 안에서 바꿔라)
- 그라데이션·필터·블러 금지. 광원은 **좌상단 45° 고정** — 음영은 언제나 형태의 우하단
- 시점은 다른 열세 종과 같은 **살짝 위에서 비스듬히 본 3/4 시점**.
  `tissue.js`, `waste.js`, `microscope.js` 를 열어 그 시점을 그대로 따른다
- 프레임을 꽉 채우지 마라. `banana.js` 정도의 여백을 남긴다
- 영어 글자를 넣지 마라. 이 앱은 한국어 앱이다.
  실물 60 mm 라 화면에서는 어차피 안 읽히니 글자는 없어도 된다
- `src/assets/contract.js`, `src/ui/`, `src/assets/index.js` 는 **건드리지 마라**

### 크기에 대해

`contract.js` 에 `realSizeMm: 60` 으로 선언돼 있다. 실험대에서의 화면 크기는 이 값에만
비례한다 — **그린 크기가 아니라 이 값이 화면 크기를 정한다.** 400×300 프레임은 꽉 채워
그리되, 실험대에서는 스포이트(150 mm)의 40 % 크기로 나온다는 것을 염두에 둬라.
그 크기에서도 "통에 유리가 들어 있다" 가 읽혀야 한다. **작게 줄여 놓고 확인해라.**

### 끝났는지 확인하는 법

```bash
npm run check:art -- coverbox
```

"위반 없음" 이 떠야 한다. 그다음 **반드시 하네스에서 눈으로** 확인한다.

```bash
npm run dev
```

`http://localhost:5173/harness.html` → 「애셋 시트 — 전 종 대조」

- 열네 칸이 같은 시점·같은 선 두께로 보이는가
- 음영이 형태 안쪽 우하단에 있는가 (밖으로 튀어나온 조각이 없는가)
- 휴지 상자와 헷갈리지 않는가 (둘 다 상자다 — 확실히 달라야 한다)
- 라이트 모드와 다크 모드 양쪽에서 봤는가
- **실험대 화면(`http://localhost:5173/`)에서 실제 크기로 봤는가**

## 사람이 알아 둘 것 (프롬프트에 포함하지 않음)

- 린터는 색·선 두께·금지 요소·계약 노드만 본다. 시점·실루엣·"작게 줄여도 읽히는가" 는
  기계가 못 잡는다. 그래서 하네스와 실험대를 눈으로 보라고 시킨 것이다.
- 통으로 바꾸면서 실험대의 낱장 석 장(`coverslip1~3`)은 없어졌다.
  종류(`kind: 'coverslip'`)는 그대로라 조작표(`dropTable`)와 규칙은 손대지 않았다.
- 낱장 애셋 `coverslip.js` 는 **그대로 남는다.** 확대 뷰에서 핀셋이 집어 든 유리를 그릴 때와
  탐구 노트 준비물 표에서 쓴다. 이 통과 나란히 놓이는 그림은 아니다.
