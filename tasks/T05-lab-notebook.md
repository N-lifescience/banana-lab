# T05 · 탐구 노트

## 목표

7단계 노트 패널, 세부 단계 기록칸, 서술형 자동 첨삭.

## 먼저 읽을 것

- `docs/06-lab-notebook.md` — **전부**

## 건드릴 파일

```
src/ui/notebook.js    (새로)
src/ui/grading.js     (새로) 서술형 첨삭
src/ui/strings.js
src/sim/state.js      (session.notes 구조가 부족하면)
tests/grading.test.js (새로)
```

## 할 일

1. 7단계 탭 + 현재 세부 단계 하이라이트
2. 세부 단계마다 관찰 기록칸 (`session.notes[stepId]`)
3. 3단계 예상 — 세 슬라이드에 무엇이 보일지 먼저 배치. **채점하지 않는다**
4. 5단계 결과 — 캡처 3장 자동 첨부 + 배율 직접 입력
5. 6단계 서술형 3문항 + 자동 첨삭
6. 흐린 캡처가 있으면 성찰 문항을 자동 추가
7. 7단계 자기 평가 — `session.violations` 를 '가치·태도' 항목에 그대로 표시

## 첨삭 구현 방침

키워드 포함 검사로 충분하다. **형태소 분석기를 끌어오지 말 것.**
학생 문장을 정확히 판정하는 게 목적이 아니라 다시 보게 만드는 게 목적이다.

```js
// 예: 2번 문항 — 대조 구조를 보는 것이 핵심
const starchWords = ['많', '가득', '고르', '빽빽', '전체'];
const lipidWords  = ['적', '드문', '작', '몇', '드물'];
// 둘 다 등장해야 통과
```

## 하지 말 것

- 통과하지 못했다고 다음 단계를 막지 말 것. 되돌려 주는 말만 보여 준다
- 예상(3단계)을 채점하지 말 것
- 안전 규칙 위반으로 점수를 깎지 말 것. 보여 주기만 한다

## 합격 기준

- [ ] `tests/grading.test.js` 통과
