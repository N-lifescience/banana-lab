# 05 · 현미경 시야 렌더러

## 원칙

시야는 미리 그린 그림이 아니라 **상태에서 매번 생성**한다. 그래야:

- 배율·초점·두께를 바꾼 결과가 정직하게 반영된다
- 결과 보드가 이미지 대신 시드만 저장할 수 있다 (07번 문서)
- 같은 학생이 다시 열어도 같은 그림이 나온다

아트 디렉션(라인+플랫)은 **여기 적용되지 않는다.** 시야는 광학 시뮬레이션이라 굵은 외곽선을 쓰지 않는다.
다만 염색색은 `PALETTE` 를 공유한다.

## 광학 — 임의로 바꾸지 말 것

접안렌즈 시야수(FN) 18 mm 기준.

```
시야 지름(µm) = 18000 / 대물배율
pxPerUm       = 시야원 지름(px) / 시야 지름(µm)
```

| 대물 | 총배율 | 시야 지름 | 세포 가로 개수 | 녹말립 |
|---|---|---|---|---|
| 4× | 40배 | 4500 µm | 약 30개 | 개별 식별 불가 → 패턴 텍스처 |
| 10× | 100배 | 1800 µm | 약 12개 | 개별 도형, 지름 약 5.5 px |
| 40× | 400배 | 450 µm | 약 3개 | 개별 도형, 지름 약 22 px |

실물 치수 (고정 상수):

- 바나나 유세포 **150 µm**
- 녹말립 **30 µm** — 세포 안에 약 20개
- 염색된 지질 방울 **14 µm**

`tests/optics.test.js` 가 이 값들을 고정하고 있다. "보기 좋게" 바꾸려는 시도는 거기서 막힌다.

## 개별 묘사 임계

세포 지름이 화면에서 **20 px 미만**이면 녹말립을 개별 도형으로 그리지 않고 `<pattern>` 텍스처로 대체한다.

성능 때문만이 아니다 — **40배에서는 실제로도 알갱이가 분해되지 않는다.**
이 임계가 "저배율에서는 위치만 확인하고 배율을 올린다"는 절차의 이유를 화면으로 설명해 준다.

## 생성 규칙

| 요소 | 규칙 |
|---|---|
| 세포벽 격자 | 불규칙 사각 셀, 한 변 `150 µm × pxPerUm`. 지터 ±16% |
| 녹말립 | 셀당 20개. 장축:단축 ≈ 1.6:1. **세포 안에 고르게 가득** |
| 지질 방울 | `면적 / 46000 µm²` 개, 최소 4 최대 320. 정원. **드문드문 흩어짐** |
| 염색 영역 | 용액이 떨어진 자리를 중심으로 반지름 `coverage × R × 1.6`. 안쪽 72%는 완전, 바깥은 옅음 |
| 색상 (가) | 염색 없음. 굴절률 차이만으로 보이는 옅은 회색 윤곽 |
| 색상 (나) | 녹말립만 청람색. 배경 세포질은 옅은 노란빛(잔여 아이오딘) |
| 색상 (다) | 지질 방울만 선홍색. 녹말립은 무색 윤곽 — **이 대비가 관찰의 핵심** |
| 교차 오염 | 두 색이 한 시야에 섞여 나타난다 |
| 초점 흐림 | `blur = focusErr × 22 px` |
| 광량 | 검은 오버레이 `(1 − brightness) × 0.7` |
| 두께 과다 | 어두운 갈색 반투명 층으로 구조가 뭉개진다 |
| 기포 | 굵고 짙은 테두리의 큰 원 |
| 넘침 | 덮개 유리가 떠서 상이 8 px 어긋나 겹친다 |
| 렌즈 오염 | 한쪽에 얼룩진 타원 |

## 절대 하면 안 되는 것

**지질 방울 개수를 늘려서 (다) 슬라이드를 화려하게 만들지 말 것.**
바나나 과육의 지방 함량은 0.3 % 내외다. 녹말립처럼 빽빽하게 그리면 과학적으로 틀린 시뮬레이터가 되고,
교과서 2번 문항(「녹말과 지방이 어떻게 분포하는지」)의 정답 근거가 무너진다.
